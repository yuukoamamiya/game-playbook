# 银河战士 融合

<ReviewTabs slug="metroid-fusion">

<ReviewTab id="ign" site="ign" label="IGN">

> 来源：[IGN](https://www.ign.com/articles/2002/11/12/metroid-fusion-review) · 作者：Craig Harris · 发布：2002-11-12 · 评分：9.5/10

这一天终于来了，兄弟，值得等待。任天堂把备受要求的《银河战士》系列搁置多年后，终于给玩家献上他们渴求的东西：一部真正的续作，不仅达到并超越了系列前三部作品确立的公式，也超越了人们对掌机体验的期待。《银河战士 融合》是 GBA 上一项杰出的成就。它不仅在这台掌机硬件上提供了极其出色的动作冒险设计，也向市场展示了只要有足够的时间和投入，这台主机能做到什么。

**特性**

- 七个不同区域可供探索
- 约十二小时的冒险
- 与《银河战士 Prime》的 GameCube 联动功能
- 卡带存档（三个存档位）
- 仅限 Game Boy Advance

《银河战士 融合》紧接《超级银河战士》结尾展开。在一次返回 SR388 星球的例行旅程中，萨姆斯遭到一种前所未见的生命体袭击，它被称为 X 寄生体。对我们的女主角来说不幸的是，这种寄生体感染了萨姆斯几乎所有生命系统。濒死之际，萨姆斯被一种用她上次任务中救下的密特罗德 DNA 制成的疫苗所救。但在此过程中，她的身体和熟悉的装甲被改变，让她处于虚弱得多的状态。即便如此，她还是被派往一座研究站，去调查并有可能消除日益增长的 X 寄生体威胁。

X 寄生体能利用其他生物的 DNA 变成它们的样子，所以研究站里满是熟悉的、却急剧变异的生物，它们被 X 控制。以新形态、新装束，萨姆斯现在能吸收区域内任何飘浮的 X 寄生体；这些寄生体会补充萨姆斯的能量和武器储备，就像前作中随机掉落的图标那样。随着玩家深入游戏，会与同样被大型 X 寄生体控制的 Boss 战斗。击败这些区域 Boss 并吸收其中的寄生体后，玩家就能恢复萨姆斯失去的众多能力之一，从她标志性的变形球到基于经典招式的强化特殊技巧。

这将是本篇评测中唯一真正的潜在剧透，但知道它很重要，因为它是整个《银河战士 融合》剧情的驱动力：一个寄生体利用萨姆斯的部分 DNA 和旧装甲，变成了这位赏金猎人本人的样子。这个生物，下文称为 SA-X，本质上就是巅峰状态的萨姆斯（不是双关）。在游戏中遇到 SA-X 几乎必死无疑，因为这玩意想让你死，就像你想让 X 寄生体死一样。

《银河战士 融合》庞大的剧情出色而引人入胜，尽管它的种种意外最终呈现出某部熟悉的科幻电影的样子。但游戏真正闪光的地方是整体玩法。开发者沿用了 SNES《超级银河战士》、NES《银河战士》和 Game Boy《银河战士 II》确立的东西，并把这套公式用在《融合》的关卡设计上。玩家必须学会用萨姆斯获得的能力打开隐藏通道和门；某些砖块没有特定技巧就无法摧毁，而很多时候那种技巧是在游戏更深处才学到的。所以要记在脑子里，因为研究站里许多隐藏内容都需要在获得更强攻击后回头来取。

正是 SA-X 的加入真正带出了许多“糟糕！”的处境。近距离看着萨姆斯克隆体在一个区域巡逻有点紧张，因为走错一步你就瞬间完蛋。冒险中有好几处会把你的快速反应逼到极限，以免被 SA-X 克隆体轰成碎片……而游戏中最有趣、最紧张的时刻正来自萨姆斯／SA-X 的遭遇。

开发者在利用 GBA 有限的四键布局实现大量不同能力方面做得极为出色。导弹发射方式的一点小改动给玩法带来很大不同；在前作中，玩家要用按键开关导弹。在《融合》中，光炮与导弹的切换通过 R 键变得瞬间直观得多：按住发射导弹，松开是光炮。我唯一遇到操作麻烦的地方是游戏后期获得的一个动作，它让击败某些敌人所需的精准跳跃变得困难。即便练习过，这个动作也无法稳定流畅地完成……在冒险深处的激烈战斗中尤其烦人。

虽然它看起来像一款《银河战士》，内部结构却明显改变了。在系列以往的作品中，你都是孤身一人。一切都在于探索；如果你在某个区域卡住或被困，那就是你忽略了什么。在《融合》中，被明确告知该去哪、该做什么、该期待什么，有点奇怪、也非常不《银河战士》……但这恰恰就是发生的事。整个冒险中，萨姆斯不断与她的电脑保持联系，电脑本质上在支配她的下一步行动。这确实某种程度上破坏了前三部《银河战士》作为支柱的探索要素。但反过来说，没有电脑，游戏的剧情就不会像本作这样深邃、引人入胜。如果没写进这套强制设计，游戏肯定会更长，我很矛盾，因为我认为萨姆斯与电脑之间的“对话”让氛围受益匪浅。

GBA 是 2D 强机，开发者确实在《融合》中很好地发挥了它的实力；这段冒险看起来极其精致，研究站各个区域都有不错的色彩深度。萨姆斯本人的动画有好几帧，设计师也没偷懒；每个动画都画了两遍，以确保她的光炮永远在她的右臂上。开发者用透明图层实现了可信的光照、水和热效果，而 X 寄生体仿佛靠程序员对 GBA 精灵图缩放能力的运用而有了生命。许多效果如此微妙、运用得如此有效，不会把玩家拉出游戏体验；“哇，酷！”的时刻少而稀疏，只因整个游戏的画面都做得太成功了。

音频也极好地烘托了整个游戏。GBA 并不以声音能力著称，但已有几位开发者在这台掌机上做出了出色的音频。可没有人像《融合》这样有效。配乐克制却恰如其分，绝对贴合冒险的情绪。音效渲染得很好，延续了 SNES《超级银河战士》确立的风格。我强烈建议你利用音频选项里特殊的“耳机”功能，因为游戏的立体声效果是耳朵的甜美糖果。

</ReviewTab>

<ReviewTab id="gamespot" site="gamespot" label="GameSpot">

> 来源：[GameSpot](https://www.gamespot.com/reviews/metroid-fusion-review/1900-2897729/) · 作者：Greg Kasavin · 发布：2002-11-15 · 评分：8.6/10

许多玩家如此深情地记得 Super Nintendo Entertainment System，原因之一是 1994 年的《超级银河战士》——经典开放式横版射击系列的第三部，也是有史以来最好的 2D 动作冒险游戏之一。由强悍的星际赏金猎人萨姆斯·阿兰主演，《超级银河战士》呈现出同类游戏中前所未见的细节、打磨与风格。这个始于 NES、延续于 Game Boy 的系列的粉丝尤其激动，因为《超级银河战士》充分实现了前辈们独特的玩法风格。此后萨姆斯曾在任天堂的多人派对游戏中露面几次，但如今她终于回到她所属的聚光灯下，任天堂同时推出两部而非一部出色的《银河战士》。GameCube 的《银河战士 Prime》是把系列雄心勃勃地重塑为全 3D，而 GBA 的《银河战士 融合》则回归《超级银河战士》，在一段全新冒险中提供那款游戏的大部分最佳品质。令人失望的是《融合》结束得太快，因为它在持续期间是如此出色。

与任何其他《银河战士》游戏不同，《融合》极度由剧情驱动。游戏以若干回顾过场开场，解释萨姆斯如何陷入最新的困境。在一次例行任务中，她遭到一种未知寄生生物袭击，它侵染她的神经系统，把她的动力装甲与她的身体融合（游戏标题由此而来），过程中几乎杀死她。讽刺的是，这种被简称为“X”的生物原来是密特罗德的天然敌人——那些萨姆斯多年前猎杀的水母状吸能生物。既然密特罗德显然已经灭绝，X 便迅速繁殖，突然对宇宙构成严重威胁，一如密特罗德曾经那样。幸运的是，用最后一只密特罗德 DNA 制成的珍贵疫苗救了萨姆斯的命——但她变了，除其他外，她如今对 X 的进一步污染免疫。所以当环绕 X 寄生体母星运行的一座深空研究实验室发来求救信号时，萨姆斯迅速接下这份工作。果不其然，设施已被侵占。于是，在一名电脑化指挥官的警惕“目光”下，萨姆斯出发去拯救研究站的残部，并希望能找到一劳永逸消灭 X 的办法。

这是个好故事，它有效地推动动作前进，因为萨姆斯的指挥官引导她穿过研究设施众多被感染的区域。但对剧情的侧重对玩法产生了某种影响。虽然《银河战士 融合》本质上具有前辈们的开放式设计——萨姆斯在游戏过程中获得众多新能力，使她能够进入此前无法到达的区域——但剧情如此紧迫，以至于你很可能发现自己不断听从指挥官的命令，而没时间探索。游戏中从来没有一刻局势不危急，所以不像过去《银河战士》那样仔细勘察周围，在《融合》中你会发现自己从一个检查点冲到下一个，一路直到开始后大约六小时（前后差一小时）通关。无法直接跳过剧情段落这一点也削弱了《融合》的重玩价值，因为你会希望自己只是在玩游戏，而不必时不时坐下来读一堆文字。

坏消息说完了，值得重申：《银河战士 融合》真的是一款出色的游戏。极其灵敏的操作、极佳的画面和出色的音频，让《融合》轻松成为 GBA 上最好的动作游戏之一。玩过《超级银河战士》的人会感到宾至如归，不过这款新作提供了若干新玩法机制。由于 X 寄生体，萨姆斯在游戏开始时没有多少标志性能力，但她仍能跑得飞快、跳得很高，并朝周围八个方向发射主光束武器。她很快恢复一些标志性技能，例如卷成“变形球”穿过狭窄通道，以及发射强力导弹。萨姆斯这次能抓住边缘，这在尝试一些危险跳跃时是必需的，在她错过平台落点时也很有用。悬挂时，萨姆斯可以把自己拉上去，或把脚蹬在附近的墙上向后翻跃。萨姆斯还能爬梯子，或在某些类型的天花板上双手交替移动，且能边移动边射击。尽量别太纠结为什么她右手还装着一门大光炮却能做所有这些新攀爬动作。

除那些基本技能外，萨姆斯会在游戏过程中升级她的光束武器、导弹和变形球炸弹，还会获得其他能力，比如旋斩攻击，让她在空中翻滚时整个身体都成为武器。《超级银河战士》中几个更酷的能力，如抓钩光束，缺席了，但这里有足够的东西替代它们。和前作一样，不断为萨姆斯的装甲寻找新升级的动力让《融合》非常吸引人。她开局就很强，到游戏结束时将极其强大。

她必须如此，因为 X 是强大的对手。很像约翰·卡朋特电影（以及近年的游戏改编）里的“怪形”，X 能模仿宿主，利用其身体达成自己邪恶的目的。等萨姆斯出现时，研究设施已经满是各种危险生物，从原科学家们可怜的残骸，到冲出隔离区的巨兽。萨姆斯本人曾是 X 的宿主，你最好相信寄生体利用了这个机会——她最危险的敌人其实是一个与她旧日自我一模一样的复制品，全副武装，毫无悔意。你会在游戏中多次遇到这个冒牌萨姆斯，每一次都极其紧张。其他许多遭遇同样精彩，萨姆斯必须与若干巨大、丑陋、强大的 Boss 一决高下才能收工。其中一些相当难，而且看起来都很棒。

一个有趣的转折是，萨姆斯对纯净形态 X 的免疫意味着她可以无害地吸收那些曾几乎杀死她的寄生体。击败敌人会让它们交出鬼魂——或者说是无定形的团块——萨姆斯必须在这些彩色东西飞走前抓到手——不仅因为吸收 X 能恢复萨姆斯的部分生命，还因为如果她不吸掉 X，它们要么再生，要么找到新宿主。总而言之，X 在《融合》中构成了一个不同而引人入胜的核心威胁，而且出人意料地很好地弥补了你对付的不是那些可爱的密特罗德这一点。

游戏完全发生在研究实验室里。这让《融合》的设定听起来相当平淡，但你会发现设定做得相当好。原来这座设施模拟了各种行星生物圈，所以你会找到气候类型完全不同的区域：炽热、严寒、水域、夜间、热带、干旱等等。《融合》的地点其实有相当丰富的多样性，有些需要技巧性的跳跃和射击，另一些则需要敏锐的眼力和仔细的探索。大多数区域起初被封锁，需要你先获得特定技能，再用它们绕过此前无法逾越的障碍。到后期，你需要几乎协同运用所有众多技能，才能穿过设施日益破败的内部。

《银河战士 融合》看起来极佳，任何深情记得《超级银河战士》出色画面的人都会高兴地发现，本作的高品质与之相当。萨姆斯本人的动画流畅得惊人，细节极其丰富——例如，你会注意到她的不对称装甲朝左或朝右时看起来不同。她面对的许多怪物看起来也很棒，尤其是游戏中巨大的 Boss。她穿越的环境既多彩又多样，背景里通常也有有趣的东西可看。连游戏的过场都很利落。《融合》听起来也很棒，虽然其配乐未达到《超级银河战士》那般伟大，但确实很好地为游戏增添了氛围。事实上，剧情中那些悬疑时刻之所以奏效，很大程度上要归功于相称的音乐。其余音频也非常好。众多生物听起来各不相同，萨姆斯的武器和各种升级也是如此。

《融合》显得如此短的部分原因，是你大概忍不住会分几次就通关。游戏玩起来如此顺畅、看起来如此漂亮、故事如此引人入胜、节奏如此之快，以至于你总想看看下一个转角有什么，直到很快看完一切。如果你也拥有《银河战士 Prime》——你应该拥有——那么在通关《融合》后，把 GameCube 和 GBA 游戏连起来（使用任天堂单独出售的 GC 转 GBA 连接线），就能在电视上（而非 GBA 上）游玩初代《银河战士》的完美移植版。而当你通关《Prime》后，你还能用萨姆斯独特的融合装甲重玩那款游戏。这些额外内容对《融合》本身没有增添什么，但本质上确实为拥有其 3D 对应作品的人提供了额外价值。不过更重要的是，《银河战士 融合》是一个一直很出色的系列中又一部优秀的作品。《银河战士》粉丝绝对应该入手，任何愿意用游戏时间换取品质而非数量的人也应如此。

> 来源：[Eurogamer](https://www.eurogamer.net/r-metroidfusion-gba) · 作者：Tom Bramwell · 发布：2002-11-26 · 评分：9/10

在 N64 生命的大部分时间里，我都在咒骂任天堂没能延续赏金猎人萨姆斯的故事——她在 Super Nintendo、GameBoy 乃至更早的 NES 上对抗邪恶密特罗德生物的 2D 冒险，我玩得那么开心。然而，《银河战士 融合》（GBA）与《银河战士 Prime》（Cube）这对组合，让系列以远超我期待的惊人姿态回归，令我喘着气、直纳闷这一切到底是从哪儿冒出来的！

GBA 这边问题的答案是“Intelligent Systems”。前身为 R&D1 的 Intelligent 是任天堂第一家内部开发工作室，是《银河战士》系列的诞生地，也是《火焰之纹章》系列、纸片马力欧和《高级战争》的诞生地——难怪《银河战士 融合》是有史以来最好的 GBA 游戏之一？不过，即便考虑到开发者辉煌的历史，做出一款超越《超级银河战士》的东西也一直很难——我认为他们做到了，但无论众多《银河战士》粉丝是否同意，融合仍是一款值得所有人关注的了不起的平台冒险。

那么，以下是原因……

## 寄生前夜

《融合》从《超级银河战士》结束的地方开始。在 SR388 上提供任务支援时，萨姆斯遭到前所未见的 X 寄生体袭击并感染。X 感染了她大部分生命系统，全靠一种基于密特罗德 DNA 的疫苗她才活下来。尽管发现自己极度虚弱，萨姆斯仍被迫前往一座研究站，从源头调查并消灭 X 寄生体。

X 寄生体是讨厌的小混蛋。它们会呈现所感染生物的大致形状和形态，所以研究站里满是变强、突变成其旧日自我可怕近似物的老敌人（很像《怪形》）。不同之处在于，通过杀死它们并吸收其中的 X 寄生体（她如今对此免疫），萨姆斯能补充生命和弹药储备，就像她过去在多色图标上做的那样。

萨姆斯遇到的任何 Boss 都会产出更大的 X 寄生体，一旦吸收，它们会重新赋予她特殊能力，以及一堆新能力。所以没过多久，萨姆斯就取回了她可靠的变形球能力，让她能变成小球进入狭窄空间、洞穴和此前无法到达的区域，而到游戏结束时，她将拥有全部旧能力和更多。令人高兴的是，她的所有新能力都是旧能力的增强，对我这样的老《银河战士》粉丝来说是种安慰。

不幸的是，普通被 X 控制的坏东西和 X Boss 与终极威胁 SA-X 相比根本不算什么。SA-X 是 X 寄生体首次侵入萨姆斯形态的结果，它几乎模仿她的每一项技能，只不过 SA-X 从一开始就全副武装，而萨姆斯直到最后都很脆弱。这个“反萨姆斯”是剧情不可分割的一部分，却完全无法触碰——如果你看到 SA-X 超过几秒，萨姆斯多半就没命了。Intelligent Systems 很早就把这一点钉死，一旦确立，他们就用这条规则细致地把你吓得魂飞魄散，牵着你的鼻子把你带到离毁灭近在咫尺的地方，再又走出来。

## 我怕改变！

但这是怎么回事，你说，牵着鼻子走？这听起来不像《银河战士》。我同意，确实不像，我起初非常怀疑。萨姆斯几乎不断与她的飞船电脑联系，这意味着被困、孤身一人的感觉几乎完全消失，你几乎总是清楚自己该去哪、为什么。

《银河战士》当然以其自由形式的玩法闻名。你在一场冒险中，一边漫游一边揭开零碎，并获得能开启此前无法进入区域的能力。这是 Retro Studios 为《银河战士 Prime》极精准保留的信条，但 Intelligent Systems 也设法保留了它，同时勇敢地摒弃了前作那种盲目“我不知道自己要去哪，但如果到不了某处，那一定是我漏了什么”的心态。

随着游戏推进，萨姆斯继续收集新能力，让她能摧毁早期挡路的某些砖块；和之前的 2D《银河战士》一样，玩家需要把设计的某些部分记在脑中，以便当砸碎某种砖块的能力到手时，确切知道该回头去哪收获奖励。《银河战士》之美正在于完全取决于你和你的记忆——你可以在不探访新宝藏的情况下通关（尽管会稍难一些），但这个系列一直是完美主义者的游乐场，《融合》尊重这一点。更重要的是，它还有一条强烈、连贯、难忘的剧情，只是浸泡在过多常见的科幻元素里。

## 到处都是 Intelligent Systems

在 GBA 上玩《融合》比我预想的容易得多，这主要归功于 Intelligent Systems 把武器功能合二为一的方式。不必一个键发射光炮、另一个键发射导弹，你只需按开火键射击，想发射导弹就按住 R 键再按。这套系统一般不会出问题。

不过，征服了操作和玩法问题之后，如果游戏看起来和前辈一模一样，那也不会有多好，而这正是我最预期《融合》会失手的地方；但和其余部分一样，它顽固地拒绝失手。《银河战士 融合》是最好看的 GBA 游戏之一，萨姆斯动画可爱，水、光照和热效果借助透明图层运用出色，还有太多微妙效果难以尽述。环境（共七个）色彩鲜明，虽然你不会找到任何特别令人瞠目结舌的东西，但对细节的关注意味着没有两个区域相同，设计始终多样而好看。作为收尾，我们有一贯低调的配乐，用忧郁、严肃的曲调凸显情绪。那就值得开着听一次。

## 现在，把她从邪恶中解救出来

《银河战士 融合》在太多层面上满足了我。它不怕玩弄《银河战士》的公式，而且始终看起来、听起来、玩起来都很美妙。我甚至无法像往常那样抱怨中途存档！《融合》有中途存档，当你找不到存档点又需要突然停止游玩时，甚至还有一个休眠模式功能，无需关机就能节省电量——如果你需要溜进会议半小时，再完美不过……

如果我预期要抨击什么，那本该是《融合》的长度，但 Intelligent Systems 在这方面也没让人失望。我原本期待大约《超级银河战士》的长度，但通关时游戏内时钟显示 6:02，而且我确定它没有计算对话和过场序列，也没算我重玩关卡的时间。你可以在这个数字上再加几个小时。

我唯一能想出、值得批评的是 GameCube 联动功能。《银河战士 Prime》要到三月才在这里发售，所以在那之前没什么可做，除非你玩的是进口版；但即便有，GBA 这边也真的什么都没有——两个主要好处只适用于 Cube 版，比如通关后在《Prime》里解锁萨姆斯的融合装甲。

总的来说，这是我迄今最喜欢的 2D《银河战士》。我不愿说它是最好的，因为有些人会觉得它新的“与朋友同行”方式有些不像它的性格，但即便他们也很难否认它有趣；如果你在读完这篇评测的大部分时都在纳闷我到底在说什么，那么该开始学习了——出去给自己买一份《银河战士 融合》吧，它是 GBA 上最好的平台冒险。
