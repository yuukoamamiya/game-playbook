# BALL x PIT

![BALL x PIT 游戏头图](/img/reviews-webp/ball-x-pit.webp)

<ReviewTabs slug="ball-x-pit">

<ReviewTab site="ign" label="IGN">

> 来源：IGN（https://www.ign.com/articles/ball-x-pit-review）· 作者：Seth G. Macy · 发布：2025-11-06 · IGN 评分：9/10

我有一个全新、吞噬一切的痴迷对象，那就是《BALL x PIT》。我并没有打算把全部空闲时间都换成刷它这款 roguelite 版《打砖块》，但它对策略的倚重（外加一点点运气的轻吻），以及场上场下都诱人的升级路线，牢牢抓住了我大脑里原始爬虫的那部分，让我彻底荒废了其他一切文明活动。我上瘾了。事实上，自从几周前第一次打开它以来，《BALL x PIT》是我唯一玩过的电子游戏。我无法挣脱它那个令人满足的循环：跑一关、升级我的球、升级我的城市以解锁更多球，然后立刻再次投入。这是一种病，一种无药可医的病——说实话……我甚至不确定自己是否想从这场缠上我的疯狂中痊愈。我一直向所有人推荐它，而到目前为止，听了我的话的人总会回过头来告诉我同一句话：“你毁了我的生活，你这个疯子。”太棒了。加入我们吧。我们都在这里弹来弹去。

远远看去，《BALL x PIT》像是你在 TikTok 或 Reels 广告里看到的那种烂游戏。你知道那种：“我们正在玩评论区说是假的游戏 第 17 期”之类的。乍一看，它确实像某款想用游戏时长宝石或当下流行的什么掠夺性垃圾来钓住你的无尽跑酷游戏。但至关重要的是，它根本不是那种游戏：它完全没有微交易，而且在把你的时间一扫而空的同时，实际上还算尊重你的时间。它在每一关里发放令人满足的升级，然后给你机会在基地里积累更永久的力量。这里没有任何廉价或见不得人的东西。它让你觉得自己很强大，而不是被骗，即便每关都有 RNG 的成分，它要求的也是你充分利用每一次机会，而不是依赖愚蠢的运气或随机概率。当你通关一关时，那感觉像是你凭实力赢来的。

实际的玩法表面上看起来也直截了当：你的角色（一个或多个）在战场上向上推进，向一波又一波的敌人发射弹跳的球。球被武器化，敌人在这轮猛攻下被碾碎，最终你会抵达某一关独有的 Boss。这就是基本循环，但关键词是“基本”。因为朋友们，《BALL x PIT》要复杂得多。首先，可发射的球就有不同种类。比如你的初始角色“战士”，开局就带一颗特殊球，能施加一种“流血”状态效果，叠加起来会对后续命中造成额外伤害。击败敌人时，你还会捡到宝石用来升级，随后便可在该次流程中选择球和其他强化道具。

有些特殊球带有状态效果或范围伤害，有些会生成更多“小球”（怪怪的），还有一大堆其他选项。此外还有增益、被动效果、防御强化，甚至还有盟友会加入你的推进，输出伤害甚至治疗。有些强化道具比其他的强得多。比如“地震球”会在命中的敌人周围造成伤害，而且和大多数范围伤害球一样，升满级后会变得强得离谱。另一些，比如“可悲洋葱”，则挺烂的。乐趣的一部分，就是找出哪些升级在某一关里最管用，以及发现把某些球和“融合”与“进化”组合起来会发生什么——它们会进一步混合或改造球的能力。

> 当你火力全开、RNG 之神也眷顾你时，那是一场美丽的血洗。

融合可以简单地把两种效果塞进一颗球，从而省下一个槽位，但特定的组合反而有机会进化成一种新能力。比如，把“水平激光”和“垂直激光”融合，就会造出我个人的最爱“神圣激光”。它命中时会向垂直和水平方向射出纯粹的火焰死亡光束，同时造成范围伤害，既实用又帅得不行。

融合球既能提升你造成的伤害，又能腾出空间加入更多球，这点很酷。要记住所有可能性很难，但游戏里有一本百科，会显示你已解锁的组合。我已经玩了 30 多个小时，却仍有没找到的融合，我觉得这简直太令人兴奋了。

老实说，任何配置下的激光球都能造成巨量伤害，灼烧整行整列，有时还会叠加像辐射这样可堆叠的状态效果，同时还在造成普通而炽热的激光伤害。当你火力全开、RNG 之神也眷顾你时，那是一场美丽的血洗。激光、爆炸和效果不断炸开，伤害数字铺满屏幕，成排的敌人蒸发成经验宝石，还有你会在两次流程之间回到城镇里花掉的金币。

城镇是《BALL x PIT》的另一半，对培养你的角色极其重要。除了单纯游玩角色就能获得永久属性提升之外，建造某些建筑和角色住房也会提供增益和加成，而你想通过后期关卡绝对需要它们。但尽管它非常重要，《BALL x PIT》的城市建设部分却极其笨拙——事实上，在我认为除此之外堪称完美的这款游戏里，它大概是最糟糕的部分。

每当你完成一关，无论成功与否，你都会被丢回城镇界面，在那里用野外收集到的蓝图建造建筑。你还会建造资源地块：产木材的森林、产小麦的田地，以及产……好吧，产石头的石头。这些资源连同金币，都是建造和升级新建筑所需的。好在除了收获之外还有很多收集资源的方式，包括在流程途中、以及像采石场这样被动的建筑，但手动收集是最有趣的。

在收获阶段，你把已解锁的角色当作球来用，从棋盘底部瞄准，让它们像陀螺一样朝你想击中的东西冲出去。它们随后会从墙壁和建筑上弹开，从资源地块上收集资源，并升级你标记为待改进的建筑。这个过程很好玩，但也相当繁琐，因为为了优化摆放，你可以在收获前移动建筑，却并没有什么方便的办法来做这件事。

> 城市建设是这款除此之外堪称完美的游戏里最糟糕的部分。

我最后通常会把所有东西挪到地图一侧，然后再把一件件零件搬回那个特定时刻我想要的位置。看起来《BALL x PIT》似乎也意识到城市建设有多笨重，因为移动地块没有惩罚、也不消耗资源。我希望能有某种一键清空白板、不必逐个手动移除每栋建筑的选项，或者有个暂存区，让我在重新规划布局时临时放下建筑。

而你会大量地重新规划布局。建筑升级需要你的角色从建筑上弹跳多次，如果那栋建筑位于一个奇怪的位置，那就祝你能把轨迹调对、在收获阶段稳定地命中足够多次，而不用重组半个城镇。我常常只能把相关建筑挪到发射区附近，这意味着要把其他东西都挪走……然后在一切结束后再重新整理一遍。我一点也不喜欢这样。

这真的很扫兴，因为你没法真的无视它，城市布局对你关卡里的强大程度极其重要。有些建筑提供的增益会让附近其他建筑的效果更强，因此它们的摆放对你能否持续取胜至关重要。这种对精心规划的需求，和收获、建造、升级时不断来回搬地块的现实相互冲突。

不过，抛开建筑本身的问题，我确实很喜欢你的城镇建筑能直接作用于战斗这一点。你的城市越好，角色就越强；你找到的蓝图越多，新一趟流程的选项就越多。把一切搬来搬去也许很笨重，但结果是有意义的，有时还会令人意外，而且最终是一种正面的意外。

### 加倍投入策略

在游戏稍早的阶段，你会解锁一栋建筑，让你能带两个角色参战，而不是只有一个，给每次流程又添了一层复杂度和实验性。起初它几乎像是作弊，但没有它在功能上就不可能走得更远。我仍在摸索哪些组合好用、哪些纯属废柴。因为即使一趟失败，你依然会获得金币和经验，所以就算我选了个彻底的废组合也不介意，毕竟我还是有所进展。也有好几次，我以为自己搞出了一套神级组合，结果打到一关四分之三处才意识到自己犯了个可怕的错误。

最糟的一次，是我在第一关的新游戏+里把“战士”和“苦行僧”配在一起。“苦行僧”射出的球会撞向屏幕底部而不是顶部反弹，而“战士”除了是你初始角色之外没有任何特殊属性。第一关的 Boss“骷髅王”需要命中它后脑勺才能造成伤害。RNG 之神倒是给了我几个还不错的融合，但它们全都在它身前两条手臂之间无害地弹来弹去，让我几乎完全无效。偶尔一颗跑偏的小球会撞墙弹回、造成一丁点伤害，但我干脆故意输掉，好退出这一关。

尽管这很令人抓狂，它却恰好体现了《BALL x PIT》让我喜欢的一点：它几乎在每个方面都要求策略。提供给你的球和升级固然受 RNG 摆布，但你也可以选择用哪些、融合哪些、进化哪些。我能够根据角色的属性识别出好组合和坏组合，并在我推进每一关时，默默记下哪些搭配能满足我的具体需求。比如“杂耍者”会把球抛过敌人头顶——把他和“暗影”（其球从场地后方射出）配对，再走一条偏重范围伤害的升级路线，我就能清掉棋盘上几乎任何一排敌人，同时还能从后方弹跳的球那里获得大量伤害。

正是这种策略，加上懂得如何为某个具体关卡优化任何给定的角色组合，让我一次又一次地回来，直到双眼发花、疲惫不堪。当一切对齐、你横扫整片敌人时，当屏幕绝对被激光、爆炸和四散的小球填满时，你会感到一股巨大的力量。从旁观角度看，打磨升级、精心摆放建筑、再靠增益建筑频繁提升属性，似乎会让《BALL x PIT》随着时间推移变得越来越简单。但它做了一件罕见的事：它没有变得简单，而是让你感觉自己很强大。

当我终于在约 20 小时处通关主线、看完制作人员名单时，我立刻开了新游戏+。我从没这么干过。但那个完全无关紧要的剧情，对我来说只是《BALL x PIT》的一小部分。真正的快乐，来自积累你的力量与组合，并看看一趟流程中会解锁哪些令人欢喜的东西。我玩它是为了那些瞬间：音乐几乎被爆炸声和激光爆炸声淹没，或者我因为清空全场敌人而拿到金币奖励，然后又在一关里再来两次、三次，甚至五次。它挠到了我爬虫脑深处的一处痒。努力有回报，但正确的升级组合再加上一点运气，回报更大。

### 总评

《BALL x PIT》是我 2025 年最喜欢的游戏。即便有一个你没法忽视的笨拙城市建设阶段，它受《打砖块》启发的实际流程也极其好玩。每次坐下开玩、我发誓就快速来一两轮时，都会陷进“再来一局”的心态。对于一款简单的打砖块游戏来说，它的策略深得惊人，奖励聪明的事前规划甚于单靠 RNG 和运气。这是一款罕见的游戏：我在通关主线很久之后仍兴致勃勃地想玩，而且在很多方面，我希望自己现在就在玩它。如果你想让自己的人生被一款看似简单的打砖块 roguelite 彻底搅乱，我极力推荐它。

> 来源：GameSpot（https://www.gamespot.com/reviews/ball-x-pit-review-off-the-wall/1900-6418436/）· 作者：Alessandro Barbosa · 发布：2025-11-04 · GameSpot 评分：7/10（Good）

近 50 年前，雅达利发行了《Breakout》，它是对《Pong》弹球玩法的一种变体，对手不再是另一名玩家，而是一堵越来越密、缓缓向你压来的砖墙。不久后问世的《Arkanoid》在其基础上加以扩展，通过引入球拍升级、生成额外球等机制，给了玩家更多玩法。这两款游戏显然启发了《BALL x PIT》的设计师 Kenny Sun，但这款现代演绎并非只借鉴了它们两者。相反，《BALL x PIT》是一场令人陶醉的混搭，融合了《吸血鬼幸存者》、众多 roguelite 以及城镇经营的元素，包裹在一段沿无底深坑向下的迷人冒险中——它混乱又引人入胜，但在执行上也有点凌乱。

和它的灵感来源一样，《BALL x PIT》很容易理解。你扮演众多角色之一，每个角色都有自己的能力，向缓缓逼近的敌人一波波投掷球。你的球会在墙壁和敌人身上弹跳，对它们造成伤害并最终消灭它们，阻止它们到达底部伤害你。和《Arkanoid》一样，你会获得各种强化道具，以多种方式改变每次流程，为你的球注入新能力，给你更多造成伤害的办法。敌人也不再像过去那些彩色砖块一样静止不动，它们会向你发射弹丸，迫使你在狭窄的竞技场里一边移动、一边仍要准确瞄准你的攻击流。这一切都被封装在短暂却刺激的流程里，以弹幕地狱般的 Boss 战达到高潮，随后你带着奖励回到地面，再重来一遍。

如果说这套设定与《Breakout》和《Arkanoid》相似，那么《BALL x PIT》混乱的玩法则继承了《吸血鬼幸存者》。看似无穷无尽的敌人成群地朝你涌来，而你的攻击（可以选择自动开火）通过有限的升级选项迅速进化，以免被它们淹没。消灭敌人时，它们会掉落可收集的宝石，用来填充计量槽并最终升级。每次升级都会让你在三件物品中做出选择，分为两类：各种新球，或一系列带有被动能力的道具。

不同的球会极大地改变每一轮的打法。有些很直接：火球灼烧敌人，冰球冻结敌人，吸血鬼球把生命吸取给你。另一些更有趣，比如分别对整列和整行敌人造成伤害的垂直与水平激光，能生成更多小球的“母巢”，或者致盲敌人、提高其攻击落空概率的光球。被动能力也会改变你的玩法，帮你确定每次流程的思路。有些会让竞技场某几侧的进攻造成更多伤害，另一些则可能在球撞墙和其他敌人之前提供伤害增益。

不过，你每类只有四个槽位，而《BALL x PIT》的复杂度正是在这里开始浮现。在一趟流程的不同节点，你可以选择融合球，把它们的独特属性砸到一起，并为之后想加入的另一个球腾出宝贵槽位。进化则比融合更进一步，需要两种特定类型的球转化成一颗全新的球，后者既更强大、又带有新效果。例如，一颗燃烧球和一颗铁球（移动更慢但伤害更高）可以进化成炸弹球，它在命中时爆炸、造成范围伤害，但使用之间有很长的冷却。这些进化之后还能和你已有的其他球再次融合，或用正确的组合进一步进化。

这些融合与进化产生的互动，发现起来是一种享受。一颗通常只在一条线上打击敌人的激光球，现在可能带着注入的毒素在敌人之间剧烈弹射，确保它们在随后几秒里持续受伤。但因为这颗球同时还融合了卵囊，每一次命中还会生成几颗小球，而每颗小球又可能带有你早先融合进去的元素效果。这是一场令人满足的连锁反应，把每次流程开始时相对温吞的动作，变成一曲狂暴的效果交响，屏幕被爆炸和粒子填满，敌人在你面前融化。《BALL x PIT》的乐趣很大一部分来自试验它提供的所有不同球和能力类型，以及你会多快地从一趟流程缓慢温吞的开局，转变为其最终 Boss 那种失去理智的混乱。

不同的角色为每次流程注入变化，同时也挑战你用不同的策略去应对。我早期比较喜欢的角色之一是“悔悟者”，它的球每次弹跳都会增加伤害，而且在撞到竞技场后墙返回时还会造成额外伤害。另一些后期选项更复杂、需要一些谨慎，比如“嵌合者”的球在上升途中能贯穿敌人，但返回时不能，如果不小心，它们可能卡在成排的敌人后面。大多数新角色带出去跑一趟都令人愉悦，但也有例外——“思考者”会替你自动选择升级，就是个好例子，它糟糕且毫无协同的选择会让一趟流程感觉被白白浪费。名单上大多数角色都有一些怪癖，可能让你每次流程不像你希望的那样最优，但依然始终富有趣味。

当《BALL x PIT》让你把球、角色特性和能力串联起来、感觉自己像在把游戏玩坏时，它的动作性达到最佳：释放出能在极短时间内清空全场的组合，让胜利像是板上钉钉。它做到这一点，却没有完全牺牲挑战，而且和它的灵感来源很像，依然需要你仔细思考如何组合一手提供的升级。不过，失败有时会被拖长。偏重伤害的构筑有时清不动大群敌人，让那些缓慢向你挪来的密集敌墙像一场缓慢的死亡。反过来说，有些 Boss 非常肉，惩罚那些专注于快速清敌的构筑。它把最终遭遇拖长成一场惩罚性的消耗战，可能让一趟原本就在几分钟前还顺风顺水的流程，落得一个酸涩的结尾。

由于进度结构的设计，以及它与每个角色成长挂钩的方式，失败也在所难免。你用某个角色完成的每一趟流程都会让他升级，提供被动加成，让下一次流程稍微轻松一点。每个关卡还要求你用越来越多不同的角色通关，才能推进到下一关，这迫使你不断选择新角色。这无意中让节奏变得不均匀，因为你被迫用完全没有升级过的角色去挑战更难的关卡。虽然这从来不至于严重到彻底中断进度，但这项要求会给你的推进带来一些感觉纯属人为的减速带：你的技术不足以弥补伤害或血量确实不够这一现实。好在流程很少超过 15 分钟，但依然令人沮丧。

roguelite 元素在流程之间引入，具体说就是当你回到地面时。在这里，你要在网格上扩建一座小城镇，放下用于不同资源的方块（如小麦、木材和石头）以及各种形状和大小的建筑（解锁新角色并提供永久属性加成）。你解锁的每个角色也住在这里，并会用于每趟流程之间那次唯一的收获阶段。这就需要你把角色瞄准城镇、像球一样发射出去，每颗都会在弹跳时从碰到的资源块上抓取资源、并协助你正在施工的每栋未完成建筑。

由于每趟流程之间只有一次机会，你会被鼓励频繁重新布置城镇，为角色找出最有效率的行进路线，仔细预判他们的运动轨迹。即便这么小心，也很容易算错，让一次跑偏的弹跳浪费掉整趟收获，使你无法带着新角色或强化属性进入下一趟流程。这是一项乏味的任务，却又是进度中不可避免的一部分，阻碍你回到《BALL x PIT》最精彩的部分。

《BALL x PIT》最闪耀的时候，是它放你去对付前方敌人，并给你工具去调配出你自己品牌的、填满屏幕的不可阻挡的混乱。当你用几分钟填进成千上万的击杀、伴随明亮爆炸和令人眩晕的粒子效果时，从一趟流程进入下一趟很容易。但你的势头也可能被其间至关重要的城镇经营时刻频繁打断。因此，《BALL x PIT》战役的推进可能显得不均匀，但这也容易忽略——因为你开启的大多数流程，都同时具备带来惊喜和愉悦的潜力，且变化足够丰富，让你在游戏的最后几个小时里的干劲，和头几个小时一样令人咧嘴而笑。

### 评测结论

**评分：7 / 10 — Good**

**优点**

- 深度十足、引人入胜的动作，简单易懂，却有着令人满足的深度
- 球与能力的组合奖励仔细思考，带来狂野、有时难以预料的结果

**缺点**

- 肉得不行的 Boss 可能与前方的要求显得矛盾，不公平地惩罚那些在此前一直有效的构筑
- 为了确保稳定推进而不得不频繁重新配置城镇，是一项无法逃避的杂务

> 来源：Eurogamer（https://www.eurogamer.net/ball-x-pit-review）· 作者：Christian Donlan · 发布：2025-10-15 · 评分：4/5

Kenny Sun 的新作是对雅达利经典的一款时髦新演绎——而且它超棒。

### 评测

《BALL x PIT》（接下来我会叫它 Ball Pit，因为那个 x 超出了我这颗脑袋和打字手指的承受范围）（编者注：只要我拦得住，休想！）是 Devolver Digital 最新的 roguelite。但它也是 Kenny Sun 的最新作品，一位我断断续续关注了很久的开发者。

- 发行商：Devolver Digital

- 开发商：Kenny Sun

- 平台：在 PC 和 Switch 上游玩

- 发售：现已登陆 PC、PS5、Xbox Series X/S 和 Switch。今年秋季登陆 Switch 2。

Kenny Sun 做的游戏似乎都建立在深深的痴迷之上。有一阵子，他真的、真的痴迷三角形，而那些三角形催生了一些很棒的游戏。现在，看样子他迷上了《Breakout》，结果是一款既非常复杂、又彻底简单的游戏。要我说，这是最好的那种游戏。

《Breakout》是雅达利的老玩意儿，把《Pong》变成了 PvE 体验。你有一个球在那儿弹来弹去，用它击碎成排成列的方块来得分。《BALL x PIT》把这一切拿来，变成了更当下化的东西。你选一个英雄，在屏幕上的一条通道里向上推进，而一排排方块状的怪物在你上方生成、朝你逼近。你朝它们扔出一堆球，慢慢把它们磨掉，如果有谁抵达底部，你就会受到它们的伤害。这就是它最简单的样子。

而在它最简单的形态下——不知道这是不是只有我这么觉得——感觉像是被困在排字工的奶酪梦里。这些推进的排排方块，在我眼里像是字体块，你必须在自己被从屏幕上抹掉之前把它们全部清掉；而在我能感觉到的某处，印坏的纸张正在堆积。即便你不这么读解，那种在东西压倒你之前把它们砸成碎片的紧迫感也很动人。这是一个用来搭建其他东西的、令人兴奋的基础。

《BALL x PIT》就是在这里变得复杂的。当你通过瞄准球、把它们甩过屏幕来击败敌人时（顺便说一句，这些都可以自动完成，你只需为射击瞄准那个带角度的准星，并移动你自己的角色），你会收集被击败敌人掉落的经验宝石。每隔一阵你就会升级，此时你可以选择一项新技能或能力。

这些通常是新类型的球——比如元素球，或者从击败的敌人身上吸取生命的吸血鬼球，又或者命中时射出水平或垂直激光束的球；不管怎么运作，它们都是一群好家伙。有时则是能力或其他点子。比如我最喜欢的能力之一，能让你击败的所有敌人爆炸，伤害它们两侧的敌人。另一个会在你的攻击从某个特定方向命中时附加暴击伤害。还有一个会时不时召出一个小石人，沿轨道朝你的敌人隆隆滚去、造成一点伤害。再有一个是炮台。你懂的。

这都很棒。但你只有四个槽位来放不同类型的 power，而随着你升级，这些槽位很快就被填满。这时事情就从复杂变成了令人眩晕的复杂。你可以捡起死去的敌人掉落的另一些小东西——旋转的小球——它们要么让你一次性升级一堆现有能力，要么以各种方式把它们合并在一起。

这不仅催生了迷人的新造物——造成流血伤害的激光束、带着闪电追击者的地震——还重新腾出了槽位，因为你把两个 power 变成了一个怪咖 power。这意味着你可以再次收集新能力，而到每趟流程结束时——各关都有主题，末尾有几个小 Boss 和一个大 Boss——你每走一步都会喷出彻底的混乱。

这一切，对吧，而它仍然是《Breakout》。也就是说，没错，当你在应付吸血鬼球、移动缓慢但伤害更高的沉重铁球，以及你的变异所烹出的任何其他东西时，你依然可以运用《Breakout》高手的严谨打法。把你的攻击甩出去，让它们沿通道侧壁弹起、再在敌人身后乒乓作响，你就能在攻击推进大军正面的同时，对它的后背造成大量伤害。

当伤害不断冒出来、效果不断炸开、屏幕不断闪烁时，那就像在看体育场演唱会的人群。你可以选择让这类攻击更强的能力，但也可能陷入麻烦，因为你的弹药会一直在外面没完没了地乒乓，没能回到你身边以便在其他地方重复使用。

再加上那些不同的关卡主题——沙地、冰面之类；真菌关简直是个灾星——然后再加入你能解锁的不同英雄，他们都会改变你处理事情的方式。其中我最喜欢的，是一个会替你做出所有升级选择的角色。感觉像是《漫威终极逆转》里阿加莎·哈克尼斯的一点东西溜进了这款游戏。我第二喜欢的是一对双胞胎，他们的力量减半、武器却翻倍，而且两人的瞄准互为反向。（我最不喜欢的那个，过几天大概就会变成我最喜欢的：他们从队尾的位置发起攻击，同时在前方四处移动。天哪，他们太难摸透了。）

### 无障碍选项

切换屏幕震动和手柄震动。手动激活升级界面、允许更慢的游戏速度、在像素字体和高清字体之间切换、禁用旋转背景和闪烁颜色。

这，深吸一口气，就是《BALL x PIT》的一大堆内容。一间造成伤害的实验室，而且，和 roguelite RPG 常有的一样，也是一间自我的实验室：这一趟我想成为谁。但还有更多。这涉及你在流程之间做的事。回到家，在坑的顶端，你可以花掉流程中收集的资源，建起一座小镇，种下庄稼、放下你解锁的任何建筑，它们或许会给你的角色属性加成，甚至解锁新角色。这座小镇必须通过派出小农夫来收获，他们运作起来就跟你流程中使用的武器一模一样，在墙上弹跳、一路收集谷物和岩石、并建造建筑。无论从哪个角度看，这都是《Breakout》。

这游戏真是可爱的东西。又是 Kenny Sun 的一份喜悦，也是他第一回有团队一路同行。它有时可能有点肝，尤其是在解锁新的流程地点时，但如果你是那种喜欢尝试不同构筑和不同力量进化的人，那这种肝就不算肝。这是最好的那种精巧的、做白日梦般的乐趣。我觉得，进来玩吧。
