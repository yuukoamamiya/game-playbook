# 巫师3：狂猎－血与酒

<ReviewTabs slug="the-witcher-3-wild-hunt-blood-and-wine">

<ReviewTab site="ign" label="IGN">

![巫师3：狂猎－血与酒 IGN 评测头图](/img/reviews-webp/the-witcher-3-wild-hunt-blood-and-wine.webp)

> 来源：IGN（https://www.ign.com/articles/2016/05/25/the-witcher-3-wild-hunt-blood-and-wine-review）· 作者：Leif Johnson · 发布：2016-05-25 · IGN 评分：9/10（amazing）

我们被告知，《巫师 3：狂猎》的《血与酒》资料片标志着利维亚的杰洛特最后一段伟大的旅程——至少就开发商 CD Projekt Red 而言是如此。我倾向于认为有迹象表明并非如此，因为它的大部分剧情都围绕一位被认为早已永远失去的朋友的归来展开。但即便它真是如此，这也已是我们所能期望的最好的送别了。这里的阳光或许比布拉维坎的屠夫以往任何时候都更明亮，在先前作品绝望的洪流中失落的一丝希望在此涌动，但恰如其分的是，在这一切之上，这是一个关于放手的痛苦的故事。

这个资料片的大部分力量，来自它如何干净利落地与《巫师 3》其余部分划清界限，在从留言板接下相关任务的那一刻之后，就把我们远远送出威伦的尸堆和史凯利杰的灰暗阴郁。目的地是陶森特，一片可爱的地方，起伏的丘陵铺满葡萄园，沐浴在仿佛能驱散忧郁的温暖阳光中。这是一次聪明的转换，因为它避免了杰洛特本该忙于处理该地区更大事务（如《石之心》中有时出现的情况）所带来的愧疚感。在阳光明媚的陶森特，杰洛特只是一位著名的猎魔人，头顶没有拯救世界的紧迫需求，就一部资料片而言，故事因此变得更好。

我承认我起初有些担心它过多地陷入插科打诨。陶森特的原型是法国南部，还没过一小时，就有一位色彩鲜艳的骑士对着一个巨人大喊他要把他剁成“肉酱”。故事中满是拿葡萄酒鉴赏开涮的笑料，甚至有一位侍酒师能凭污渍在几秒内嗅出一款具体葡萄酒的准确年份。法国骑士传统也遭到揶揄，当我得知一场围绕一块绣有 D.L.C. 缩写字母的手帕的大动干戈时，我翻了翻白眼。有一小段时间，我觉得想告诉大家别去陶森特——对这样一个阴郁严肃的角色来说，那地方太傻了，没法茁壮成长。

> 安娜·亨利叶塔女公爵体现了陶森特本身的复杂性。

但在这段大约 20 到 25 小时的冒险的头两个小时内，我就爱上了这个地方。它向我们展现了杰洛特世界的另一面，也表明 CD Projekt Red 依然能在不过度依赖厄运与阴郁的情况下讲好一个故事。尽管陶森特大约只有威伦的无人之地那么大，如今回到诺维格瑞和史凯利杰却感觉像是被流放。赢得我欢心的不仅是那座被雪顶群山环绕的如画城堡，还有那强大的角色阵容。有一个脾气急躁的擦鞋男孩，他从不错过在每一次对话中捞一笔的机会；有杰洛特那位迷人、新近归来的朋友，我在此不予透露；还有一位狡黠的年轻女子，她的怨恨可能就此终结陶森特相对而言的幸福。但最让我着迷的，是陶森特的安娜·亨利叶塔女公爵。她体现了陶森特本身的复杂性，和平时身披华服，需要时则英勇而自信地战斗。

对这样一个阳光与痛饮葡萄酒之乐的故事来说有点出人意料的是，这主要是一个关于吸血鬼的故事。总体处理得不错，即便主要反派从未像围绕在他身边的那一大群角色那样被有力刻画。他给人的印象是个任性却强大的白痴，而他唯一一次真正的复杂时刻，也随着他脱离实体形态一同迅速消失。他主要的作用是让杰洛特那位归来的朋友更具复杂性。事实上，吸血鬼的框架主要充当背景，衬托两个好人挣扎着为自己对固执的朋友和家人的感情、以及这些关系给其他人带来的后果寻找正当理由。

然而其中的传说设定非常迷人。故事带我们深入《巫师》创作者安杰伊·萨普科夫斯基对吸血鬼那种古怪而迷人的诠释，并在故事看似接近尾声时通过引入新的转折来维持势头。它精彩地礼赞了我们迄今为止所熟知的多姿多彩的《巫师》体验，无论是意料之中的战斗、化装舞会上的闲谈，还是好人杰洛特解除古老诅咒，甚至与大灰狼一决高下。

> Boss 战总体上强调迅捷和谨慎的战略思考。

和《石之心》一样，这里的 Boss 战总体上强调迅捷和谨慎的战略思考，这再次标志着相对于本体游戏中可预测的斗殴的一种受欢迎的转变。（埃瑞汀，说的就是你。）我最喜欢的其中一场，是与一只巨大的滚动岩石生物进行的锦标赛式战斗，它试图在一个没有任何遮蔽物的小竞技场里把我砸扁，因此要求我进行数次时机精准的闪避。

《血与酒》为《巫师 3》带来的色彩并不局限于风景。有时它是字面意义上的，比如杰洛特可以用在猎魔人套装（但遗憾的是，不能用在其他任何东西上）上的外观染料。这是件小事吗？也许吧。但对像我这样，即便一套本来不错的护甲看起来像不搭调的垃圾就不肯穿的人来说，这意义重大。染料也让我以新的方式欣赏那些我本就喜爱的部件。就拿熊学派护甲来说；泼上一抹浓郁的红色染料后，我感觉自己像是《权力的游戏》里拉赫洛的某种审判官。

《血与酒》还让我们认识了身为有产酿酒商的利维亚的杰洛特——他在早期收到了一座破败的葡萄园庄园（住着一些似乎完全不知道他才是老板的农民）。这是那种我个人不介意退休养老的地方，但平心而论，对利维亚的杰洛特——了不起的怪物杀手、萝卜的骑手——来说，这似乎有点不符合性格。我用这样一个想法来调和：这个资料片代表着杰洛特某种意义上的退休。实际上，翻修它提供了一个绝佳的地方来展示杰洛特的护甲和武器，而不是把它们塞进箱子里，也是一种用金币换取额外加成的方式。比如一张床能给杰洛特活力；翻修过的马厩给萝卜更多耐力。甚至还有一个种草药的花园，以及一个能分解突变的炼金实验室。这些都构成了时不时回来看看的绝佳理由，但我确实感到遗憾，除了决定掏钱修缮这栋或那栋建筑之外，几乎没有任何选择余地。

这还没算上所有新武器、护甲，以及像一套新的史凯利杰昆特牌这样的好东西，它们为资料片画上句号，其中还包括带有套装加成的大师级制作套装。这些套装加成往往甚至出现在你找到的非猎魔人专属套装上，比如我个人最喜欢的吸血鬼重甲套装，只要我穿着六件中的至少三件，它就能提供巨额的近战抗性，并在每杀死一个敌人时恢复活力。

> 这个资料片还带来了突变，它们（终于）解锁了新的技能槽并提供副作用。

这个资料片还带来了突变，它们（终于）解锁了新的技能槽并提供副作用，比如一种能在战斗最初几秒提升攻击力和法印强度的。这 12 种突变能极大地改变《巫师 3》战斗的风味，无论是让敌人在你以暴击杀死他们时爆炸，还是让致命一击有几率使杰洛特回复到满血。

所有这些东西本可能让早期故事和战斗变得无足轻重，因此突变的针对性很明智：给进入更高难度的新游戏+玩家提供优势。正因如此，在等级达到 33 左右之前，你甚至无法在《血与酒》内容中立足，所以游戏前期依然具有挑战性。（如果你想跳过这一切，用一个全新的 35 级角色直接进入，也可以。）不过，随资料片一同发布的一个补丁将为所有人带来用户界面的改进，包括一个早该有的、让你一捡起新书和信件就能阅读的选项。

我确实希望我们还能再有至少一个资料片，但《血与酒》的新增内容帮助补强了《巫师 3》为数不多的几个薄弱点。这是告别杰洛特的好方式。但这并不意味着我不会想念他。

### 总评

《血与酒》为利维亚的杰洛特的传奇画上了风光的句号，带来一个关于迷人吸血鬼与麻烦友谊的故事，背景设定在一片令人惊叹的新风景中，与我们迄今所知的阴郁截然不同。这个资料片还带来了一些受欢迎的游戏性增强，包括突变、给护甲染色的能力，以及一座种植草药的葡萄园。最重要的是，它让杰洛特停在一个好的位置。

## 《巫师 3：狂猎》—《血与酒》评测

痛苦与狂喜。

“你能闻到那些娇嫩花朵的香气，”女公爵对利维亚的杰洛特说，而在那一刻，你也许会相信自己真的能闻到。和本体游戏一样，《巫师 3》的最终资料片《血与酒》有一种把感官愉悦表达得如此充分、如此丰富的方式，以至于你会被说服，相信自己真的感觉到雨水倾泻在脸上，或一只蚊子在你耳边嗡嗡作响、恼人地挠痒。说《巫师 3》在观感与听觉上依旧如此华美并不令人意外，但《血与酒》的视觉效果比本体更大胆、更鲜艳。有时，陶森特这片广阔的新区域仿佛是从童话书页上倾倒在屏幕上的——而取决于你的选择，你可能会真的发现自己被拉进这样一个故事里。

《血与酒》有时在主题上和它的前作一样黑暗。以吸血鬼为核心的主线故事探讨了这些生物与生俱来的嗜血欲望，以及它们的其他怪癖与激情，相关场景以《巫师》一贯的传统风格呈现出戏剧性与令人不安。然而，与《巫师 3》其余部分相比，《血与酒》更明亮、更欢快，淡化了忧郁，把幽默推到了前台。这并不是说这个系列从不搞笑；事实上，它一直拥有一种刁钻的机智。然而，幽默从未如此无处不在、如此直白。你也许会在寻找一尊雕像丢失的睾丸时，路过听到一位当地人低声哼唱《老鹰之歌》，或者当你注意到对发行商 CD Projekt 旗下数字商店 GOG.com 那些毫不隐晦的影射时，会多看两眼。

这种自我指涉的幽默在一个涉及致幻蘑菇的支线任务中达到顶点，不过细节我最好还是不要透露。只需说，开发商 CD Projekt RED 毫无顾忌地拿自己的小毛病开涮。不过我不能说这些影射总是对《血与酒》有利。我本想置身其中的那个奇幻世界，太频繁地让我想起我实际居住的世界。也许如果《血与酒》的主线故事和角色更吸引人，这些影射就不会那么令人分心，但杰洛特的新同伴中没有一个能比得上叶奈法那炽热的神采，或血腥男爵那残酷的悲伤。这个宇宙里的矮人往往是银行家——但在《血与酒》里，这几乎成了他们扮演的唯一角色。因此，游戏中最无聊的任务让你陷入一家矮人经营的银行里一堆财务繁文缛节之中，也就合情合理了。而它对这个任务自身乏味之处的会心影射，也没能让它变得不那么无聊。

别误会：这些细节之所以容易被挑刺，只是因为《巫师 3：狂猎》是一款如此惊艳的游戏，任何够不上非凡的东西都注定会因“仅仅”优秀而显得扎眼。我怀念老角色阵容的多样性——陶森特主要居住着普通人类——但我仍然被当地民众的争吵与压力卷了进去。家庭戏往往处于最前沿（这是《血与酒》中“血”的几层含义之一），无论那个家庭是一群崇尚暴力的兄弟、彼此疏远的姐妹，还是一对即便在死后仍继续鸡毛蒜皮争吵的夫妻。然而，最出色的任务是那些从离奇谜团开始、讲述最凄凉故事的任务。一个收集了数千把勺子的生物，你该如何看待，而面对折磨它的诅咒，最好的应对方式又是什么？一棵树怎么会流血，而当地一位女巫在其中又扮演了什么角色？

由这些任务衍生出的战斗场景同样引人入胜。《血与酒》一开始就定下富有挑战性的基调，让你和一群友方骑士对抗一个冲锋的巨人，而即便你以建议的 35 级进入资料片，你也可能发现这场战斗比预想的更吃力。陶森特迎来了一连串怪诞而美丽的生物，它们准备不惜一切代价自卫。其中一些桥段变得重复——游戏到底需要多少场对那种喷脓植物的可预测战斗？——但大多数不仅本身有趣，而且由于它们与周遭冒险交织在一起而更添一倍的乐趣。例如，在一个任务中，你陪同一位类似摄影师的人踏上探险，为当地野生动物编目。这是用你的猎魔人感官侦察、保护你的伙伴免遭掘地蜈蚣侵袭，以及参与《血与酒》中令人愉快的闲聊的绝妙混合，这一切最终以一个关于孔雀的可爱又难忘的桥段收尾。

《血与酒》的新突变系统就是为了至少缓解一部分挑战而存在。它提供了一系列额外的被动加成，还解锁了新的技能槽。（为此感谢火焰吧。）你可以跳过揭示这个系统的支线任务，但我不建议这么做，免得你把技能点浪费在不想用、又没有槽位可放的技能上。不过，这项新增确实有一点平衡性问题。《血与酒》在你启用那个给阿尔德法印附加冰冻效果的技能后，就从一段恰到好处的挑战性冒险变成了某种闲庭信步。我承认，当一群强盗被你手腕一甩推开、其中一些当场冻住碎裂时，这更加令人愉快，但当这样的力量就在你指尖时，最终战也少了几分刺痛。（不过，无论从机制还是视觉角度来看，我都无法否认那些战斗的巧妙。）

另一项值得注意的新增是杰洛特的庄园和葡萄园，你可以花上一点金币购置新床、武器架和其他杂物来升级它。总的来说，葡萄园是个次要元素，但它又一次给了你欣赏《血与酒》非凡细节把控的机会。你可以为你葡萄园出产的葡萄酒命名，然后在投入生产后拿起酒瓶痛饮。取决于你早先的选择，你也许会招来一位意想不到的员工作为员工来安排膳食，让一个原本不相干的任务多了几分情感分量。

葡萄园在主题上也很贴切，体现在两个截然不同的方面。首先，陶森特是葡萄酒之乡，所以杰洛特以这样一座庄园为据点也就顺理成章。然而更重要的是，葡萄园是对杰洛特冒险的纪念，整个《血与酒》也是如此。一位艺术家为杰洛特画肖像；你参加一场锦标赛，也许是在一面代表着一段几乎被遗忘的过往的纹章下；你和你的总管举杯自酿的葡萄酒庆祝你的成就。这些都是致敬之举，是对一位英雄的送别。而且别搞错：《血与酒》把杰洛特视为英雄，而不仅仅是一个受雇的怪物猎人，无论你为自己的酬劳讨价还价得多厉害。葡萄园象征着这位即将退休的猎人，他留下的不只是一堆狮鹫内脏，而是一段在陶森特整个文化中被反复提及的传说。

当然，杰洛特配得上被称为传说，尤其是因为他主演了有史以来最伟大的角色扮演游戏之一。也许我们还会在另一场冒险中与他相聚，但如果《血与酒》是白狼在游戏中的最后一次登场，他至少是风光谢幕。我会想念你，杰洛特——你那完美得不可思议的头发、你那唯利是图的性情、你那面对骇人罪行和难以言说悲剧时的坚忍态度。如果你和萝卜必须策马驶向夕阳，那么我很高兴我们共度的时光如此令人着迷。

### 评测结论

**评分：8 / 10 — Great（优秀）**

**优点**

- 一整个游戏量级的诱人探索
- 充满艺术与主题上的风采
- 许多精彩、节奏得当的任务
- 谜团、恐怖与幽默之间引人入胜的平衡

**缺点**

- 自我指涉的笑话可能令人分心
- 主线故事和角色没那么有趣
