# 超级马力欧 阳光

![超级马力欧 阳光 游戏头图](/img/reviews-webp/super-mario-sunshine.webp)

<ReviewTabs slug="super-mario-sunshine">

<ReviewTab site="ign" label="IGN">

> 来源：IGN（https://www.ign.com/articles/2002/08/22/super-mario-sunshine）· 作者：Fran Mirabella III · 发布：2002-08-22 · IGN 评分：9.4/10

说到他的名字，你不可能不想起电子游戏。他不仅是任天堂的吉祥物——他是整个行业的偶像。他闻名全球，之于电子游戏，就像米老鼠之于动画。我们甚至还没提到他的名字，你就已经知道了：马力欧。很难想象拥有一台游戏机，却不知道这个史上最具影响力的系列之一。大多数玩家都是伴随着这位意大利水管工长大的，并因这个系列一贯的品质与标志性特质而心生敬意。马力欧走到哪里，众人便追随到哪里。他引领许多人进入 2D 横版卷轴的世界，又义无反顾地大胆踏入复杂的 3D 领域。我们信赖名牌，而马力欧凭借这份明星号召力始终领跑。如今，在阔别近六年之后，他又带着一段全新的冒险回来了，按度假主题姑且命名为《超级马力欧 阳光》。不过，自从他革命性的 3D 首秀以来，这位业界的老朋友已经错过了太多。次世代技术与游戏设计惯常的演进，催生了大量令人印象深刻的作品。从科乐美白金销量的《合金装备》系列，到 Rockstar 火爆异常的《侠盗猎车手 III》，行业已经改变。任天堂的马力欧系列曾孕育出蓬勃的玩家文化，如今许多人即便长大成人，也仍无法把手柄从手中拿开。

念及于此，我们不得不问：马力欧是变成了过气的潮人，还是仍具备再次俘获数百万人的本事？在花费无数小时体验这款全新的平台冒险之后，我们有了答案。《阳光》就是我们玩过最好玩、制作最精良的 3D 平台游戏。它绝非完美，但乐趣至上，以我们的标准看，任天堂交出了它多年来最出色的作品之一。

### 特色

- 任天堂的吉祥物终于携一场全新冒险在 GameCube 上登场
- 玩法让马力欧踏上清理岛屿、洗清罪名的旅程
- 基础操作沿袭《超级马力欧 64》奠定的框架——蹬墙跳、三连跳，以及经典的臀部重压砸碎敌人
- 得益于绑在马力欧背上的全新水枪，带来全新的操作机制与动作——悬停、喷射、滑行、喷洒
- 自超级任天堂以来首次可操作，耀西可作为马力欧的坐骑解锁
- 视觉上独一无二，有鲜艳的 3D 梦幻景致，以及经典的马力欧外观
- 充分挖掘 GameCube 的机能，呈现超大的绘制距离、实时反射、水体折射、精细的粒子效果与流畅的动画
- 马力欧的多功能水枪能解锁秘密区域，也是击败 Boss 的关键
- 长达 25 小时以上的流程
- 最多可收集 120 个“闪耀”，重玩价值极高
- 为高清电视用户支持逐行扫描 480p
- 音响爱好者可享受真正的杜比 Pro Logic II

### 玩法

马力欧在 1996 年凭借 Nintendo 64 上的 3D 首秀完成了最大的一次飞跃。当时，它被许多玩家视为必备的平台游戏，与主机同步发售，卖出数百万份。然而，他从 2D 到 3D 的转变，让一些忠于横版卷轴玩法的玩家感到失望。马力欧系列的重点是从一个平台跳到另一个平台，但复杂的镜头控制以及当时令人望而生畏的 3D 环境，在粉丝之间划出了分歧。大多数人留在了他身边，但也有人几乎彻底抛弃了这个系列，只偶尔随意玩上几局。无论你属于哪一边，如果你对《超级马力欧 阳光》感兴趣，有些事显而易见却又必须明白。它是《超级马力欧 64》风格的延续。关卡设计、操作机制与玩法概念都得到了精心打磨，但它并非一场革命性的作品。正如这个传奇系列的缔造者宫本茂反复指出的那样，它更多是“演进而非革命”。如果这正合你口味，那么《超级马力欧 阳光》就是一套你不该亏待自己的度假套餐。如果不是，这位意大利水管工的魅力仍有机会征服你，但你最好仔细考量它的优缺点。

这段最新冒险的构想是：马力欧与碧姬公主终于要离开总是麻烦不断的蘑菇王国，好好度一次假。只是他们很快就发现，度假目的地的小岛上正乱作一团。一个罪魁祸首用黏液和颜料涂满了整个世界。更糟的是，据当地人说，他偏偏长得像马力欧。本该度假的行程，结果又成了马力欧工作的一天。被误认成真凶的他被定了罪，并被勒令用一台绑在背上的喷水装置清理整个世界——而这台装置恰好为惯常的平台动作增添了全新的深度。度假的点子很新颖，但也带来了一些牺牲。我们一直以来所喜爱的角色和标志性美术风格大多被移除了。取而代之的是大量新的、相当缺乏感染力的角色设计，以及海滩主题的视觉。有人或许会辩称，这应当被欣然接受为一股新鲜血液，但我们不这么认为。马力欧很大程度上关乎怀旧，虽然这种元素仍在，却并不浓厚。森林、水、冰与熔岩主题世界交织的那种搭配，被深深地怀念着。在这方面，任天堂仍未完全找回《超级马力欧世界》的伟大。

不过，我们最终得到的，是一个极具说服力的度假胜地。从城镇出发，马力欧很快发现这里是通往岛上其他区域的枢纽世界，包括一处依山傍海的海滩、一片高耸崖壁环绕的海湾，甚至还有一座游乐园。这些加勒比风情的场景宏大而美丽，设计得如此出色，常常让人笑逐颜开。

如果你还没读过我们的专题报道、想进一步了解各个世界，请务必查看我们的游戏页面获取详尽解析。只需点击马力欧的视线，就能一探究竟。

第一个真正能让你沉浸其中的关卡，把你带入一个地势相当低平的世界，那里用绷紧的绳索把风车与住宅区串联起来。弹性绳索的加入是其中最强有力的点子之一。这些富有弹性的绳索随处可见，并鼓励你尽可能多地使用它们。一旦尝到把自己高高弹向空中的滋味，你就不想再落下来了。而这仅仅是马力欧世界新增内容的一个开始。迄今为止，他的背包在游戏中扮演着最具创新性的角色。它简化了整个平台跳跃的概念，同时又增添了全新的操作深度。你再也不必在只有一次机会的情况下，祈祷着跳向下一个平台、把马力欧的影子与地面对齐。背包有若干不同功能，其中之一能推动马力欧向上，让他在身下水柱喷射时悬停。于是，你可以在半空中止住下落，试着让马力欧稳稳飘落到平台上。诀窍在于，喷流只持续很短的时间。你会有机会纠正失误，但这依然需要技巧。

同样值得注意的是，虽然第一个关卡让你待在某种舒适区里，但后续关卡的难度会迅速攀升。一旦你习惯了在绳索上弹跳、贴着地面行动，《阳光》便会把你抛进垂直高耸入云端的平台跳跃天堂。单是抵达最高点而不带任何目标，就能给你一种成就感。如果你担心游戏目标太少，别怕。马力欧有一大串待办事项。除了枢纽世界和最终第七关之外，还有六个主要世界，每个都包含八个不同的故事。每完成一个故事，马力欧就会获得一个“闪耀”，大致相当于我们在系列前作中早已习惯的星星系统。最终目标是收集足够的闪耀，为这座古朴的小岛恢复一些光明，并最终恢复和平。每个故事的任务差异很大。你将迎战巨大的 Boss，闯过布满障碍的平台跳跃梦魇，甚至还要花些时间用成加仑的水把大地冲洗干净。

你正在玩《超级马力欧 阳光》吗？这里有完整的《超级马力欧 阳光》攻略与通关指南，涵盖游戏中所有任务和金币。

当然，八个故事的设定也带来了一些固定套路。其一是红币收集任务，它们通常会让你做出相当惊人的操作；其二是那个旷日持久的任务——追着假马力欧满关卡跑，用水把他喷倒。我们最喜欢的常备要素之一，是马力欧几乎在每个关卡里都会发现的隐藏秘密世界。当他跳进一根看似无害的管道或洞口时，常常会发现那是假马力欧设下的陷阱。马力欧的背包被偷走后，悬停带来的缓冲就没了，你必须在好一阵子里用老派方式做平台跳跃。那些玩具箱主题的关卡可爱又复古，令人怀念，甚至还有经典马力欧主题曲的无伴奏合唱版本。同样令人满足的是，它们带来了相当大的挑战。大到每个关卡都藏着至少一条额外生命，你每次尝试都得把它捡起来。这样的秘密关卡大约有十几个，你甚至会发现有些巧妙地藏在枢纽世界里。得益于它们的复古风格和纯正的平台跳跃，这些体验会成为你游戏中最钟爱的部分之一。

在所有这些出色的关卡设计之外，任天堂再次超越了自己和业内其他公司，拿出了市面上最扎实的操作机制。公司深知，用户与电视屏幕所见之间的关键纽带就是操作。马力欧身上那种惯性、摩擦力与精准操控的感受令人难以置信。再配上比以往更多的动作，你会很容易在世界里跳来跳去地自娱自乐。它就是“手感好”，无论你对细节的关注理解到什么程度，你都能欣赏它，因为这是一种触觉上的体验。蹬墙跳、三连跳、后空翻和臀部重压都从《马力欧 64》回归了，而随着水背包及其两种附加功能的加入，游戏推进过程中还有更多动作等待你发掘。有些纯粹是为了好玩，但大多数都以某种方式派上了用场，让你在任何情况下都能随机应变。这种纯粹的多样性，让你能以许多不同方式游玩《阳光》。

遗憾的是，当你考虑到《超级马力欧 阳光》并没有一个革命性的镜头系统、甚至连演进式都算不上时，上述所有乐趣都可能戛然而止。任天堂把镜头控制很大程度上交给了玩家。大多数情况下，玩家可以用 L 键把镜头居中到身后，但设计中有很大一部分要求你不断使用 C 摇杆。镜头可以拉近拉远，并围绕马力欧 360 度旋转。本质上，你必须成为自己的智能镜头，这大概是玩家们面临的最大学习曲线。老练的玩家能够驾驭镜头，但我们担心，对休闲玩家而言这需要大量练习。这是一块很大的绊脚石，而且相当令人失望：五年前开创这片 3D 疆域的任天堂，居然没能找到更好的解决方案。唯一聪明的补充，是当马力欧移动到物体后方时能看见他的剪影。这确实有帮助，但它更像是在你调整镜头时用来追踪他的权宜之计，仅此而已。更令人失望的是，任天堂设计了一些目标，在这些地方镜头绝对地、令人抓狂地糟糕。你几乎会觉得，有些区域根本没人做过游玩测试，因为镜头会被墙壁卡住、困在墙后而猛地翻转。好的一面是，优点远远盖过缺点。只要加以练习，你就能设置出足够多的聪明视角，助你完成冒险。镜头糟到让你无法行动的情况极为罕见。

归根结底，我们忍不住喜爱《超级马力欧 阳光》。它当然有令人失望之处。从主题上说，它确实像是这个系列的一次“度假”，镜头也带来无数问题，但总体而言，它充满了有趣的内容。坐下来玩它，你很容易一玩就是好几个小时。无论你是在追逐 100 枚摆放巧妙的硬币，还是在痛揍一个十倍于你体型的 Boss，你都不容易感到无聊。即便你走完最终关卡、击败最后一个 Boss，在你集齐全部 120 个闪耀的路上，你仍会发现许多很酷的支线任务——顺带一提，这并不特别容易，尤其因为它还涉及找出 240 枚蓝币。总而言之，我们认为你会爱上它。如果有一款 GameCube 游戏人人都该拥有，那就是它。

### 画面与技术

在试图描述《超级马力欧 阳光》的图形引擎时，“各部件之总和大有可观”这句话会浮现在脑海里。它自成一格。鲜艳到几乎刺眼，其美术风格与贴图设计是我们前所未见的。没人会把它错认成别的游戏。引擎大体以流畅的 30 帧每秒运行，是优良与糟糕技术的混合体。

先说优点：《超级马力欧 阳光》的绘制距离非常出色。你可以清晰地看到游戏中每一个世界的尽头。从树木到敌人，一切都清晰可见。这可不只是为了炫耀。当你搜寻硬币或某件物品时，即便它看起来在一英里之外，你也能看见它。最重要的是，这大概是这套引擎最大的长处。

紧随其后的，是水体效果。一款以热带海岛为背景的作品拥有惊艳的水，应该不足为奇。几乎每转过一个方向，你都能看到一片波光粼粼、向远处延伸的海水。值得注意的是，它并不平板或乏味。任天堂精通了其中的物理与“闪光”。起伏的水面由数层贴图叠加而成，在烈日下呈现出近乎完美的闪烁效果。这正是《水上摩托：蓝色风暴》所欠缺的效果。折射——即让水下影像弯曲的效果——也做得很好。当你在世界里喷洒水时，会看到大量折射。静水上的倒影同样是一处令人愉快的细节。如果你在马力欧脚下积起水洼，你会看到他的倒影在蒸发前浮现出来。

视觉上还有许多微妙的细节。散布在世界各处的黏液和彩色颜料会粘在马力欧身上，让他在身后留下脚印；若他在水里冲洗，则会留下一团浑浊的水雾。如果你愿意，还可以快速旋转马力欧甩掉颜料，看粒子四散飞溅。

不幸的是，马力欧最大的问题出在贴图设计与质量上。有许多丑陋的贴图被拉伸着铺满各个世界，而马力欧本身就是一款高对比度的游戏，这让问题雪上加霜。它充满了非常明亮的颜色——有些亮到刺眼。它无疑很独特，刻意营造出游乐场般的感觉，但必定会让口味挑剔的人望而却步。所幸，它确实支持逐行扫描，偶尔能展现出一些清晰锐利的贴图。正如我们所说，你得把引擎提供的一切都看一看，才能欣赏它。拉伸的绘制距离、相对流畅的帧率，以及令人惊叹的水体效果，会抵消掉一部分负面印象。

### 声音

玩家对马力欧作品一直有所期待的一件事，就是朗朗上口的配乐。近藤浩治总能为这个系列带来令人难忘的东西，但回到“度假”这个比喻，《超级马力欧 阳光》因为海岛主题，在音频上也让人感到陌生。近藤与一位新作曲家的灵感来自夏威夷、意大利这样的度假胜地。不出所料，原声依然抓耳，我们会习惯性地哼起枢纽世界的主题曲。秘密世界里还收录了初代马力欧主题曲一段令人惊艳的无伴奏合唱改编。尤其是这两首曲子非常棒。不过，其他一些世界也有许多平淡的、烘托气氛的曲目。它们就是留不在你脑子里。即便玩了无数个小时，我们能记住的主要还是枢纽世界的主题曲。另一处败笔是，任天堂把一些互动音频做得过头了。进入不同区域时听到音乐渐起或渐弱固然很棒，但有时会显得不搭调。更糟的是，有几首耀西主题曲里，不和谐的邦戈鼓会盖过其余音乐，吵得让人烦躁。话虽如此，《超级马力欧 阳光》里有几首曲子你会很喜欢，但大多数都不会让你有太大触动。

在音效方面，任天堂录制了相当多的马力欧台词与反应语音。你会听到大量重复的音频，比如马力欧跳来跳去时，但也会有一些让你惊喜的采样。碰到发烫的东西，可能会冒出一句滑稽的“好烫、好烫、好烫！”。另一方面，岛民和蘑菇王国来客也配有一些相当可笑的配音。蟾蜍家族里任何人听起来都很蠢，岛民也差不多糟。不过，撇开人声不谈，音效做得相当不错。你会听到水背包执行各种功能时叮当作响，水花四溅，敌人追着你跑，当然还有每收到一枚硬币的叮咚声。它甚至支持杜比 Pro Logic II。不过说到这里，环绕声的使用很有限。声音听起来更饱满，但比不上《永恒黑暗》或《星球大战 侠盗中队 II》里的表现。

2020 年，《超级马力欧 阳光》作为《超级马力欧 3D 收藏集》的一部分重新发行，与《超级马力欧 64》和《超级马力欧 银河》一同收录。Nintendo Switch 版《超级马力欧 阳光》拥有更高的分辨率、新的宽屏模式，并做了一些调整，以让操作适配没有模拟扳机的 Switch 手柄。若想一睹 Switch 版的样子，请观看下面的预告片，并阅读我们的《超级马力欧 3D 收藏集》评测。

### 总评

这是迄今为止我最喜欢的单人 GameCube 游戏。它从一开始就完全引人入胜，我对它扎实的操作怎么夸都不够。手感就是对的。不过，我对度假主题以及任天堂在呈现上固执地不上心相当失望。尤其是故事与角色设计，执行得很糟。我觉得任天堂认为把碧姬塑造成十足的花瓶、把马力欧弄成胖乎乎的蠢货很有趣，但对我们这些有点头脑的人来说，这看起来很蹩脚。如果任天堂真的不在乎故事，那它还不如干脆别费劲提供那些做得糟糕、压缩过度的过场动画。

但归根结底，《超级马力欧 阳光》的核心是玩法。它的深度轻松跨越了呈现、声音和画面上的所有问题。如果《超级马力欧 64》是你最爱的游戏之一，那么我相信《超级马力欧 阳光》也会跻身那份名单。

寻找一段好冒险的玩家不会选错。

> 来源：GameSpot（https://www.gamespot.com/reviews/super-mario-sunshine-review/1900-2878399/）· 作者：Jeff Gerstmann · 发布：2002-08-26 · GameSpot 评分：8/10（Great）

任天堂的软件阵容始终围绕着一群核心角色展开，他们出演的游戏往往能成为推动主机销量的作品。你总会觉得，由这些角色担纲的游戏会被额外打磨一番，以确保一切都恰到好处，哪怕这意味着游戏要跳票数月甚至数年。因此，像《超级马力欧 阳光》这样的游戏必然备受期待。《超级马力欧 阳光》是任天堂 GameCube 上第一款真正重量级的作品，也是任天堂最具辨识度的角色在该主机上的首次领衔主演。一旦你从“最新的马力欧游戏终于来了”的兴奋中缓过神来，你会发现这是一款总体讨人喜欢、却高度依赖几个新动作的游戏——这些动作更像是噱头，而非玩法上的创新。

《超级马力欧 阳光》是六年来第一款全新的马力欧平台游戏。游戏开场，马力欧和他的随行众人飞往天堂般的海豚岛度假，逃离蘑菇王国的日常劳碌。但飞机一降落在岛上机场，马力欧的度假美梦就立刻被打断了。整座岛似乎被涂鸦和污染覆盖，而肇事者偏偏长得足够像马力欧，引发了一桩情景喜剧式的身份误认。马力欧的判决是借助 FLUDD——一台背在身上的水枪——清理整座岛。一路上，公主会被绑架，黏液会被冲走，还会有大量的“闪耀”（本作中相当于《超级马力欧 64》的星星）被收集。

《超级马力欧 阳光》与 1996 年的《超级马力欧 64》有许多共同之处，后者是一款了不起的游戏，为此后每一款 3D 平台游戏树立了标准。当然，此前的马力欧游戏同样出类拔萃，所以《阳光》要背负的期待很重。它试图通过不偏离前作套路太远来承受这份期待。新作中相当于《马力欧 64》城堡主世界的地方，是城镇广场。枢纽区域很大、细节精致，并且有多条不同的路线通往各个关卡入口，让你不必花大量时间从一个地方跑到另一个地方。它还有相当多的秘密等待发掘。除了枢纽区域以及简短的开场和终章部分，游戏包含七个关卡。和《超级马力欧 64》一样，每个关卡都被分成多个有顺序的目标，这意味着你得多次重进每个关卡才能彻底完成它。每个关卡都包含八个章节，完成一个章节总能获得一个闪耀。《超级马力欧 阳光》共有 120 个闪耀，但你用不到一半的数量就能通关。

关卡目标往往相当直白，因为在游戏中你几乎可以通过单纯朝任何问题喷水来解决它们。每个章节开始时都会短暂环视一下关卡，几乎总是在几秒内就精确展示出你需要做什么。有些目标简单到只需抵达关卡中的某个地点，与 Boss 战斗以赢得奖励，或和另一个角色赛跑到某个特定地点。另一些目标，比如让你骑在一只鱿鱼般的小生物背上冲浪的，更像小游戏。同样从《超级马力欧 64》延续而来的还有红币挑战——你只需被派去进行一场寻宝，找齐一定数量的红币。每个关卡都至少有一个必须完成的红币收集目标，其中有些必须在限定时间内完成。每个关卡还有一个目标是追着邪恶的“马力欧克隆体”满场跑，用水把他喷到认输、给你一个闪耀。

还有许多目标会把你引入洞穴和其他封闭区域。进入这类区域会触发一段简短却被滥用的过场动画：马力欧克隆体偷走你的水枪并把它卷走。随后，你会被送进几个不同障碍赛道式关卡之一，这些关卡里满是漂浮和移动的、贴图做成木纹质感的方块。随着游戏推进，这些赛道会变得越来越难，并且能够重新唤起那种经典的平台游戏挫败感：你看见终点，也清楚如何抵达终点，却似乎怎么也拼凑不起来、真正把马力欧操控过去。偶尔的技术问题也会带来相当的挫败感，比如穿模问题让你穿过物体坠落，或把你卡在墙壁、栅栏里。虽然少数关卡目标确实出彩，会让你想起自己最初为何热爱马力欧系列，但游戏里许多目标——尤其是红币挑战——纯粹是乏味的，完成它们与其说是奖励，不如说是一种解脱。为了通关，你必须把每个关卡至少来回跑上七遍，这一点也没多少乐趣，尽管不同目标之间关卡会略有变化。尽管我们等了很久，但《阳光》依然有些粗糙的棱角。

操控马力欧轻而易举。他在《超级马力欧 64》中的多数动作都被保留了下来，包括极其好用的转身跳和三连跳。不过，马力欧的拳脚功夫派不上用场了，因为他所有的物理攻击都被水枪取代。水背包配有两个标准喷嘴。炮嘴能让你朝身前短距离喷水。按 R 扳机能启动水枪，把扳机按下一半则能让你在移动中喷水。把扳机一按到底会让你站定，但同时让你能瞄准水枪。另一个标准喷嘴是双管悬停喷嘴，能让你腾空而起。这便于你跨越沟壑，或为跳跃增加一点高度。不过水压不会永远持续，所以你不能就那样一直待在空中直到水箱见底。

随着游戏推进，你会找到其他喷嘴来替代悬停喷嘴。火箭喷嘴能把你射向高空，但不让你悬停；螺旋桨喷嘴让你沿着地面或水面疾冲，但除非你铁了心要找齐每一个闪耀，否则它从未真正发挥过有意义的作用。你最终还能骑上马力欧那只恐龙般的伙伴耀西，但不幸的是，他看起来像是被当成事后才想起来的附加品塞进来的。耀西唯一有用的地方，是他那种把果汁到处乱吐的古怪能力，而这又只用在一个必需谜题和少数可选谜题上。

不必说，你在《超级马力欧 阳光》里的大部分时间都在操控马力欧。但你也得花时间操控游戏的镜头。实际上，游戏的大部分难度，都来自你在完成马力欧那些本应简单的任务时，还得把镜头照看好。当你改变方向时，游戏自动校正镜头角度的速度很慢，结果就是你真的一刻不能松开 C 摇杆，才能确保自己看得见需要看的东西。除了围绕马力欧旋转视角，你还能用镜头控制来拉近拉远画面。如果你的背正贴着墙，这或许有帮助，但有时连镜头控制都救不了你，你只能盯着墙壁贴图的背面，靠马力欧的剪影大致判断他在屏幕上的位置。

不幸的是，你看不到附近任何平台或其他重要物体的剪影，这让这个解决方案完全失去了价值。说明书里说，当你贴着墙时，镜头会自动打开某种舷窗，好让你仍能看见画面，但它很少这么做，反而会在你根本不需要的地方使用舷窗效果。虽然镜头倾向于让你主导画面，但在狭窄处它会相当闹脾气——你可以把镜头转到任何你想要的角度，可你一松开 C 摇杆，它就会迅速转回默认位置，这有时很不方便。游戏的镜头问题在通往游乐园摩天轮后方的那一章节，以及最终 Boss 战中尤其明显。

与镜头不同，《超级马力欧 阳光》的画面看起来要精致得多。整个游戏有一种非常风格化的外观，从艺术角度看极为出色；而且从技术角度看，《阳光》也往往是一款相当好看的游戏。它通常以稳定流畅的帧率运行，角色色彩鲜艳、建模精良，角色动画也做得很好。游戏里许多贴图看起来也相当不错。但当你凑近某些贴图时，它们就开始显得分辨率极低、块状明显。游戏色彩丰富，但有些部分几乎显得褪色——这或许是为传达海豚岛阳光特质而刻意使用的效果，但在某些地方实在不太奏效。当你在环绕小岛的海洋以及游戏各处的水体中看到它们时，游戏的水体效果非常惊艳，而水枪留下的水洼也呈现出不错的倒影效果。

其他令人印象深刻的特效也比比皆是，比如你注视远处物体时会看到的热浪扭曲。游戏在少数几处会掉帧，但除了最终 Boss 关那处相当恼人的例外——它在相当关键的地方变慢——掉帧并不妨碍操作。游戏的关卡非常大，画面以令人赞叹的绘制距离渲染，让你能清晰看到周围所有的动态。不幸的是，游戏用于偶尔叙事片段的过场动画相当糟糕，这些 FMV 片段里的角色模型和场景，看起来并不比游戏内效果强多少。

《超级马力欧 阳光》有许多可取之处，但它本可以更好。《超级马力欧 阳光》的 FMV 里还包含 GameCube 上最糟糕的一些配音。没有哪个声音特别贴切。碧姬公主听起来太傻，马力欧仅限于咕哝和其他非语言交流，而游戏的反派则完全不搭，令人彻底失望。不过，游戏其余部分的音频要好得多。马力欧在游戏中跑跳穿梭时发出那套标准的呐喊叫嚷，你会喜欢他的鞋子在各种材质表面上敲击的声音。要是能听到所有岛上居民说出他们的台词就好了，但鉴于游戏其余部分糟糕的配音，以及大多数对话措辞都很拙劣，角色大多保持沉默或许反而是好事。游戏的大部分音乐都不错，但没有哪首真正脱颖而出。障碍赛道关卡里播放的经典马力欧主题曲改编版，看起来像是对马力欧过去一次刻意的牵强致敬。

马力欧系列几乎一直堪称惊艳。如果你玩电子游戏哪怕只有几年，并试着列出一份史上最佳游戏名单，你很可能会把至少两三款马力欧游戏排在很高的位置。但《超级马力欧 阳光》很难不负这份传承。就自身品质而言，《阳光》是一款扎实的游戏，拥有非常独特的外观和一些精彩时刻，但也有它应得的那份不足。虽然游戏不算特别难，但太多目标属于那种让你在完成后立刻心想“好吧，至少我再也不用做那个了”的类型。虽然有些玩家能够看开、甚至欣然接受《超级马力欧 阳光》极度贴近《超级马力欧 64》套路这一事实，但另一些人会觉得游戏缺乏创新。游戏的技术问题和时常沦为噱头的设计仍然更难被忽视，它们叠加在一起，让游戏有时显得出奇地粗糙，甚至有些仓促。不过说到底，《超级马力欧 阳光》有足够的内容值得购买，尤其当你考虑到 GameCube 上确实找不到什么像样的平台游戏，而这确实是市面上唯一一款全新的马力欧游戏时。
