# 超级马力欧兄弟 惊奇

<ReviewTabs slug="super-mario-bros-wonder">

<ReviewTab site="ign" label="IGN">

![超级马力欧兄弟 惊奇 IGN 评测头图](/img/reviews/super-mario-bros-wonder.jpg)

> 来源：IGN（https://www.ign.com/articles/super-mario-bros-wonder-review）· 作者：Ryan McCaffrey · 发布：2023-10-18 · IGN 评分：9/10（amazing）

每一款马力欧平台游戏，无论 2D 还是 3D，似乎都会兴高采烈地在某种程度上重塑自我，把它们带给我的独特乐趣加倍奉上。延续这一传统，《超级马力欧兄弟 惊奇》这个名字起得十分贴切，因为很简单：它充满了“惊奇”。真的是妙不可言！每一帧都洋溢着喜悦，从明快的色彩，到花花王国里无处不在的会说话的花——当你跑着跳着穿过几十上百个关卡时，它从不缺少鼓励的话语；而这些关卡会被难以预测、常常令人咧嘴一笑的“惊奇效果”改变，而且往往还有马力欧本人的滑稽举动。无论你是独自游玩，还是与最多三位朋友同乐，《超级马力欧兄弟 惊奇》都有很多值得喜爱之处。

《惊奇》一眼就能抓住你的目光。它凭借标志性且讨喜的丰富色彩而令人目眩，尤其突出鲜艳的蓝、红、绿、黄。但它在动态中尤其令人印象深刻。在此要对《耀西岛》说声抱歉——它看起来就像是，你心目中一部真正的《超级马力欧世界》续作应有的样子，假如那部续作是在 2023 年而非 1995 年制作的话。

动画无疑是这里最出彩的部分：马力欧冲进水管时会伸手去够他的帽子；小怪物们在被水管工追赶、惊恐逃窜时眼睛会因恐惧而鼓起；板栗仔打盹时鼻孔上会挂着鼻涕泡；大象马力欧把自己巨大圆滚的身体挤进传送水管，还会——笨拙地——在低矮的一排砖块下蹲行时尽量把自己缩到最小。这样的细节还有太多太多！这些巧思在很大程度上让马力欧的首次花花王国之旅鲜活了起来。

> 你大概已经猜到了：马力欧又卷入了库巴的一场阴谋。

花花王国是什么？它是我们熟悉的蘑菇王国的邻邦，而事实证明这是一个令人耳目一新的舞台，主要是因为它带来了如此多可供马力欧踩踏的全新独特敌人。剧情方面，你大概已经猜到了：前来造访的马力欧当然又卷入了库巴的一场阴谋——这只爬行动物利用这片土地的“惊奇”之力，把自己和王国的主城堡融为一体，让居民们的生活苦不堪言。一如既往，剧情薄得像纸（薄得像马力欧），而且你知道一路上免不了要和小库巴们交手。

### 花之力量

但这并没有给花花王国留下任何阴霾，因为六个主要世界（外加本身就含有许多关卡的花瓣群岛枢纽）中数十个关卡呈现了如此多样的风貌和狂野的创意，那个通常会被遗忘的剧情也就变得无关紧要了。大多数关卡至少包含两颗惊奇种子，一颗在终点，另一颗则藏在关卡某处。想要拿到那颗隐藏的种子，通常需要找到一朵惊奇花——有时藏在砖块、敌人或秘密区域里——它会引发意想不到的事情。遗憾的是，我不能向你展示其中最精彩的大部分内容，但马力欧可能会变成一颗滚动的带刺球，镜头可能切换成俯视视角，马力欧和他的敌人可能一起变成富有弹性的墨水剪影，他可能变成一只不会跳、也不会攻击的板栗仔，或者出现一场舞会。你永远不知道接下来会发生什么。正因如此，我期待每个关卡的惊奇效果。它们体验起来实在太有趣了，以至于如果我在某个关卡里漏掉了一个，我都有充分的动力跑回去把它找出来。简而言之，惊奇效果成就了这款游戏。

> 简而言之，惊奇效果成就了这款游戏。

每个世界都安排了完全不同的敌人组合，其中大多是全新的敌人，同时也向一些经典角色致敬——既有云上飞的拉基图这样的常客，也有《超级马力欧兄弟 2》里波奇这样较为冷门的角色，这当然毫无坏处。在新面孔当中，芦苇怪会朝你冲过来，且无法用传统的踩踏击败，但你可以骑上去，而《惊奇》巧妙地利用了这一点。至于看起来呆头呆脑的食人花怪，它们看上去甜美、悠闲又无辜——直到它们发现你，这时它们张开的大嘴会张得老大，如果你不迅速跳得很高，就会被整个吞下。而毛毛怪呢，除了个头高得难以跃过之外几乎构不成威胁，而我怎么也玩不腻抓住它们那松垮的布片、把它们拆得无影无踪。我希望有一天能再次见到花花王国，因为我不想让这群鲜活有趣的新敌人只登场这一次。

### 其实，我们需要这些该死的徽章

2D 马力欧的配方中还有另一处新变化，那就是“徽章”——一组大约二十多个可解锁的主动或被动效果，你可以选择带进每个关卡。“增强旋转跳”让你按下右肩键就能有效地二段跳。“钩索藤蔓”意味着连马力欧游戏如今也有抓钩了；“安全弹跳”能让你掉进岩浆也活下来；而“传感器”会在你靠近关键物体时更频繁地发出提示音，比如大紫币以及（至关重要的）惊奇花。这些徽章让你能以一种最适合自己玩法风格的方式去应对关卡，这种掌控感很受欢迎，更不用说它还额外带来了一点重玩价值，堪称锦上添花。

有些徽章可以在商店里购买，另一些则要通过完成围绕该特定能力设计的“徽章挑战”关卡来获得。相比之下，用紫币购买徽章让人感觉不太满足，尤其考虑到我从来不缺紫币——我希望每一个徽章都能配有一个有趣的挑战，而不是只有一部分才有。

> 在线部分的整合出人意料地无缝。

说到新增内容，《超级马力欧兄弟 惊奇》提供了熟悉的四人本地多人模式，以及全新的在线多人模式，而在线部分的整合出人意料地无缝。我并不把它看作那种需要约好时间一起玩的多人游戏——在任何马力欧多人游戏里，沙发合作依然是王道——但它确实行得通，而且你可以在大多数关卡里发起的“好友竞速”，能让人从主要的平台跳跃玩法中分心娱乐一下。无论你们是在同一块屏幕上一起玩，还是在线联机，都很高兴看到任天堂做出了更协调一致的努力，通过立牌——让你能为朋友留下复活点——以及把伙伴们变成幽灵、使他们不会在需要精确跳跃或操作时挡住你的去路等方式，让多人模式成为平台跳跃中更有机的一部分，而不是事后硬加上去的附属品。

### 像大象一样聪明

不过，让我再回到大象马力欧身上说两句。他有解释吗？他到底讲不讲得通？这重要吗？不重要。他厉害吗？厉害。在《超级马力欧兄弟 惊奇》里，他是一股占据统治地位、宛如奥尼尔般的力量，还配有绝对搞笑的动画。当他用象鼻挥击较小的敌人时，只需轻按 Y 键就能把它们打飞。他的象鼻还能存水，在需要时浇灭滚烫的砖块、给干渴的植物浇水。他庞大的身躯甚至能让他用象鼻砸碎砖块。他就是好玩得不行。

钻头马力欧也是受欢迎的新增形态。帽子上装着一个钻头，他可以钻进地面——或者天花板！——进入隐藏区域，并从下方突然冒出来袭击毫无防备的敌人。

> 大象马力欧是一股占据统治地位、宛如奥尼尔般的力量，还配有绝对搞笑的动画。

对泡泡马力欧我就没法这么说了。他能吹出巨大的泡泡，泡泡可以捞取金币、略微追踪并困住敌人，还能当作跳跃踏板，这些都算得上实用。但在可以选择变成哪种马力欧形态时（和过去的马力欧游戏一样，你可以保留一个道具以备随时来回切换），我通常还是会选大象马力欧或老牌的火焰马力欧。

尽管 2D 的《超级马力欧兄弟 惊奇》大部分内容都洋溢着喜悦，但它还比不上上一部正统 3D 马力欧杰作《超级马力欧 奥德赛》。这次的音乐虽然完全谈不上差，却出人意料地容易被人遗忘；而且虽然有一些五星难度的关卡——包括一整组我不会在此剧透的关卡——《惊奇》在挑战性方面还是偏轻，所以对身经百战的老玩家来说，它提供的内容不如前作那么充足。不过平心而论，马力欧是面向所有人的，我女儿就很喜欢小偷兔作为可操作角色登场——我们一起玩的时候，敌人伤不到她，我们也更享受推进许多关卡的过程。尽管如此，我依然渴望马力欧的下一段 3D 冒险，尤其是眼看着距离《奥德赛》已经过去六年多了。

### 总评

《超级马力欧兄弟 惊奇》为 2D 马力欧平台游戏应有的样子树立了新的标准。它色彩缤纷，生机勃勃，充满欢乐。它还凭借难以预测的惊奇效果，不断以更有创意的方式给我带来惊喜和愉悦——这些效果会短暂地把关卡变成完全不同的事物。它们就像每道关卡主菜中间的一道甜点，令人难以抗拒，总能让我露出笑容——大象马力欧这个绝对的猛兽也是如此。除了高难度挑战之外，《惊奇》在各个方面都像是《超级马力欧世界》在 21 世纪的继任者，我想不出比这更高的赞誉了。

> 来源：GameSpot（https://www.gamespot.com/reviews/super-mario-bros-wonder-review-a-badge-of-honor/1900-6418136/）· 作者：Steve Watts · 发布：2023-10-18 · GameSpot 评分：9/10（Superb）

《超级马力欧兄弟 惊奇》仅凭一己之力就证明了，2D 马力欧不应在现代马力欧正典中被降格为二线地位。

无论任天堂是否有意如此，通常的看法倾向于把现代马力欧游戏在脑海中排成某种等级表。《银河》和《奥德赛》这样的 3D 马力欧游戏是旗舰级的吉祥物平台游戏，而《新超级马力欧兄弟》系列这样的 2D 马力欧游戏则在某种程度上是较次等的复古回归之作。仍然优秀、可靠，但没那么显赫。在 2D 游戏多年处于替补地位之后，《超级马力欧兄弟 惊奇》终于登上中心舞台——而且它的表现如此惊艳，以至于它（无论含蓄与否）提出了这样一个论点：2D 马力欧游戏对这门媒介的重要性，完全可以与其 3D 兄弟比肩。

从本质上说，赋予《马力欧 惊奇》之名的惊奇效果，可以类比《超级马力欧 银河》中的小行星——一个简单、易懂的钩子，让关卡设计师可以自由地发挥想象力、尽可能古怪，不断重塑机制、颠覆预期。结果再次是一款塞满了令人愉悦的小惊喜的游戏，就像拆开一系列专为挑剔的马力欧平台游戏粉丝——也就是你——准备的礼物。

这些惊奇效果也延伸到了故事，而故事松散且不碍事。马力欧和他的伙伴们正在拜访邻国花花王国的弗洛里安王子，后者急于展示他王国最伟大的宝物——惊奇花。但库巴自然破坏了这个外交活动，偷走了惊奇花，把自己变成一座活着的、漂浮的城堡，高耸于王国之上，并腐化了里面的一切。前提确立，马力欧一行人赶去救援。惊奇花的确切科学效果从未被恰当解释，但我们足够清楚地领会了大意：它以一种巨大、常常出人意料的方式改变现实。

这个故事的设定实际上等于给了任天堂一张创造力的空白支票，让任何天马行空的想象都能发生，时长完全取决于找到乐趣所需的长短。如此一来，它重新捕捉到了让初代游戏如此令人难忘的那种不可预测、如梦般的逻辑。

上一刻，你还在一个传统的《超级马力欧》关卡里跳跃、旋转前进，下一刻，你可能被变成一只板栗仔，躲避着吃板栗仔的食肉生物；或者只以剪影的形式看见自己；又或者随着有节奏的舞蹈蹦跳前进。其中一些是真正有挑战性的，而另一些则作为一个可爱的玩笑来玩，提供短暂的喘息。你永远不太确定接下来会发生什么。

偶尔会有惊奇效果重复出现，但这通常是那种能支撑多个关卡的效果。唯一令人印象深刻的例外是在游戏很早期，两个“芦苇冲撞”关卡紧挨着接连出现。这些关卡让你骑在一群狂奔的芦苇怪背上，第一次玩是个有趣的桥段，但我得承认，在游戏这么早期就看到重复让我有点紧张。如果它们已经开始重复点子了，那创意或许比我期望的要少？幸运的是，随着我进一步探索、遇到众多多样的惊奇效果和关卡类型，这种担忧消退了。

这种多样性也得益于新的设定，它还带来了创造大量全新敌人类型的机会，这些敌人完美契合马力欧传统的视觉与玩法美学。我们迎来了板栗仔和幽灵等熟悉的最爱回归，同时还有大量富有创意的新增角色。弹喙鸟是速度快、喙如剃刀的飞行敌人，会径直朝你冲来，然后扎进地面或墙壁。跳跳猫是危险的带刺壳敌人，每当你跳跃时它们也会跳，要求你更仔细地思考应对方式。木乃伊怪是木乃伊般的生物，除非你从背后接近、用力拉扯它们垂下的绷带，否则无法伤害它们，此时它们会散解成虚无。这样的例子还能一直列下去。

最令人惊讶的是，尽管有新的敌人类型和惊奇花带来的持续惊喜感，《超级马力欧兄弟 惊奇》从未丧失其作为马力欧游戏的身份。平台跳跃一如既往地精准，而即便你错过或选择不拿惊奇花，关卡设计也作为一款出色的马力欧游戏而运作。关卡设计的匠心体现在细微之处，比如给王国中众多魔法花之一浇水会让花瓣随风飘动，奖励你金币的同时，也巧妙地引导你的目光投向兴趣点。

少数几个新强化道具同样完美融入马力欧正典。最引人注目的是大象强化，它让马力欧和他的朋友们变得巨大，赋予他们额外的力量，以及用鼻子收集和喷水的能力。泡泡强化让你能困住敌人，或制造可踩破的平台来跳跃，感觉就像是一个简单却做得极好的概念，本可以存在多年。我个人最喜欢的是钻头服，它让你能钻入地下甚至天花板，钻到新的位置，然后从敌人下方或难以到达的物品附近冒出来。它作为防御和进攻工具都很出色，也有助于探索——而且碧姬公主裙子上那漩涡图案还很时尚。

这一切本已会是多年来最强劲的一款 2D 马力欧游戏，但《马力欧 惊奇》在此基础上又叠加了更多东西。马力欧庞大的角色阵容中有许多都有代表且可玩，让你能扮演马力欧、路易吉、碧姬、黛西、黄或蓝奇诺比奥、奇诺比珂、几只耀西，以及纳比特。耀西和纳比特不会受到伤害，这让他们成为很好的入门角色，无需退回到菜单选项或为年幼孩子打开“简单模式”。

然而，马力欧的朋友们没有了源自《马力欧2》的标志性能力，这可能会让一些老粉丝感到不适应。路易吉没有了他跳得很高的飘浮跳，碧姬也无法飘浮跳。用这些角色游玩却没有这些移动能力感觉有点不对劲，而这确实产生了把每个角色都抹平成相同玩法风格的效果。比如说，奇诺比奥和路易吉之间实际上没有玩法差异，这需要时间适应。不过，这似乎是为了让所有人处于公平的竞技场，而且效果还算不错。

> 这个故事的设定实际上等于给了任天堂一张创造力的空白支票，让任何天马行空的想象都能发生，时长完全取决于找到乐趣所需的长短。

取代独特角色能力的是徽章，实际上给了马力欧和他的朋友们一套轻量的装备系统。例如，在这里你可以装备一个“飘浮高跳”徽章，模拟飘浮跳，所以如果你想装备它并扮演路易吉，就能重现那种感觉。（不过据我所知，没有碧姬飘浮跳徽章。）徽章分三类。像飘浮高跳这样的动作徽章会以某种显著方式改变你的实际玩法行为，而增益徽章则给你一些被动好处。例如，安全弹跳在你掉进坑或尖刺时提供一次性保护，而金币奖励让你每击败任何敌人就能获得金币。稀有的专家徽章以重大、富有挑战性的方式改变游戏，玩法效果比前两类更大。你一次只能装备一个徽章，而游戏让你按下一个“王子的选择”按钮，获取关于哪个徽章可能最适合新关卡的提示。总而言之，这些创造了一个可随心定制的不同风格游乐场。有些徽章取决于个人偏好，通常有一两个能让关卡更简单，但你也可以用一个让关卡更难对付的徽章来挑战自己，或用徽章打开可能揭示新秘密的“！”方块。发现所有组合变化带来了重玩价值与探索。

这种自定义确实有一个重要的附带条件。在本地合作中，所有角色只能一次装备一个徽章，这意味着你们各自必须认同单一玩法风格或能力，而两名玩家未必能达成一致。这似乎是为了游戏平衡，但这条规则并不适用于在线多人。在网上与好友组队时，你们可以各自装备符合自己偏好的徽章，甚至头脑风暴出有创意的组合。既然如此，本地合作感觉相对受限就很奇怪了。

事实上，《超级马力欧兄弟 惊奇》的在线多人自始至终都考虑周到、设计精良，对于一个常常把在线游玩当作事后补充的系列来说，这令人惊讶。你们可以加入一个大厅一起通关关卡，或者各自独自探索。如果你们确实加入了同一关卡，你们可以一起努力攻克它，或触发一场类似速通的竞赛，看谁先通关。这一切都感觉现代化了，而马力欧传统上在这方面一直有所欠缺。

尽管在线多人做得很精良，但对我来说最突出的是那一整套新的在线功能，即便你独自游玩也能提升体验。你可以使用立牌，而收集这些立牌是游戏内金币经济的一种用途。只要你能在某个地方下蹲并按 X，你就能在关卡任何地方放置一个立牌，然后你的立牌会出现在其他玩家的游戏中。你可以用这个来留下关于隐藏秘密的提示，或仅仅为其他玩家提供一个喘息之处。因为如果你在关卡中死亡，你会变成一个幽灵，可以通过触碰附近的立牌来复活自己——就像在多人模式中你可以通过触碰另一名玩家来复活一样。所以把立牌留在有帮助的地方对你有好处，而每当它们被触碰，你就能获得爱心点数，显示你是一个多么乐于助人的玩家。

联网游玩还意味着你有时会看到其他玩家在关卡中游荡的影子，这能帮助你弄清楚棘手的平台跳跃谜题。这在新的寻宝派对关卡中体现得最为明显，你需要找到五枚隐藏金币。立牌和影子能帮你指向正确的方向，营造出一种非同步的解谜体验，感觉非常棒。当然，如果你更想自己找出答案，随时可以断开连接，那些幽灵和立牌就会消失。

寻宝派对是打乱传统平台跳跃关卡的几种新关卡类型之一。你还会发现徽章挑战，你通过证明自己理解某个徽章的用法来赢得它；KO 竞技场，一个限时关卡，根据你多快击败各种敌人房间来奖励花币；以及休息时间，一段不到一分钟的随机小游戏或任务的轻松闲逛。

所有这些不同的关卡类型都散布在一个开放世界中，让你能自由漫游发现秘密，而且大多数情况下能按自己选择的任意顺序挑战关卡。整个世界都感觉生动而引人入胜，鼓励探索与重玩，以揭开所有关卡、惊奇效果、商店等等。

此外，呈现中还投入了令人惊讶的匠心与用心。即便是视觉上乏味的《新超级马力欧兄弟》系列看起来也相当扎实，但《超级马力欧兄弟 惊奇》看起来简直令人难以置信，它在面部表情和动画上十分讲究，背景和关卡元素也拥有鲜亮的糖果色，跃然于屏幕之上。有些瞬间在视觉上极具冲击力，这是我有段时间以来对一款 2D 马力欧游戏无法说出口的。音频也受到特别关注，尤其是遍布王国的会说话的花所提供的实时解说。这些话痨可能会提供提示，或只是拿某个狂野的新敌人或惊奇效果开个玩笑。考虑到任天堂在话痨配角方面有过参差不齐的历史，这是个冒险的选择，但这些花确实有趣，基本上不碍事，还能帮助把玩家引向正确的方向——有时是字面意义上的。

《超级马力欧兄弟 惊奇》是个大胆的命名选择。它在地上插下一面旗帜，暗示任何低于持续惊奇与愉悦的表现，按它自己的标准都算失败。但令人惊讶的是，《马力欧 惊奇》迎难而上，结果是成就了一部现代经典。惊奇效果是最耀眼的特色，理由充分，因为它们成为丰富创意的跳板。但真正把它牢牢钉进马力欧正典的，是围绕新强化道具、徽章、在线多人以及视觉风采的明智而周到的选择。它是《超级马力欧世界》当之无愧的继承者，希望它也能成为 2D 马力欧未来发展的试金石。

### 评测结语

**评分：9 / 10 — Superb**

**优点**

- 惊奇效果提供了源源不断的愉悦惊喜
- 新的关卡类型用短暂休息和谜题丰富了平台跳跃关卡

- 极偶尔会有惊奇效果重复，包括一个未能展现最佳一面的早期效果
- 本地合作中无法装备多个徽章，使其不如在线模式
