# 使命召唤

<Tabs groupId="review-source">
  <TabItem value="ign" label="IGN">
![使命召唤 IGN 评测头图](/img/reviews/call-of-duty.jpg)

> 来源：IGN（https://www.ign.com/articles/2003/10/28/call-of-duty-review）· 作者：Dan Adams · 发布：2003-10-28 · IGN 评分：9.3/10（amazing）

时代在变，口味在进化，游戏也必须向前迈进，以满足这些新的期待。Infinity Ward 作为一家开发工作室，在他们有史以来的第一款游戏里，正试图做到这一点。《使命召唤》中的许多创意或许最早出现在别的作品里，但在这款游戏中它们被磨砺到了极致。如果你想要的是一段让你心脏出问题、让你耳朵乐得直扇、并让你尽可能贴近二战体验（或者说你真正会想体验的那种）的惊险旅程，那就是这款游戏了。单人战役中那些小毛病和相对较短的流程，都无法掩盖这段美妙游戏体验中随处可见的精彩时刻。

《使命召唤》将把玩家带回二战——过去几年里，这段历史对玩家来说已变得无比熟悉。真正的诀窍一直在于，如何把那场战争、乃至战争本身的感受真正带给玩家。而把玩家置于孤胆枪手、一举消灭整个纳粹威胁的位置上，并不能做到这一点。这时，《荣誉勋章：联合袭击》登场了。它是最早真正把玩家放到一支更大队伍中一员的游戏之一。那种自己只是险恶战场上又一名士兵的感觉，此前从未被人以如此深刻的方式体验过。如今，当年把《荣誉勋章》送到热切玩家手中的许多团队成员，转投到了 Infinity Ward，并开始开发《使命召唤》，希望把同样的游戏体验推向更高的高度。他们取得了丰硕的成功。

虽然这款游戏并非每个方面都让我像个小女生一样咯咯直笑，但有足够多“$#!*!!!”和“噢糟了！噢糟了！噢糟了！”式的时刻，让我热情地向射击游戏迷们推荐它。当你发现自己在“子弹从耳边呼啸而过”时真的会在电脑屏幕前低头躲闪，你就知道自己已经彻底沉浸在一段引人入胜的体验中了。你将依次扮演一名美国士兵、一名英国士兵和一名俄罗斯士兵，经历一系列惊心动魄的任务，战役从“霸王行动”一路推进到最终强攻柏林。

游戏的开场方式令人惊艳：你（扮演第101空降师的一名美军伞兵）从空中坠入法国，要在诺曼底海岸的D日登陆开始前先行打击目标。当你独自降落、为其他伞兵安放信标以作为降落参照点时，四周静得诡异。在解决掉几个落单的哨兵后，你放好信标，等待飞机从头顶飞过，把它们的“人肉货物”投放到德军占领的领土上。当那些飞机掠过时，警笛开始尖啸，防空武器开始轰鸣，在背景中把天空点亮。随着更多部队在地面与你汇合，并向附近的建筑推进，一切都乱套了。百叶窗打开，露出MG42机枪阵地，而德军士兵则在房屋里占据位置，向推进中的你的小队开火。枪声的骤然爆发，真的是值得细细品味的一刻。

而这种对枪声与音效的品味，是你在游玩过程中必须习惯的东西。《使命召唤》的音效是我有幸在游戏中体验过的最出色的之一；简直是一场由骇人枪火与爆炸构成的狂欢。那些弹跳的子弹、擦身而过的险情，以及你或队友中弹时的闷响，正是让你喊出“$#!*!!!”、像傻瓜一样在电脑前低头躲闪的元凶。这游戏真是震耳欲聋！震耳欲聋！我爱死它了。当你的班长开始吼出命令时，各种声音完美地融合在一起，但你绝不会漏掉88炮那令人心碎的闷响，或是MG42阵地那骇人的哒哒声，因为它们会和这一切一起奏响。枪声不止令人满意，爆炸震得你脑袋发晃，盟军与敌军的呐喊会把你牢牢钉进这段体验里，让你不得不把双手从鼠标键盘上硬扯开。唯一的薄弱之处是一些配音。我理解为什么它们用英语而不是俄语录制，但我多少希望当时能有像DVD那样的字幕或英语配音可选。除了这个小小的纠结之外，《使命召唤》的音效工作无可挑剔。

从画面上看，这款游戏非常扎实。它或许没有法线贴图以及所有那些大家似乎都很兴奋的新玩意儿，但它有风格、有清晰度、有出色的贴图、有不错的人物模型和不错的人物面部，还有一些极棒的灯光和爆炸效果。尤其是角色动画，看起来很有趣：士兵们一边射击一边四处奔跑，有时抱着头，还用手势告诉你该往哪走。游戏中有一个特别的瞬间——史蒂夫通关时甚至都没看到——展现了你的战友们在一架滑翔机“着陆”时（相当粗暴地）在后舱被颠得东倒西歪。他们最后全都从座位上摔下来，叠在一起；这是个很好、很有趣的细节。

在游戏的大部分时间里，你会发现自己被友方AI包围，它们支持你的行动，并带来一种比我在迄今任何射击游戏中记得见过的都要深得多的沉浸感。当你接到向左翼包抄的命令，听到班长高喊“压制火力！”时，你最好赶紧动起来。因为当你的小队向敌人猛烈开火、压得他们抬不起头时，你就能移动到一个有效得多的包抄位置。如果你等太久，在压制火力没能阻止德国人开枪时才冲出去……那你可就有麻烦了。

整个游戏中的AI都扎实得令人印象深刻。有些时刻我的战友会走到我的火线前中弹，但大多数情况下，他们都很擅长选择自己的位置、朝正确的地点射击。敌方AI在大多数场合也相当聪明。它们似乎喜欢活着，一般不会没头没脑地朝你直冲，除非它们进入了搜索歼灭模式，那种情况下它们会想要把一整栋建筑或一片区域里的敌人揪出来。你肯定会看到敌人试图向你的位置推进（尤其在防守任务中），但在这么做时一般会尽量保持低调。它们会利用掩体、被摧毁的坦克、战壕、碉堡和建筑，尽可能躲得不见踪影。它们和你一样，有能力从拐角处探头射击，以让自己成为尽可能小的目标。我无法告诉你，看到友方和敌方单位都拼命想活下去，是多么令人愉快。

不过AI也并非没有怪癖。有时你会看到自己的小队（大概是受寻路AI或脚本的指挥）径直从一名德国兵身边跑过，结果被枪托砸头或是屁股中弹——除非你冲过拐角去保护他们。这是种非常古怪的现象，但似乎双方都会发生。敌方AI还懂得优先追杀你。你会时不时看到敌人把目标切换成你，或者躲在暗处等你这个人探出头来。有一个特别让我恼火到极点的例子：一名德国兵躲在一扇向庭院外开出的门后面。他对所有已经跑到那里的盟军士兵视而不见，但当我走到外面时，他从门后跳出来，让我的脑袋变得软了一点。这实在不公平。我完全支持惊喜，但当我的小队几乎全员都已进入该区域、而且没有任何交火时，我可不期望被那该死的门框后面攻击。

游戏中大量的脚本化设计，我知道这是玩家们所担心的一点，但它确实倾向于很好地融入玩法。比如死亡就不总是脚本化的。有些任务里，你身边可能会有三个或更多朋友，也可能一个都没有，取决于他们做了什么、你做了什么来让他们活下来。但你会看到某些事情无论你做什么都会因你的行动而触发、每次都会发生。例如，在我刚描述的第一个任务中，其中一栋建筑只会在你成功干掉藏在里面的MG42机枪手之后才会被轰炸。但另一方面，一些乍看之下完全脚本化的事件，并不总会以同样的方式上演。在“飞马日”任务中，你必须防守一片区域，抵挡包括坦克在内的敌人猛攻（一个精彩又困难的关卡）。如果你在其中一辆坦克驶来前快速存档，你会突然发现坦克并不总是从同一方向开来，这让事情变得更有趣。不过，一旦你通关一次，你就会知道大多数敌人会从哪来、每一关会发生什么。它只是比《荣誉勋章：联合袭击》里奥马哈任务整合得稍好一些——在那里，每个士兵每次都会死在同一个地点。

不管脚本化的问题如何，《使命召唤》依然是一款极其刺激的游戏，仅凭大多数关卡设计所展现出的优雅与节奏，你在通关后就会想回来以更高难度再玩一遍。毫无疑问，游戏中最好的任务，是那些你与一支庞大友方AI小队合作完成目标的任务。有些任务把你更多地置于突击队的角色中，虽然做得不错，却提供不了那种背水一战的兴奋感。其中一些的节奏会变得有点慢，因为你从拐角到拐角地潜行，试图看清下一个敌人。在英国战役里这类任务中有一段略显沉闷的间歇，但到了俄罗斯战役事情又稍微回到了正轨，尽管在斯大林格勒一些穿下水道、以及那些千篇一律的炸毁建筑中奔跑的桥段，会让你想再次和战友们一起冲到开阔的室外去。

与《荣誉勋章》中的大多数任务不同，《使命召唤》的关卡之间通常有不错的衔接与流畅感。虽然除了战争本身之外其实没有什么剧情，也没有真正的角色发展，但有些面孔会随着他们一关接一关地出现而变得熟悉。不过，尽管这种衔接存在，游戏确实倾向于跳跃得有点厉害。美国战役顺畅地接入英国战役，但在英国战役结尾，过渡显得很突兀。前一秒你还在攻打一处机场，下一秒你就坐在船上攻击一艘德国驱逐舰，除了书面简报上的几条笔记外，几乎没有说明原因。这类任务之间显然本可以有更多的视觉和听觉简报。我第一次在船上时，还没读完就不小心点了开始任务，所以我满脑子只能想：“我他妈怎么突然就在船上了？”跳转到俄罗斯战役倒可以理解是突兀的，毕竟战争各条战线之间相隔那么远，所以这方面我不能说有什么意见。

有一个方面可能会让你们中一些人失望（也让我有点失望），那就是流程长度。我们办公室近来其实一直在讨论“质量还是数量”的问题。很难说每个人对一款游戏应该花多少小时通关到底怎么看。这取决于满足感的高低、它是否让你想再玩一遍、有没有多人模式……很多因素。所以，在以普通难度用6个半到7小时通关单人游戏后，我可以说我对内容非常满意，但又有点希望它能再多一点。我又以老兵（最难模式）通关了一遍，花了大约10到11小时。但那个老兵模式在某些部分真的非常非常难。敌人的枪法会好得多，而且没有医疗包。谢天谢地，游戏里没有那种烦人至极的“狙击小镇”式任务，敌人似乎也并非时刻都知道你在哪。总的来说，我对流程长度是满意的，只因为这份作品太棒了。如果多几个关卡、或多玩一会儿，我会不会更开心？会。但那就像说，即便我刚吞下一整个蛋筒冰淇淋，再多一勺超好吃的冰淇淋我也会更开心一样。

何况，当你再加上多人混战这份美味佐餐时，事情就变得更能忍受多了。多人模式有几种不同的玩法。有标准的死斗和团队死斗，玩家们会在这些节奏极快的对战地图上玩得相当尽兴。但也有三种更有意思的游玩模式。第一种是“敌后作战”，它把一定数量的玩家（取决于服务器规模）设为散布在地图各处的盟军玩家。其余玩家（在人数上远多于盟军）则是轴心国。每当一名轴心国玩家杀死一名盟军，该轴心国玩家就变成盟军。作为盟军存活的时间越长，赚取的分数越多。在盟军一方击杀轴心国玩家还能获得更多分数。

最后两种玩法是团队制的。一种是“搜索与摧毁”，顾名思义，它要求一支队伍安放炸药并摧毁两个目标之一，很像《反恐精英》多年来一直在做的那样。第二种是“夺取”，它要求其中一支队伍找到并拾取一个物品，把它带回夺取区，很像《重返德军总部》做得非常出色的那样。这两类地图都像《反恐精英》那样进行，所以你只有一条命。你死了，就得等到下一回合。

过去一周里我有机会玩遍了所有这些任务，它们都非常有趣。关卡大体上感觉不错，武器平衡得很好（我本以为俄罗斯人因为选择少会处于劣势，但我爱那把PPSh冲锋枪，而莫辛-纳甘是把非常有威力、虽然射速慢的步枪），无论是只为图个乐随便进来玩玩的玩家，还是更认真的战队，应该都会玩得很爽。有些关卡似乎内容多到几乎应付不过来，但我认为那只是需要花点时间适应、摸清路线和好的藏身点而已。

所有多人模式中一个有趣的部分是“击杀镜头”。当你在游戏中被杀死时，击杀镜头实际上会让你在凶手杀你之前的几秒里，透过凶手的眼睛来看。得益于悬在你位置上方的一个巨大白色箭头，你能看清自己在哪里，从而看到敌人是如何偷偷摸到你身边、狙击你、或者干脆把你碾压的。我非常喜欢这个新增功能；尤其是它对抑制“蹲点”行为的潜在作用。

从技术上说，这款游戏在我们这里所有人的机器上都运行良好，几乎没什么问题。有件事是潜在买家在购买本作前可能想知道的。我们一直听说这款游戏在ATi显卡上有些问题。听说之后，我们也特意在这些显卡上做了检查，但完全无法证实这一点，因为游戏在我们的Radeon 9800 Pro配置上运行良好、毫无问题。如果你确实遇到任何问题，我们听说可能和Catalyst 3.8驱动有关。但正如我所说，我们没看到任何问题，而我们甚至用的就是3.8驱动……所以谁知道呢，也许我们就是运气好。

### 结论

你不得不爱上一款把你黏在座位上、让你始终保持兴趣的游戏。《使命召唤》正是如此。我仍然觉得它可能偏短了些，但对我而言，所有其他考量都压过了这个特定的问题。我把这款游戏通关了两遍，两次都很喜欢，过去几周也在多人模式里玩得非常开心。

除了长度之外，我的抱怨从整体体验来看都相当微不足道。这真是一款刺激的软件，动作游戏迷应该抓住它、狠狠地爱上它（只是当心被纸割伤）。准备好骂脏话吧，准备好开枪吧，准备好赴死吧，准备好把德国人打回他们的老窝吧。使命在召唤，士兵，你最好听它的。

-- Dan Adams

### 另一种看法

我同意丹的看法：少数几个突击队任务，与游戏其余部分相比显得有点多余、也不太合调。就像《光环》或《荣誉勋章》一样，当我觉得自己是某场战斗的一部分时，我对《使命召唤》的喜爱程度最高。当然，个人英雄主义也有发挥空间，但《使命召唤》显然把玩家放进了众多士兵中某一个人的军靴里。更棒的是，你不是发号施令的那个人，所以你不必操心去指挥小队成员。

这种开放式的协作战斗感，有时会被游戏更紧凑、更线性的空间所削弱。在最好的情况下，它讲的是在开阔环境中穿行、找到能良好观察敌人的好掩体。在最糟的情况下，它讲的是在又一条走廊的拐角处探头张望。虽然以建筑为场景的关卡带来了不错的变化，但我发现那些轨道射击式的段落打断动作太多，以至于抵消了受限关卡更传统的《反恐精英》式玩法。

但即便在较弱的时刻，《使命召唤》依然爽快得要命。我们经常谈论自己喜爱游戏的电影化品质。精心的节奏、令人信服的对话，以及全面的视觉呈现，能让一些游戏接近互动电影的水平。这里战斗的情感氛围相当强烈，你自己成功与失败所带来的后果也一目了然、意味深长。

直到现在，每当我渴望一些离线经典二战射击游戏的动作体验时，我都会在《荣誉勋章》里找到。多亏了Infinity Ward，现在我又多了一个解馋的新去处。

-- Steve Butts
