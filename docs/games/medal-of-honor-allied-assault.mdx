# 荣誉勋章：联合袭击

> 来源：IGN（https://www.ign.com/articles/2002/01/19/medal-of-honor-allied-assault-2）· 作者：Dan Adams · 发布：2002-01-19 · IGN 评分：9.3/10（amazing）

尽管第二次世界大战长期以来一直是灵感与想象的稳定源泉，但二战在大众想象中的复兴正开展得如火如荼。斯蒂芬·安布罗斯和《拯救大兵瑞恩》在很大程度上延续了上个十年五十周年纪念活动所激起的势头。最新加入这一行列的是EA的《荣誉勋章：联合袭击》。这是该系列（由史蒂文·斯皮尔伯格的梦工厂打造）首次登陆PC，虽然早就该来了，但也确实值得等待。

《荣誉勋章》就像一部极其精彩的电影。我玩过的另一款在电影化风格上能与之比肩的游戏，只有《血色苍穹》。关卡非常自然、令人信服，任务脚本精良，节奏感极佳。而且游戏的所有个性都在几乎没有真正的过场动画的情况下得以呈现。除了任务简报之外，所有动作和故事都发生在游玩过程中。可惜的是，这种做法让游戏的结尾显得有点突兀，但当人们谈论出色的呈现时，说的就是这个。

直到你第二遍通关，才会明显察觉这款游戏投入了大量脚本设计。那些第一次玩时显得如此即兴的角色和情境，突然开始显得有些可预测了。奥马哈海滩的登陆就是一个很好的例子。当一个个士兵冲上海滩时，他们每次都会遭遇相同的情境、抵达相同的位置。

但即便你第一次通关，大概也会注意到几处这样的情况。其一，你的战友受制于一种你无法改变的命运的严苛摆布——无论你读档多少次。角色到了该死的时候就会死，你无能为力。在一个较早任务的开始，这点尤其令人沮丧：你的一名弟兄尽管你竭尽全力去救，还是死了。这显得廉价又专断（更别提在第八九次读档之后有多气人了）。同样，如果某个角色注定不会死，你可以眼睁睁看着他被打成筛子也照样不倒。

但这一切仍然如此引人入胜，以至于你并不会真的在意那些脚本化的部分。战役始于1942年营救一名OSS军官，终于摧毁一个……好吧，这个我就不剧透了，只能说是在三年之后结束。虽然你会从阿尔及利亚一路杀到挪威、干掉大量士兵，但这只是游戏真正目标的附带品——炸毁纳粹的武器——从高射炮到潜艇再到整座制造工厂。一路上还必须完成许多小目标。

构成六个任务的20个关卡都相当大。一个小罗盘会帮你指向下一个目标。（和《幽灵行动》一样，它不一定能表明目标在你上方还是下方。）这些任务显得有些片段化、彼此不相关，但这里有很强的连贯感和趣味性。目标大体上以线性方式一个接一个推进（虽然也有一些灵活性），你通常总能清楚地明白一个任务为何以及如何如此推进和发展。

这款游戏里有几个瞬间很可能会长久地留在我心中。既然大家都已经知道奥马哈登陆了，那我就干脆剧透这个吧。你从希金斯艇上开始，驶向海滩。一名军官在你周围炮弹落水时下达命令。一到海滩，舱门打开，你冲上一片广阔的海滩，上面布满了“捷克刺猬”和其他形式的“隆美尔芦笋”。你必须在掩体之间推进，同时看着战友们在你四周倒下。避开炮击和机枪火力，一路冲到砾石滩。而这还只是关卡的头几分钟。奥马哈这一段确实是我玩过的最棒的东西之一，但还有许多其他精彩时刻，我在这里就不剧透了。

有些段落难到无法享受。不少地方需要你冲出去，还没搞清楚是谁在开枪就被打死。游戏中有相当多的区域，会有似乎无穷无尽的部队朝你（通常是身后）冲来。有时这说得通，有时则不然。这显得有点廉价，但其本意是逼你向前推进。无论如何，在一个你已经清理过的区域里都不能感到安全，这其实挺酷的。

作为一名特别行动人员，你本应在大多数任务中独自行动。讽刺的是，这款游戏在你作为团队一员行动时才处于最佳状态。身边有几名士兵会极大地提升你的游戏乐趣。在一队步枪手的簇拥下跑过一座小镇，简直令人兴奋不已。你真的会觉得自己是团队的一部分，而且由于你有时要听从某名友方AI士兵的指挥，你会被要求执行特定任务。十有八九，听起来会是这样：“鲍威尔，你带头，我们跟在你身后五十码，听着子弹声。”

不过，在己方加入额外部队也带来了三个较大的问题。首先，它们通常是在你很可能遭遇大量敌人抵抗时才派给你的。一旦屏幕上有十几个人互相射击，游戏就开始卡顿。其次，你无法控制你的单位。它们有时无法安全躲开你自己引爆的炸药。第三，身边这些不对你开枪的士兵的存在，让那些预先脚本化的事件变得更加显眼。

敌方AI则稍微灵活一些。遗憾的是，敌人对周围环境的感知远超它们应有的程度。它们会锁定你，在你还看到它们之前就朝你脑袋里打进三颗子弹。在有大量掩体的开阔区域，这个问题更严重，但真是气死人。敌人通常很擅长不让自己暴露在多余的火力下，但由于它们能用的姿态比你多，这显得有点不公平。敌人可以卧倒并只露出手从拐角处射击。你却不能。真正酷的是往一个房间里扔手雷，听到德国人一阵叫喊，然后看着他们从门口跑出来。不酷的是看到你的手雷还没炸就被扔回你脸上。

好吧，那也许还是有点酷的。

武器平衡是一流的。虽然这一类型的游戏通常会让你用上各种各样的手枪、机枪、弩和土豆投石机，《荣誉勋章》却只用了少得多的武器库。但每一件都设计精良，非常适合特定的任务。少数几件新奇武器（霰弹枪和火箭筒）没有得到它们或许应得的那么多关注，但M1加兰德、狙击步枪和汤普森冲锋枪已经足够可靠，以至于你大概根本不会考虑其他武器。

很多人抱怨游戏里没有血迹。老实说，我完全不觉得这会拉低游戏。你不需要萨姆·佩金帕式的血腥效果来营造真实感或紧张感。一个漂亮的血液模型能强化这些特质，但它并不是唯一能贡献可信度或趣味性的东西。这款游戏确实有一些非常令人印象深刻的武器效果——击中身体或墙壁时扬起的小小尘雾、从门上飞溅出的木屑、以及小规模的手雷爆炸，全都是一流的，没有血迹不应该让任何人却步。何况，青少年分级意味着你在线上会有更多人可对战。

由于游戏尚未发售，我们还无法测试网络对战。不过我们玩了很多局域网对战，假设网络对战时性能不会大幅下降，《荣誉勋章》绝对有实力与《德军总部》一较高下。与《德军总部》中选择兵种不同，你要选择携带一件武器。这多少设定了你在游戏中的角色，但似乎并不要求《德军总部》那种程度的配合。等服务器上人更多一些后，我们会在本月晚些时候的另一篇IGNsider特稿里介绍多人对战的基础内容。

为了充分体会游戏的完整效果，你需要一台真正强悍的机器。幸运的是，一套出色的配置设置让你可以微调各项细节，找到画面与性能的最佳组合。我在家里用一台P500MHz、512MB内存、GeForce 2的机器，以800x600分辨率、中等细节游玩时只有几次卡顿。在更好的系统上，你可以期待大幅提升的画面和运行表现。

即便是在中等细节水平下，这款游戏也美得惊人。人物面部和角色模型逼真可信得不可思议。动画和表情让你真切感到游戏中的角色是各不相同的个体（即便在你朝他们开枪时很难分辨谁是谁）。建筑令人惊叹，城市完全可信。地面贴图大概是游戏中唯一真正的弱项，但即便这些也还过得去。

塔尔在某个周末向我指出，游戏里的油桶中装有真实体积的液体。你朝它们射击时，液体会流出来。你在桶上打出更多洞，它流得就更快。而且液面高度也被建模了，所以如果你打中桶的顶部，液体只会流一小会儿；如果你打中底部，液体会一直流到全部流光。探照灯周围有一群群飞蛾环绕。如果你把灯打灭，会得到一片火花作为奖赏。正是这些细节，在把你拉进游戏方面产生了巨大的差别。

音效也拥有同样程度的细节。武器的声音全都极其令人满足。（我爱M1加兰德退出弹夹时那声“叮”。）爆炸和引擎声会让你的低音炮真正得到锻炼，而配乐则颇具电影感。游戏中的配音相当不错，而且与《德军总部》不同，所有这些德国人都说的是正确的语言。

自从我在这里工作以来，我只会回头重玩过三款已经通关的射击游戏——《半条命》、《命运战士》和《无人永生》。但在圣诞假期里，我把《荣誉勋章》通关了好几遍，而且很可能在今年结束前还会再玩几遍。你也会的。虽然这款游戏有一些小（但恼人的）问题，整体效果却是深远的。我唯一不会推荐这款游戏的对象，就是那些单纯讨厌动作游戏的人，以及没有电脑的人。除此之外，你都应该入手它，并取消未来一周左右的安排。除非你叫丹·亚当斯，那样的话，我完全期待你下周来上班。

-- Steve Butts

### 结论

鉴于我最近刚评测过《重返德军总部》，我本来就相当兴奋能有机会玩到《荣誉勋章》。然后，在我被隔离去履行陪审团义务期间，和我共事的那些混蛋却有机会去EA玩了单人模式和一堆多人模式。我在工作时往他们电脑里撒了尿之后（他们还以为自己的问题跟病毒有关……），我又是哀嚎又是哭闹，最后过了好久，我才终于有机会把游戏拿到自己手里，好好爱它一下。在听了那三位（也就是史蒂夫、伊万和塔尔）的狂热赞美后，我以为这游戏肯定是被上帝触碰过。它的一部分确实如此。但大部分并非如此。别误会，这款游戏很棒，我只是希望有更多那种AI部队跟着你、帮你的关卡。在奥马哈海滩上冲锋、和战友们一起攻下一座被摧毁的城市，真是太过瘾了。他们的命令、声音甚至脸上的表情，有时都令人惊叹。

不幸的是，那该死的AI有着疯狂的精准度和全知的眼睛，让游戏的一些部分几乎变得不好玩。但在我通关、熬过这一切之后，我确实非常满意。这是一款超好玩的游戏，即便有问题，在某些地方也堪称绝妙。遗憾的是我还没机会玩多人模式，但据我所听到的一切，它就算不比《重返德军总部》更好，也至少一样好。绝对值得任何动作游戏迷入手。
