# 马力欧卡丁车8 豪华版

<Tabs groupId="review-source">
  <TabItem value="ign" label="IGN">
![马力欧卡丁车8 豪华版 IGN 评测头图](/img/reviews/mario-kart-8-deluxe.jpg)

> 来源：IGN（https://www.ign.com/articles/2017/04/20/mario-kart-8-deluxe-review）· 作者：Jose Otero · 发布：2017-04-20 · IGN 评分：9.3/10（amazing）

《马力欧卡丁车8 豪华版》（Mario Kart 8 Deluxe）是 Wii U 平台《马力欧卡丁车8》的强化版。将近三年前我评测《马力欧卡丁车8》时，认为它是一款出色的游戏，给了它 9.0 分。以下是我当时的原话：

“《马力欧卡丁车8》是任天堂长期以来做过最好的卡丁车竞速游戏。它在精炼旧点子与引入新鲜点子之间取得了谨慎的平衡。诚然，它华丽的画面和爵士风格管弦配乐提升了整体呈现，但这款游戏给你的远不止外观——尽管我花了大量时间对着慢动作里的细节啧啧称奇，真正让我一再回来的，是与朋友在本地和线上竞速时那种又快又猛的节奏。”

《马力欧卡丁车8 豪华版》包含上述一切，外加此前发布的所有 DLC 以及一些新增内容。这意味着你将获得 48 条出色的赛道和 42 名各具特色的角色，其中包括酷霸王Jr.（Bowser Jr.）和《斯普拉遁》（Splatoon）里的乌贼娘等新角色，还有一些很棒的额外内容，比如快得难以置信的 200cc 速度级别。每条赛道、每个角色和每个模式都从一开始就解锁，意味着你可以直接上手开跑。

唯一执行得奇怪的新增内容是智能转向（Smart Steering），这是一项旨在帮助新手玩家保持在赛道上的新功能。考虑为新手提供帮助、让他们理解像《马力欧卡丁车》这样规则简单的游戏，这个想法本身一点也不坏，但任天堂选择默认开启智能转向，而在菜单里如何关闭它并不一目了然。除了这个恼人的小毛病，这个合集是一款内容丰富的优质卡丁车竞速游戏。

> 它在 2017 年和 2014 年一样出色

《马力欧卡丁车8 豪华版》在 Switch 上也表现出色！它在 2017 年和 2014 年一样出色，而出色的美术指导正是其画面经得起时间考验的主要原因。尤其是赛道设计，堪称顶尖——我喜欢马力欧赛道（Mario Circuit）像莫比乌斯环一样扭曲弯折的样子。即便是重制的赛道，比如 SNES 彩虹之路（Rainbow Road）或《F-Zero》的寂静之城（Mute City），也有着令人瞩目的细节，无论你是掌机模式还是电视模式游玩都能注意到。如果你在一台 Switch 上与三到四名玩家同玩，帧率确实会从每秒 60 帧降到 30 帧，但当竞速看起来如此出色时，这很难算是什么决定性的问题。

如果你已经有 Wii U 版，那么入手《马力欧卡丁车8 豪华版》的真正理由是全面革新的对战模式（Battle mode）。任天堂新增了五个巧妙的目标导向模式，每一个都在其八个各不相同的竞技场中带来独特的竞技角度。在气球大战（Balloon Battle）中，你必须利用道具和聪明的走位，通过扎爆对手的气球来得分。偷光者（Shine Thief）是对“抓人游戏”疯狂而动作感十足的花样演绎。炸弹兵爆破（Bob-bomb Blast）则是一场爆炸性、夸张到极致的对决。不过，我倒希望自己能更有动力去玩金币收集者（Coin Runners）。收集金币或从别人身上抢金币还算可以，但相比之下远没有那么刺激。

最大的亮点是“亡命之徒集结”（Renegade Roundup）那种充满悬念的战或逃本质。这是一个回合制模式，一队亡命之徒拼命躲避一队食人花警察，直到计时结束。如果有队友被抓，你可以靠高超的车技把他们救出来，但代价是若你是最后幸存者，就有被抓、输掉比赛的风险。这造就了紧张的一决胜负时刻，配上合适的队伍，可以真正令人热血沸腾。这些模式你都可以对抗不同智能程度的机器人游玩，但真正的乐趣在线上。

> 《马力欧卡丁车8 豪华版》的线上内容依然同样简陋

话虽如此，《马力欧卡丁车8 豪华版》的线上内容在 Switch 上依然和在 Wii U 上一样简陋。它的一些改进值得注意——例如，它能更快地让你进入一局游戏，而且你终于可以在比赛之间更换角色或卡丁车了。但与其他系统的便利相比，Switch 仍让人觉得麻烦，因为你还是得借助外部手段（比如手机）才能与朋友交流。没有办法邀请玩家加入你的比赛，这一点也令人恼火。考虑到这是 Switch 上的首款大型线上多人游戏，看到在理顺这一体验方面所做甚少，实在令人失望。

### 总评

《马力欧卡丁车8 豪华版》是一款出色的游戏，理由与我最初评测中提到的完全相同。它仍是一款华丽的卡丁车竞速游戏，和 2014 年时一样令人上瘾。这是该系列迄今为止最好的一作，拥有你所需的一切内容。回归的玩家此前已经见过这款游戏的许多内容，但全面革新的对战模式及其五种额外玩法是入手的绝佳理由。任天堂在改善线上体验方面做得不够，但这款游戏的其他部分都保持得很好。
