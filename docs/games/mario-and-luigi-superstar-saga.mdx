# 马力欧与路易吉RPG

![马力欧与路易吉RPG 游戏头图](/img/reviews-webp/mario-and-luigi-superstar-saga.webp)

<ReviewTabs slug="mario-and-luigi-superstar-saga">

<ReviewTab id="gamespot" site="gamespot" label="GameSpot">

> 来源：[GameSpot](https://www.gamespot.com/reviews/mario-and-luigi-superstar-saga/1900-6083876/) · 作者：Ricardo Torres · 发布：2003-11-18 · 评分：9.2/10

《马力欧与路易吉 RPG》是一款动作 RPG，让马力欧兄弟在 Game Boy Advance 上展开一段原创冒险。这款精致的游戏是马力欧系列第三次涉足 RPG 类型。第一部 Super Nintendo 的《超级马力欧 RPG》是与 Squaresoft 合作诞生的经典明珠，第二部 Nintendo 64 的《纸片马力欧》由 Intelligent Systems 开发。这一最新作品由 Alpha Dream 开发，是对传统动作 RPG 体验的一次有趣而迷人的演绎，等量混合了令人印象深刻的技术、创新和幽默。最终结果与它的 Super Nintendo 和 Nintendo 64 前辈一样，带来了一段有趣、迷人的体验，不容错过。简而言之，它是今年最好的 GBA 游戏之一。

游戏的故事围绕两人试图抓住邪恶的卡克莱塔展开——这位来自邻国豆豆王国的强大女巫偷走了碧姬公主的声音。失去声音的碧姬只能说出一些奇怪符号，一吐出口就爆炸。虽然碧姬的状况对她的宫廷成员来说相当令人担忧，但对长期绑架犯酷霸王来说尤其令人不安——他在卡克莱塔袭击后不久赶到，想记上一笔高质量的绑架时光。由于担心她爆炸性的话语会毁掉自己的城堡而无法绑走碧姬，酷霸王提出帮马力欧追查卡克莱塔，并帮忙恢复碧姬的声音……好让他能绑架她。一连串不幸的事件，涉及酷霸王的喽啰和路易吉，让马力欧的弟弟——通常乐于留守后方——也一起上了路。这个疯狂的前提为穿越豆豆王国的滑稽冒险做了完美的过渡，兄弟俩将面对各种危险。

《马力欧与路易吉》的玩法骨子里是一款动作 RPG，与经典的 Super Nintendo《超级马力欧 RPG》和 Nintendo 64《纸片马力欧》一脉相承。你会漫游整个豆豆王国，试图挫败卡克莱塔的邪恶计划。你会在回合制战斗里面对各种敌人，解开谜题，穿行于地牢式环境。虽然《马力欧与路易吉》听起来可能只是又一款动作 RPG，但游戏的双角色机制提供了极其新鲜、独特的玩法体验。你甚至会遇到一些令人想起之前马力欧游戏里滚木桶和平台跳跃的桥段，融入这套迷人的配方。

游戏中你能主动操控两兄弟，这为冒险带来了全新的转折。你用方向键移动兄弟俩，通过 A 和 B 键能分别独立操控两个角色。虽然每个兄弟起初只会简单的跳跃，但随着游戏推进，各自都会获得使用锤子和施展不同特殊招式的本领。每个兄弟可用的招式取决于马力欧还是路易吉在前，你能按 Start 键随时切换两人。当你为兄弟俩获得更多能力后，可以用肩键轮换它们，两个肩键分别轮换分配给它们的特定能力。

你获得特殊招式后，能以不同方式与环境互动，也能进入游戏中的新区域。比如，兄弟俩拿到锤子后就能砸碎挡路的岩石。当他们学会特殊的元素手部攻击后，就能触发特定的开关。比如，马力欧的火焰手能点亮某些开关，而路易吉的雷电手能激活另一些。此外，当由不在前的兄弟触发时，手部能力还有次要功能。马力欧的火焰能点燃路易吉的屁股。这让两人高速奔跑，从而变成有效的攻城槌。路易吉的雷电技巧能电击马力欧，也把两人锁定在前冲姿势，让他们移动时不必转身。这对付那些你正面朝向就会消失的 Boo 开关再合适不过。兄弟俩还能以同样有创意的方式用锤子互相作用。路易吉在前时，马力欧能把他锤进地里，让他钻到某些障碍物下面或挖出隐藏物品。马力欧在前时，路易吉能把他敲成迷你形态，好钻进小洞。兄弟俩也有远没那么暴力的合作方式，比如用路易吉做一次超高跳，或用马力欧做一次特殊的螺旋跳，让两人飘过沟壑。

独特的双人操控机制延伸到战斗系统，它是《超级马力欧 RPG》开创的回合制系统的延伸，要求你在攻击中把握按键时机。你走进敌人来触发战斗，进入战斗画面。和探索部分一样，你仍能通过 A 和 B 键主动操控角色，用它们为马力欧和路易吉做选择。每个兄弟在战斗中有四个选项：单独攻击、兄弟攻击、逃跑和道具。单独攻击让你跳跃、使用锤子，和/或使用该兄弟的元素手部能力打击敌人——取决于你在游戏中获得了哪种元素。选定攻击后，你能在攻击的兄弟出手前按下他的按键来增加伤害量。如果成功，攻击会造成稍多伤害。每个兄弟有三类单独攻击：简单跳跃、锤击和手部攻击。兄弟攻击是需要马力欧和路易吉合作的特殊连招。

你最终会找到三种可选的攻击：一种武装攻击、一种锤击、一种手部能力攻击。这些攻击消耗固定数量的"兄弟点数"，需要一系列按时的按键输入才能成功施展。攻击分三个威力等级。前两个威力等级会放慢动作，并在屏幕上提示何时按键。第三个、也是最高的威力等级不提供按键提示，以正常速度进行，让攻击难以成功施展。如你所料，威力等级越高，攻击造成的伤害越大。额外好处是，一旦你成功施展足够多次，攻击还能升级到高级阶段，进一步提高伤害。道具选项让你在一回合中使用库存里的道具，增强兄弟俩的血量或兄弟点数槽。逃跑选项让你猛按按键、直到兄弟俩跑出屏幕来逃离战斗。代价是，逃跑途中他们会不断失去金币，直到离开战场。尽管上述玩法相当繁复，游戏的操作却紧凑灵敏。

击败敌人会奖励你道具、金币和经验，让马力欧和路易吉升级。升级会提升兄弟俩各方面的属性。虽然大多数属性，如生命值、兄弟点数、力量、防御和速度，都不言自明，但神秘的"胡子"属性值得解释一下。似乎兄弟俩的胡子评分越高，他们的胡子就越有光泽。拥有一副气派的胡子在游戏里带来不少好处。战斗中，马力欧和路易吉更有可能打出暴击幸运一击，对敌人造成大得多的伤害。造访城镇时，浓密的胡子会让店主眼花，给你大幅打折。这是对标准动作 RPG 内容的一个轻松点缀，会让你为两人买新背带裤、给他们装备提升各种能力的徽章。你还能期待找到支线任务，比如收集各种豆子，在当地的星豆咖啡店换取独特物品。此外，还加入了各种小游戏来补充内容充实的主线——这段旅程会让你忙碌 20 小时以上。游戏还包括出现在之前 GBA 马力欧游戏里的同一款多人《超级马力欧兄弟》，到了这一步，它早就赖着不走了。

游戏的画面有一种微妙的魅力，得益于硕大细致的角色精灵和环境。角色阵容混合了新面孔和大量马力欧宇宙里熟悉面孔的客串，全都设计精良。动画是一流的，加入了数量惊人的微妙细节，为这群色彩缤纷的角色注入充足个性。环境方面，豆豆王国呈现了数量可观的可探索场景，提供了你在马力欧游戏里期待的那种多样性。在救公主的旅途中，你会跋涉穿过森林、洞穴、水下区域、沙漠等等。这些区域有独特、细致的外观，充满个性。环境还带有令人惊讶的大量动画，与其干净细致的外观相得益彰。比如，你会看到瀑布旁流水飞溅，或海滩上潮汐的涨落。环境最令人印象深刻的方面之一，是那些暗示地下埋藏物体或其他兴趣点的微妙视觉线索。视觉上的精致也延伸到查看兄弟俩属性时的彩色动画菜单，菜单里有他们的特写。这套令人印象深刻的组合有一个明显的瑕疵，就是偶尔让开关或跳跃有点困难的略别扭的视角。不过充其量只是个小烦恼。

音频是原创音乐与许多系列熟悉主题、标准马力欧游戏音效以及大量语音采样的令人印象深刻的混合。游戏的音乐提供了一批上口、多样的原创曲调，帮助赋予豆豆王国独特的感觉。原创音乐还包括忠于某些最上口曲调精神的新曲目。新音乐由许多之前马力欧游戏里的熟悉主题补充。你会注意到某些音轨有相当多的循环，但多亏了上口的曲调，你不会被逼疯。音效大量使用大多数现代马力欧游戏里久经考验的声音，并为音频典籍又添了几笔。游戏里的语音量之大令人惊喜。马力欧和路易吉在整款游戏中相当健谈，与其他角色互动、彼此互动时发出感叹和胡言乱语。其他主要角色也有不少语音，无疑帮它们注入了不少个性。这些单独的部分最终组合成一个令人印象深刻的整体，是今年 Game Boy Advance 上最丰富的音效呈现之一。

最终，《马力欧与路易吉 RPG》是马力欧系列令人印象深刻的新成员，不容错过。强劲的画面、滑稽的故事、丰富的玩法和漫长的旅程，共同造就了今年 Game Boy Advance 上最好的体验之一。它也有一些在 GameCube 上玩的价值，因为配合 Game Boy Player 使用时支持震动。唯一的抱怨是缺乏任何形式的多人支持，但那是小事。作为很可能成为 GBA 系列的第一部作品，《马力欧与路易吉》在各方面都交足了功课。

> 来源：[Eurogamer](https://www.eurogamer.net/r-marioandluigi-gba) · 作者：Tom Bramwell · 发布：2003-12-08 · 评分：9/10

你很可能从没玩过马力欧 RPG。这不会让你变成坏人。你甚至可能不知道自己错过了什么。毕竟，这种把原型平台游戏主角与角色扮演游戏从容的节奏和大量叙事结合在一起的奇特组合，最初几乎没能跨过大西洋。采用 Rare 在游戏中首创的 ACM 图形技术的等距视角作品《超级马力欧 RPG》，原本是任天堂与 Squaresoft 的梦幻合作，尽管在日本和美国好评如潮，却从未在英国或欧洲发售。这件事我抱怨了好多年。

与此同时，《纸片马力欧》在 N64 生命周期的末尾得到了荒谬地有限的发售，同样悄无声息地溜过了雷达。Intelligent Systems 这款 2D/3D 铅笔手绘风格的作品，在风格上大概比初代 SMRPG 更是《马力欧与路易吉》的前身，而且好到值得根据任天堂最新的发售计划来一次 Cube 版更新，它当然也迷人地简单、平易近人。真要说的话，它更多是因其作为 RPG 的野心而受苦——在那些 A 键不是用来猛按、B 键更多调出物品清单而非想起火球攻击或奔跑修正的家里遭到批评，只因它胆敢偏离普遍接受的套路。你能和最小的孩子一起愉快地玩它，是另一个模糊的问题。

然而，《马力欧与路易吉》真正把脚跺在欧洲板栗仔的头上，无疑还蹦跳着向上领一颗蘑菇形状的奖励，因为它成功取悦了所有人。开发方 Alpha Dream 没有把现有的角色和点子硬塞进传统 RPG 的模子里，而是反其道而行之——审视角色的强弱、他们的工具、能力和环境，打造出一款出类拔萃又幽默的 RPG，它改良式地重塑了回合制战斗，在纯粹的巧思上也挑战最好的《塞尔达》。它还成为今年极少数配得上其价签的 GBA 游戏之一，并且真的在欧洲发售了。吸鼻子！还有什么可说的？幸运的是，可说的还很多。

## 超级

《马力欧与路易吉》骨子里是一款带回合制战斗、设定必然甜腻的动作 RPG。但即便在这里，游戏也避开了陈词滥调，因为原来酷霸王并没有绑架碧姬公主，而是邻国豆豆王国的卡克莱塔假扮来访贵宾偷走了公主的嗓音，让她只能说出一些奇怪符号，一吐出口就爆炸。为了追捕卡克莱塔、找回碧姬闪闪发亮的声音，马力欧和路易吉很快得到一个意想不到的盟友——酷霸王！他们之间毫无情分可言，但酷霸王显然和大家一样对卡克莱塔的邪恶计划火冒三丈，因为如果公主每句话都是塞了 C4 的毒药，他根本没法现身绑架她。不幸的是，他们联手对抗卡克莱塔的计划很快告吹，但 M 和 L 会在整款游戏里的一系列搞笑对峙中撞见酷霸王。其他熟面孔也会冒出来，每一句对白、每一个能认出的客串都以充满爱意的幽默处理——比如，一个贯穿的笑点是，大多数人只有在看到马力欧兄弟能跳多高时才认出他们……

而他们依旧跳。常常一起跳。贯穿《马力欧与路易吉》，无论是解游戏地牢式环境里的简单谜题，还是应付头目遭遇，他们原有的能力和双人组合的动态都驱动着玩法。两个角色随时能做出各种动作，A 键映射给前面角色的招式，B 键给后面角色。你可以用 Start 键切换他们的行动顺序，用肩键轮换每个角色的单独能力。起初这是套非常简单的系统，你会用它跳过成排的尖刺（让马力欧用 A 跳、路易吉随即用 B 跟上），操作移动平台之类的东西（按 A 和 B 让两人交替跳），最终组合出诸如用锤子把马力欧压扁以便钻过小洞，或把你的旋转跳悬浮技巧与一阵阵旋风配合、飘过更大的距离。

解谜和探索依赖马力欧与路易吉的独特能力以及他们如何协作，而像《塞尔达》一样，游戏通过 NPC 教程逐步教你组合能力。其实整体结构很大程度上很像《塞尔达》，随着逐步揭示，你能打开那些初次探索环境时或许看到、或许没看到的隐藏门。台词和关键事件会撩拨你想起那些挠头的问题，比如"我在洞穴里该怎么越过那个像犰狳的壮家伙？"，因为兄弟俩的锤子之类新增能力让他们能砸开通往新区域的路，而马力欧的火焰手能点燃路易吉的屁股、把两人像攻城槌一样拖着撞穿更坚硬的地表。

## 时间不多了

虽然我把解谜和探索比作《塞尔达》，战斗也值得和《时空之轮》比较一下。至少某种程度上……好吧，它们并没有太多共同点，但确实共享一个非常明显而关键的元素——你可以挑选战斗。当然会有因为叙事原因被迫与特定敌人交战，或某处景物挡住视线、你一头撞进麻烦的时候，但这里的敌人以精灵形式画在屏幕上，稍加努力你就能愉快地避开撞上它们（或它们撞上你）。虽然如果你经常回避战斗，到后面面对更难的挑战时会惨兮兮地准备不足，但能有这个选项总是好的。随机战斗实在是个陈腐的公式，不用操心下一步是否会让你花五分钟乏味地猛按按键，要好得多。

或许讽刺的是，随机战斗在《马力欧与路易吉》里本来也不会让人觉得多烦，因为它还有我多年来见过的最巧妙的回合制战斗机制之一（甚至胜过常被忽视的《影之心》里的"命运之轮"技巧）。而它做到这一点，只需借一点马力欧系列对像素级精确和时机的传统痴迷。但别担心，它其实非常简单，也不那么紧张。比如游戏开始时，两个角色的主要攻击都只是跳到敌人头上弹一下。虽然你确实可以按 A 选择"单独攻击"、再按几下选择跳跃攻击，但如果你在角色与敌人接触的精确瞬间按 A，几乎肯定能削掉更多血量。随着游戏推进，你得掌握不同的时机要素，比如等锤子武器开始振动再按攻击键，还有"兄弟攻击"这个聪明的风险/回报系统——双人配合的招式，让一个兄弟像棒球一样把另一个打飞，或互相踩头以获得速度和高度。虽然这些无疑会带来更多麻烦，它们也需要非常特定的时机才能发挥最大威力（可选择限制其效果，但换来慢动作和按键提示），而且它们还会消耗"兄弟点数"，相当于游戏里的魔法货币。

仅这一点就是个值得庆贺的战斗系统，但当你考虑到能闪避敌人攻击之类的东西时，听起来就更棒了。虽然巧妙的是，要闪避每一次攻击非常难，但凭借一些练习和直觉，你能相对毫发无伤地打完一场仗。而且闪避不是让战斗更无聊，反而增强了兴奋感，因为你真的必须时刻保持警觉——尤其因为你不能暂停战斗。更妙的是，当你面对一个新敌人、不知道他的攻击套路时，它还添了一种趣味与忐忑——这种感觉是今年许多圣诞档的"指哪打哪"流水线作品该努力传达的。

## 魔法豆

这是近年来最引人入胜的 RPG 之一，几乎一切都让你微笑。它是那种你会沉醉其中的游戏世界，即便迷路或卡住时也是——看着一个肚子灌满水的臃肿马力欧摇摇摆摆地走动，你忍不住纵情咯咯笑，然后又咧嘴笑看路易吉第一次跳上他的头、把水从他嘴里喷出来。你甚至会心照不宣地微笑，看着熟悉的道具和角色如何融入游戏世界——蘑菇当回血道具、1-up 复活倒下的同伴、空中的问号砖块藏着道具和强化，等等，还有豆豆王国边境的守卫让你在一条晃动的绳子上跳过好几次，以在背景里那座眼熟的城堡上升起一面旗……

当然你也会升级、接下支线任务、在穿越某些区域时玩小游戏（比如巧妙无比的矿车/手电筒桥段），甚至可能把卡带接到朋友的 GBA 上玩原版街机《马力欧兄弟》游戏（好吧，如今没人有耐心玩那个了），但总体上你只会觉得它彻底引人入胜、原创又有趣。完成团队谜题、智胜设计师所带来的满足感，是今年极少数其他游戏能提供的（也许《波斯王子》算一个）。这是一部现代杰作，每一刻都被经典马力欧曲调激昂的演绎唤醒，配上一批原创作品（它们能与如此经典的配乐无缝并肩，几乎本身就值得加一分），还有出人意料地顺耳的对话——既好笑又可爱地幼稚——马力欧和路易吉用数字化语音"Wahoo！"着度过许多小时奢华细节的冒险。

即便在 Game Boy Player 和大电视上玩，星野和那听起来傻乎乎的"呜呼大学"的古怪环境也被生动地呈现、清晰可辨、赏心悦目，满是色彩缤纷、富有想象力的角色。兄弟俩对于一对蹦蹦蹲蹲的水管工来说出奇地有表情，这很大程度上归功于他们硕大的角色精灵和精细的动画（精细到路易吉掰开马力欧的嘴、塞进一颗 1-up 蘑菇把他救活），而一些头目角色也很精彩，比如山顶的怪物，它掌握着游戏最有趣的原创角色之一——豆豆王国王子——的秘密。

## 最好的之一……

总的来说，这是一款我很少犹豫去推荐的游戏。有时镜头会让你难以准确判断开关或跳跃的透视，有时某个特定的团队能力需要你在狭窄平台上移动以找到必要的空间，但需要多走几步或挪一下的不便很少值得一提（而且从不致命，也不特别有害）。更重要的是，由于能力如此多、按键却如此少，再加上需要经常切换角色，你的手指有搞错、按错东西的倾向。在最初几个小时后，我常常发现自己得费劲思考哪个角色需要什么、在哪、何时。不过除了偶尔按错键，这是一款非常难以挑刺的游戏。

当然，我们掌机评测的老读者会知道，许多游戏表现出色却在最后一道栏前栽倒——一道标着"耐玩度"的又大又刺眼的多彩栏——而且玩《马力欧与路易吉》早期区域时，确实会担心它几个小时内就会干净利落地收尾。它开头相当线性，地图看起来也没那么大，但几小时后它就打开了，事情变得不那么直白。说实话，通关时间的估计各异，真正取决于你打算多彻底，但 15 到 25 小时大概差不多，而重点只是：这是一款 Game Boy 游戏，不仅长度体面，还有合理的重玩价值前景。我肯定会回来再玩，哪怕只是提醒自己，"RPG"也可以意味着一段平稳、易懂的旅程，与对简单而巧妙设计的礼赞相结合。

平心而论，这也带来一个小小的保留。严格传统 RPG 的粉丝——那种整个体验里最有活力、最依赖反应的环节就是撕开玻璃纸、卖力消化说明书的玩家——大概不会在这里找到他们想要的东西。不过对其他人来说，它拿到整整三个 OOTB——它是今年最好的 GBA 游戏之一、最好的 GBA 任天堂游戏之一，也是有史以来最好的 RPG 之一。简单、有趣、有回报，这是献给所有曾对初代马力欧 RPG 垂涎却从未玩过的人，也献给除此之外的所有人……
