# 推拉方块

<ReviewTabs slug="pushmo">

<ReviewTab id="ign" site="ign" label="IGN">

> 来源：[IGN](https://www.ign.com/articles/2011/12/08/pushmo-review) · 作者：Lucas M. Thomas · 发布：2011-12-08 · 评分：9.5/10

直到第一个完整年度的年末，任天堂的 3DS 似乎才终于全速运转起来。几周前《超级马力欧 3D乐园》的发售，为这台主机在实体卡带方面补上了它所需的杀手级作品。随后，本周早些时候推送的新固件更新又让主机内置软件本身迎头赶上，终于启用了诸如 3D 视频录制等承诺已久的内置功能。

而今天呢？三件套就此凑齐——因为除了在实体包装游戏和内置应用上都拿出了真正的佳作之外，任天堂终于为我们带来了一款独占的、仅限下载的 eShop 作品，而且绝对是一款必买之作。女士们先生们，我向你们介绍《推拉方块》。

本作由 Intelligent Systems 开发——就是那群以《高级战争》《火焰之纹章》《纸片马力欧》和《瓦力欧制造》系列闻名的聪明人——《推拉方块》是一款极具原创性、绝对迷人、又时常刁钻的便携解谜小品。游戏中你扮演马洛（Mallo），一个快乐、圆滚滚的主角，任务是救出被困在某种独特游乐设施——也就是“推拉方块”——里面的孩子们。每个推拉方块都是一摞彩色方块，马洛必须在每道谜题中推、拉并跳跃穿行于各个方块顶部，才能抵达顶端那个关着孩子的箱子所在的位置。

一眼就能看出这款游戏是专门为 3DS 开发的，因为每个推拉方块的呈现方式都最大化了主机的立体视觉特效。每关开始时，马洛走向那摞方块，而它们最初都平贴在背景上。随后他抓住一个方块向前拉——向前景拉出一步——它自然也就同时“更靠近”你的脸。他可以再拉一次到更远的第二段距离，最后再拉一次到最远的、离你最近的第三段距离。

这太不可思议了。它本不该显得如此惊艳，因为这些并不是华丽的爆炸或张牙舞爪扑向你的敌人角色——它们只是方块而已。但这些方块在立体的简洁中显得非常出色。游戏那绝妙的鲜艳配色大概也有一份功劳，因为这个世界看起来就像绘儿乐（Crayola）工厂工人梦中的景象。

以典型的任天堂风格，最早的关卡会教你所有这些推拉操作的机制。一位睿智的老推拉方块建造者帕帕·布洛克斯（Papa Blox）会教你成功所需的技巧——尽管要掌握的并不多。基本思路是你需要抓住方块，并按照能为你搭出一道通往顶端的简易楼梯的顺序把它们拉出来。有时你需要从侧面抓住一个方块来拉，或者调整自己的位置，以便在不会从边缘掉下去的情况下把方块拉得更远。

但拉、推和跳就是你真正能用的全部手段——而令人惊叹的是，这一小套有限的动作为何能构成数百个不同脑筋急转弯的基础。哪怕看起来最简单的方块堆也可能变成真正的难题，而当你终于解开并通关一个卡住你的关卡时，那种满足感非常真实。（不过，同样以典型的任天堂风格，你永远不会被卡在任何一关。你可以选择跳过任何对你来说太难的关卡，稍后再回来。）

《推拉方块》超过 250 道谜题的主线战役，还由一些额外的玩法特性加以点缀，比如一种时间回溯能力，让你可以像《Catrap》《时空幻境》或《波斯王子：时之沙》那样撤销过去几秒的操作。每关还有一个重置开关，如果你想的话，可以干脆抹掉所有进度从头再来；后期关卡则通过引入梯子和管道来打乱“搭建方块楼梯”的基本概念——管道有点像马力欧的传送水管，迫使你抵达方块堆上的不同位置，钻进去，再从结构上的另一处冒出来。

所有这些额外元素都带来了便利，也延长了你通关《推拉方块》默认挑战集所需的时间，但随后真正制胜的额外功能登场了——推拉方块工作室（Pushmo Studio）。只要你通关游戏的第一组教学关卡，它就会解锁，你可以在工作室里创作自己的关卡。更棒的是，你还能生成自己作品的二维码，以便和同一个房间或互联网另一端的玩友分享。

我看得出这会让人上瘾，毫无疑问，推拉方块的社群已经在互联网论坛上形成，互相交换各自最拿手的脑筋急转弯和/或复刻的 NES 像素图。（这也算是个额外福利，因为这些方块谜题天然契合任天堂怀旧情结——公司肯定也意识到了这一点，因为在马洛的冒险途中你会遇到一两张熟悉的马力欧面孔。）

你现在被《推拉方块》说服了吗？你应该被说服了——它很出色。但尽管游戏如此优秀，我确实还是有一个小小的抱怨。《推拉方块》并不支持任何“擦肩”功能。

任天堂若在《推拉方块》里加入 StreetPass 或 SpotPass 支持，那本会是额外的用心，但遗憾的是两者都没能实现。StreetPass 功能本可以让我把自己最喜欢的自创谜题分享给无线擦肩遇到的路人，或者 SpotPass 本可以每天自动下载一个由任天堂自家设计师制作（或从社区投稿中挑选）的新关卡。缺少这些功能确实令人遗憾——但这真的只是个小抱怨，而且对二维码的依赖从长远来看应该能确保关卡分享过程显得更加私人。

是的，3DS 花了很长时间才站稳脚跟。3DS eShop 呢？更久。但《推拉方块》的问世要求所有任天堂最新掌机的拥有者都站起来关注这家公司最新的下载商店，因为它是一款绝对的必买之作。eShop 一直需要的第一方杀手级作品就在这里——而且甚至超越了 3DS 本身，这很可能是有史以来任天堂以任何形式提供过的最好的下载游戏。

<ReviewTab id="gamespot" site="gamespot" label="GameSpot">

> 来源：[GameSpot](https://www.gamespot.com/reviews/pushmo-review/1900-6348267/) · 作者：Britton Peele · 发布：2012-01-05 · 评分：8.5/10

一款解谜游戏能让人感到真正新鲜而特别，这并不常见。这一类型中的佳作往往玩法简单、易于上手，但如果你想要挑战，又能变得极其困难。《推拉方块》不仅具备这些，还更胜一筹，使它不仅成为 3DS eShop 上一款出色的下载游戏，更是该主机上最吸引人的解谜游戏之一。

《推拉方块》的核心就是拉拽和推动方块，以便攀爬到它们所构成的巨大结构的顶端。每道谜题（也叫“推拉方块”）起初都是一幅相对扁平、无法攀爬的图像。你的角色马洛可以行走和跳跃，但更重要的是他能抓住构成一个推拉方块的单个方块。理想情况下，你把某个方块拉出几格，跳到它上面，再把下一个更高的方块拉出一点点，如此反复直到抵达顶端。然而，你并不是在反复拉出大小一致的小像素方块来搭一组简单的楼梯。方块往往形状和位置都很古怪，迫使你认真思考要把什么移进或移出背景。游戏会在过程中教你新技巧，比如从侧面推拉方块的能力，但简单的能力在某些挑战中帮不上忙，例如当你恰好站在那个你迫切想要移进或移出背景的方块上时。如果你决定撤销某个操作，比如一次跳砸了，你可以稍微回溯进度；或者你可以在关卡底部按一个按钮，把整道谜题重新开始。

游戏很擅长慢慢向你介绍这些机制，一开始让你玩只需要移动两三个方块的非常简单谜题。没过多久你就会发现自己在为每个解法想得更久，花的时间越来越长，直到“啊哈！”的那一刻到来，你会为自己抵达终点而自豪。超过 200 道谜题的难度会越来越高，连解谜老手也会受到挑战。随着时间推移，开关和井盖等新花样被加入这套公式。开关被按下时，会把它对应颜色的所有方块完全拉出，改变你所站立的地形，开辟新的移动可能。井盖则有点像相互连接的传送门，让你能跳进或跳上一个彩色开口，再从关卡中另一处的孪生开口弹出，前提是两个井盖都没有被遮挡。

但即便事情变得复杂，《推拉方块》也相当没有压力。没有计时器让你感到匆忙，也没有任何理由去害怕以某种方式失败。谜题关乎巧妙的思考和移动，而非速度，这不像某些把推方块当作机制的其他游戏。推拉方块分两种：壁画，是赏心悦目但不太有挑战性的美术作品；挑战，则名副其实，把逻辑置于视觉之上。两种谜题各有各的乐趣。

游戏在角色或对话方面没什么内容，但《推拉方块》的世界依然充满魅力，氛围悠闲。每个关卡都充满鲜艳的色彩，马洛本人也是个可爱的角色，动作动画做得很好。在 2D 下一切看起来都不错，但把 3D 滑块调高以增加一些纵深感，真正让 3DS 的标志性功能派上了用场，尤其是因为纵深感本就是玩法的一部分。画面结合欢快的音乐，让解谜体验保持愉悦，即使后期关卡变难也是如此。你可以在游戏中大部分时间用试错法推进，从每次经验中学习，慢慢来。如果你被某些谜题卡住，游戏没有任何提示，但一旦它判定你尝试得够久了，就会给你一个无惩罚跳过该关的选项。你总能在更有信心时再回来。

仿佛内置的谜题还不够，当你开始游玩推拉方块工作室时，游戏会进一步展开，它拥有强大却易用的工具，供你创作自己的谜题并与朋友分享。用触控笔以像素画风格绘制谜题轻而易举，而一旦你自己通关一遍以证明它可被攻克，你就能生成二维码，让分享你的关卡变得简单。即使你对制作谜题不感兴趣，这个选项也意味着除了原版游戏内置的内容外，网上还有大量可用关卡，只要你愿意去找。许多论坛发帖者和社交网络用户都建立了自己的自制推拉方块创作中心，所以你不用找太远就能找到新内容。用 3DS 摄像头通过二维码获取新关卡是一个简单且即时的过程，如果能有一套完善的在线分享系统，它只会变得更好。如果任天堂至少为用户生成内容创建一个官方门户网站，让你上传二维码并给喜欢的作品投票，那就更好了。

在你能尝试所有内容之前，你确实得在主游戏中推进一些进度（在你能创建甚至获取带开关或井盖的关卡之前，你得先解开几十道谜题），但当游戏玩起来如此有趣时，这只是很小的代价。《推拉方块》提供了完整零售版往往缺失的丰富内容和聪明的游戏设计，所以它能以 6.99 美元下载到这一点令人印象深刻。它是一款无忧无虑、令人上瘾的解谜游戏，配有出色的玩家创作工具，让你能尽情地一直推拉方块。

<ReviewTab id="nintendoworldreport" site="nintendoworldreport" label="Nintendo World Report">

> 来源：[Nintendo World Report](https://www.nintendoworldreport.com/review/28656/pushmo-nintendo-3ds) · 作者：Patrick Barnett · 发布：2011-12-12 · 评分：9.5/10

3DS eShop 已经拥有不少优秀的下载内容。《推拉方块》不属于那一档——它超越了那一档。它令人上瘾的特性，加上简单的平台跳跃，使这款游戏成为任何 3DS 拥有者的必买之作。

游戏一开始向你介绍马洛，一个在推拉方块世界里长得像相扑选手的角色。他的任务是救出被一个不知名的邪恶家伙困在名为“推拉方块”的方块结构里的孩子们。随后游戏带你过一遍教学（对我来说稍微有点长）来教你基础。推拉方块在让你为后续内容做准备方面做得很好，但到达真正有趣的内容花了稍微太久。

在每个关卡中，你得到一组扁平、无法攀爬上去的方块。不过，你可以把这些方块向外拉出最多三格的距离。利用从正面和侧面的拉拽，你攀上并绕过结构以抵达终点。这个概念看起来也许简单，但其中涉及相当多的思考。想清楚如何到达顶端需要大量思考，而且解法通常不会就摆在你面前。我发现这些谜题难得恰到好处，能把我短暂难住，但总是可解的。如果某个谜题给你造成麻烦，也可以选择跳过它。

游戏后期，你会再过一遍教学，学习开关和管道的加入。开关会把某一颜色的所有方块带到最前层，而管道则把你传送到谜题的不同区域。这里教学同样有点冗长，但它所教的内容非常精彩。这些新元素让一些谜题更具挑战性，因为我现在不仅要考虑眼前的区域，还要考虑整个谜题四周。

解开所有谜题也涉及相当多的平台跳跃。做出刁钻的跳跃、恰好落在你需要去的地方，是成功的关键。所幸，游戏内置了一个回溯按钮。每当我跳错，或意识到自己把某些方块拉错了位置，我就能回溯时间再试一次。在游戏后期更复杂的关卡中，这个功能至关重要。没有它，你可能就得用结构前方那个有时挺有用的重置开关，把整道谜题重新开始。

挑战谜题数量充足，包括代表从恐龙到你最爱的任天堂偶像等一切的壁画谜题。挑战谜题通常只是几个简单方块拼在一起，最终却构成非常棘手的谜题。我觉得壁画穿行起来更有趣，但解开两种谜题都同样令人满足。

对富有创造力的玩家来说，游戏最大的吸引力之一是推拉方块工作室。在这里，玩家可以创作自己的推拉方块来分享。有大量颜色、工具以及其他一切你需要的东西来创作自己的推拉方块谜题。创作谜题最棒的一点是能用二维码轻松分享。使用它们，你可以随意把自己的谜题分发到任何地方。同样，你也可以用二维码把别人创作的谜题加入自己的推拉方块收藏。我已经收集了几个别人创作的谜题，并打算继续收集有挑战性、令人印象深刻的谜题来玩。

游戏的画面只能算有点印象。不过，作为一款解谜游戏，并不需要超乎寻常的画面。真正锦上添花的是 3DS 的 3D 效果，它让区分方块的各个层次确实变得更容易。在一些 3DS 游戏里，3D 效果只是敷衍了事。而在这里，我觉得它为体验增色太多，我更愿意开着它玩，而不是关掉。

《推拉方块》是一款巧妙的解谜游戏，会占满任何愿意一试之人的空闲时间。由于它令人上瘾的特性，我发现自己一玩就是好几个小时。如果你有 3DS，帮自己一个忙，去下载《推拉方块》吧。
