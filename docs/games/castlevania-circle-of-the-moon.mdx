# 恶魔城 月轮

<ReviewTabs slug="castlevania-circle-of-the-moon">

<ReviewTab id="gamespot" site="gamespot" label="GameSpot">

> 来源：[GameSpot](https://www.gamespot.com/reviews/castlevania-circle-of-the-moon-review/1900-2770559/) · 作者：Jeff Gerstmann · 发布：2001-06-07 · 评分：9.6/10

科乐美备受欢迎的猎吸血鬼系列《恶魔城》起源于 NES 上的横版街机式平台游戏。虽然系列早期作品偶尔尝试非线性玩法，但直到 PlayStation 的《恶魔城 月下夜想曲》发售，科乐美才真正找到把系列拓展到一堆相对简单动作游戏之外的方法。《月下》把《恶魔城》的概念与一个令人联想到 NES 经典《银河战士》的非线性世界融合在一起。结果这款游戏大获成功，至今仍是史上最出色的 2D 横版冒险游戏之一。《月轮》作为科乐美最早的 Game Boy Advance 作品之一，相当贴近《月下》的公式，同时加入了一点收集元素，为整体增添了更多重玩价值。

游戏发生在 1830 年的一座奥地利城堡里。卡米拉再次成功复活了德古拉伯爵，内森·格雷夫斯以及莫里斯与休·鲍德温这对父子要阻止这个邪恶的吸血鬼。然而莫里斯几乎立刻被抓，内森和休则被丢在一旁等死。休出发去寻找父亲，留下你扮演内森，踏上击败德古拉、救出莫里斯的旅程。像任何优秀的《恶魔城》主角一样，内森随身带着鞭子，还能拾取并使用系列其余作品里那些经典副武器，比如匕首、圣水、停时怀表和一柄斧头。副武器由心驱动，心通常藏在需要用鞭子抽打的蜡烛里。起初内森的移动与攻击选择相当有限，但随着游戏推进，你会找到额外道具，让你能够奔跑、发动冲刺攻击、二段跳、蹬墙三角跳、水下呼吸，以及高高跃入天空。游戏还有一个叫 DSS 的魔法系统。DSS，即双卡组合系统，由卡牌驱动。不同的卡牌在游戏不同区域找到，出现具有半随机性。魔法强化通过从两类卡中各选一张来选定。行动卡指定你使用何种魔法，而属性卡则通过给咒语附加效果（通常带元素性质）来改变行动。比如，一个咒语可能让蓝色火球绕着你旋转，而更换属性卡会改变咒语，让你被一团植物孢子包围。这对不同武器也有用，比如火焰或冰霜之剑。不过并非所有组合都是严格意义上的攻击或防御咒语。其他组合让你治疗自己、以双倍速度奔跑，甚至提升运气属性，让获得道具更容易。游戏还会记录力量、防御和智力属性。当你拾取护甲、戒指等物品时，可以装备它们来提升不同属性。游玩过程中你还会获得经验、提升等级，这是另一种提高生命与魔法上限及其他属性的方式。

游戏的操作正如《恶魔城》应有的样子。你用两个正面按键攻击和跳跃。按住上再按攻击会使用当前副武器。L 键开关当前选定的 DSS 组合，R 键用于冲刺攻击、三角跳以及游戏中大多数其他特殊招式。有些咒语需要你像格斗游戏那样转一圈（从下到上）才能激活。《月轮》的城堡相当大，且像《月下夜想曲》一样被划分为不同区域。你最终会发现传送房，能让你迅速从城堡一处移动到另一处，还有存档房，能让你完全恢复并保存进度。虽然游戏基本非线性，但你最终会到达一个只有一条路可走的地步，通往一场头目战。击败那个头目会给你一件道具，让你能去往之前无法进入的地方，然后这套流程重复。城堡里塞满了隐藏道具，能提升你的生命、魔法或一次能持有的心数上限。虽然城堡很大，有经验的平台游戏玩家应该能在八小时游戏时间内抵达游戏的最终决战。不过要当心——游戏的最终决战可不是闹着玩的。通关游戏会解锁不同的角色变体，行为与原角色相同，但初始属性和道具不同。比如魔法师型角色一开始就拥有游戏全部卡牌，魔法能力出色，但初始力量值较低。

画面方面，《月轮》看起来很不错。背景都令人印象深刻，虽然游戏对 GBA 本已昏暗的屏幕来说有点太暗，但整体观感清晰。唯一拖累画面的是动画不足——你的角色移动时看起来有点生硬，尤其是奔跑时。敌人也不是动画的喷泉。配乐充满大量出色曲目，模仿了早期《恶魔城》游戏的音乐，但它们本身也完全立得住。此外，游戏的音效做得非常好。

总而言之，《月轮》是一款真正接续《月下夜想曲》的作品，也是史上最出色的掌机冒险游戏之一。任何渴望精彩 2D 冒险的人——不只是《月下夜想曲》粉丝——错过它都绝对是犯傻。

<ReviewTab id="ign" site="ign" label="IGN">

> 来源：[IGN](https://www.ign.com/articles/2001/06/14/castlevania-circle-of-the-moon) · 作者：Craig Harris · 发布：2001-06-14 · 评分：9/10

我们很幸运有科乐美站在我们这边——当然，公司库里有一大堆我们希望在掌机上看到的游戏，但它最出名的可以说是某一个系列：《恶魔城》。随着 Game Boy Advance 的上市，我们得到了《恶魔城》系列中最有深度、最令人满足的作品之一。虽然《恶魔城 月轮》在画面上并不完全震撼，但它深厚的玩法与极长的旅程，远远弥补了平庸的图像与画面技法。这是新掌机上必买的一款游戏。

## 特色

- 80 种 DSS 咒语效果
- 10 种魔法召唤攻击
- 电池备份
- GBA 独占

玩过系列任何一作的人都会觉得 GBA 版《恶魔城》非常熟悉，因为其设计没有偏离基本公式。你会鞭打僵尸、幽灵、蝙蝠和其他可怕野兽，并为副武器（回旋镖、匕首、圣水、秒表）收集心……同时穿过德古拉城堡的恐怖。现在轮到内森·格雷夫斯执鞭，他要去从复活的往昔吸血鬼手中救出被绑架的父亲。

《恶魔城》系列凭借出色的 PlayStation 版《月下夜想曲》摆脱了 NES 和 Super NES 系列那种结构化的关卡设计，而 GBA 上的《月轮》沿用了非常相似的公式。设计很像任天堂自家的《银河战士》：你身处一个连续的"世界"——这里是德古拉的城堡——这座巨大建筑的其他部分，只有当你获得特定且必要的技能后才能进入。游戏开始时，你手里只有鞭子——随着推进，你会获得奔跑、二段跳、打破特定墙段……以及其他便利能力。如果你想穿过德古拉宅邸的许多不同区域，就必须掌握这些特定技能。但别以为会迷路——你的进度会被标在一张极其方便的自动地图上……这也是与《银河战士》设计相呼应的元素。整段旅程中你还会找到能保存当前游戏进度的房间——面对《月轮》这么长的旅程，你会非常感激卡带里的电池。

当你击败众多不同敌人，会获得经验值来提升角色等级，增强属性以辅助整体的攻击与防御能力。除了获得的技能，你沿途还会收集被称为 DSS（双选系统）的卡牌。卡牌分两大类：行动卡与属性卡，当两类各取一张组合时，能启用一种特殊攻击技法，对付特定敌人时大有裨益。寻找彼此搭配的卡牌是个试错过程，也为玩家提供了新东西去发现，增添了乐趣。

与《恶魔城》系列其他作品不同，《月轮》并非其所对应主机的画面展示品。比如当年 Super NES 的《超级恶魔城IV》问世时，开发组尽可能榨取了主机的画面特效。这里却不然——虽然游戏看起来很不错，图像却不会让人屏息。有些房间有多层卷轴背景以制造纵深感，另一些则只有单层卷轴。角色精灵的动画帧数非常有限，尤其是主角——他走路的循环只有三帧，显得别扭，像是从 Game Boy Color 版里出来的。而且，它很暗。开发组为营造特定氛围调低了画面对比度，这在没有背光的 GBA 屏幕上效果不佳。别想在头顶没有直射光照明 LCD 的地方玩这款游戏……它就是很难看清。

但《月轮》的核心全在玩法——而这正是游戏真正发光的地方。这是已发售的《恶魔城》游戏中手感最好的之一。世界很大，头目生物体型巨大、难以击败。整体旅程极其令人满足，因为完整通关要花上好几个小时。

### 总评

《月轮》可能是《恶魔城》系列中最好的 2D 游戏，而我们掌机玩家是受益者——游戏非常长、极具挑战，却不会令人沮丧，也不是必须匆匆赶完的苦差。只可惜画面没有稍微升级一下，因为角色动画看起来像是从 GBC 开发里撕出来的，而且游戏需要尽可能多的光线，才能看清城堡里所有黑暗房间。尽管如此，它是一款出色的游戏，绝对位列 Game Boy Advance 五大首发作品之中。

> 来源：[Nintendo World Report](https://www.nintendoworldreport.com/review/3788/castlevania-circle-of-the-moon-game-boy-advance) · 作者：David Trammell · 发布：2001-07-18 · 评分：9/10

David Trammell 暂时放下《暗黑破坏神II》，抽出时间写下了我们对这款新《恶魔城》游戏的第一篇评测。本周晚些时候会有更多内容！

我是 PSX《恶魔城 月下夜想曲》的忠实粉丝。因此，我很高兴《月轮》与那款游戏非常相似。相似的是游戏的基本观感与手感；其他一切自然都很新。像它的前作一样，《月轮》有一座可探索的广阔城堡。沿途会有升级帮助你跳得更高或摧毁障碍，你会获得经验、提升等级、找到物品、与巨大头目战斗，最终再次面对邪恶的德古拉伯爵。《恶魔城》诚实地说正从动作平台游戏演变为动作冒险游戏，这一变化绝对受欢迎（虽然我也不介意多一些老派《恶魔城》）。画面方面，本作是系列除《月下夜想曲》之外前作的一次提升。相比《月下》，动画有时看起来有点有限，但考虑到 GBA 的内存限制，这可以原谅。提醒你，这是 GBA 上较暗的游戏之一，但几个好灯泡就能解决。游戏的音效很好地体现了系列。事实上，大部分音乐只是从之前游戏中重新混音而来。操作方式大概是对经典《恶魔城》游戏最大的提升。你能轻松地跳来跳去、鞭打敌人，并会全程获得额外能力，到达之前被阻挡的区域。游戏大部分时间花在与怪物战斗上，你会因此获得经验和物品作为回报。这次实现的一个非常好的点子，是击败某些头目会改变某些区域出现的怪物。所以当你回头探索旧区域时，仍会受到强敌的挑战。游戏应该要花你十小时以上才能通关，如果想完全探索地图则更久。通关后还有额外的游玩模式可供探索。

## 画面

环境有趣且构思良好，但许多细节在黑暗中丢失。动画有时有点僵硬，不过屏幕上通常同时有很多大型敌人。一大加分项是这款游戏是为 GBA 从头打造的，不像其他一些首发作品。

## 音效

音效做得很好，能在音乐之上清晰听到。音乐本身由编排精良的混音组成，但我必须抱怨游戏里原创音乐只占少数。

## 操作

GBA 上的四个按键都得到了很好的运用。角色的移动非常精准，挥舞贝尔蒙特家族传统的鞭子从未如此轻松。

## 玩法

《月轮》从它之前的多数《恶魔城》游戏中各取所长，再融合一些新创意，做出了一款应该能让你沉浸无数小时的游戏。

## 耐玩度

你的首次通关应该会持续远超十小时，还不算暂停查看地图和物品的时间。通关后解锁的新模式你多半也会想玩。

## 总评

如果你还没体验过《恶魔城》游戏，现在正是好时机。《月轮》是巅峰状态的《恶魔城》，它绝对在我最喜爱的游戏名单中占有一席之地。
