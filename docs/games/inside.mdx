# 囚禁

<ReviewTabs slug="inside">

<ReviewTab site="ign" label="IGN">

![INSIDE IGN 评测头图](/img/reviews/inside.jpg)

> 来源：IGN（https://www.ign.com/articles/2016/06/28/inside-review）· 作者：Ryan McCaffrey · 发布：2016-06-28 · IGN 评分：10/10（masterpiece）

更新 2：Inside 现已登陆 Nintendo Switch。我们玩过之后，将它和 Xbox One 版并排对比，在绘制距离、画质、帧率，乃至初始加载时间上都没有察觉到可辨的差异。简而言之，它仍是当初我们给出 10/10 分的那款游戏，我们极力推荐。

更新：Inside 已获 IGN 2016 年度游戏提名。

《Inside》——开发商 Playdead 继《地狱边境》（Limbo）之后让人翘首以盼的续作——的最初 10 分钟，在美丽、萦绕不去与恐怖之间摇摆。有时这三种感觉会在同一瞬间同时袭来。从那之后，它又在这些之上叠加了悬念、惊奇与震撼，并且始终不曾松懈。正因如此，最好你听我一句，完全蒙着眼睛进去，自己去发现它。但如果你需要被说服，请继续往下读，了解这款视觉惊艳、引人深思又神秘莫测的杰作更多。

尽管从机制上说它是一款 2D 解谜平台游戏，《Inside》却简直是我玩过最美、细节最微妙的游戏之一。每一帧画面似乎都被精心打磨、反复抛光过无数遍，从烟雾弥漫的空气中悬浮的尘埃颗粒，到沼泽里溅落的雨滴，再到金色阳光透过窗户洒在你那位无名红衣男孩化身身上。一切都仿佛得到了艺术家全身心的专注。我常常停下来只是欣赏周围环境，品味那些微妙的动画细节、阴郁的灯光、大胆对比的色调，乃至那种诡异而不安的音效设计。你能听见男孩跑了一阵之后沉重的喘息。你能看见他跳跃后稳住奔跑落地时踉跄一下。灰色涂抹了大部分场景，但一抹抹色彩——常常是红色——被用作大胆的对比，把视线引向设计师想让你看向的地方。镜头运用也值得称道；视角只会略微变化，但从一个场景到另一个场景，你始终处在观看屏幕上所发生之事的最佳位置，而且每当镜头拉近、拉远或改变角度时，总会有视觉上的回报。

无论我说什么，都无法让你为 Playdead 这款基于物理的解谜平台游戏中那些模糊、无言的种种事件做好准备，但不剧透地说，要不对接下来发生的事感到震惊，几乎是不可能的。当你闯入《Inside》的军事化设施、在其约三个小时紧凑而节奏得当的流程中深挖它诡异的深处时，它在外观和玩法上都会不断以出人意料的方式变化。当你最终置身一艘单人潜水艇，在这座基地深处寻找答案时，那仅仅是谜团的开始。

> 令人耳目一新的是，游戏完全没有给出任何说明。

《Inside》的玩法与《地狱边境》简单却富有氛围的 2D 解谜平台跳跃相似。死亡频繁，起初看起来似乎无法避免、也不公平，但它们实际上是教会你该做什么、不该做什么的课程。总得有什么来教，因为（令人耳目一新地）屏幕上和语音中都没有任何说明。而当你死去时，男孩殒命的动画花样繁多，有时夸张到颇具娱乐性——有时也令人毛骨悚然。看着他被电子触手电击并拖出屏幕，或被轰得灰飞烟灭，为那些含蓄的撕咬和枪击增添了几分轻松感。与此同时，存档点足够慷慨，加载时间也足够短暂，死亡从不让人感觉是一种惩罚。

和《地狱边境》一样，你只有两个按键：跳跃（A）和互动（X）（PC 上默认是上方向键和右 Ctrl，用方向键控制移动），而色调或光线的微妙提示会把你的注意力引向需要去的地方。谜题本身比《地狱边境》里的稍容易些——我从没卡住超过几分钟，就会迎来那种解谜顿悟的满足感。有些涉及移动特定的物体，比如箱子。另一些则要你激活奇怪的空气推进方块，它们会腾空而起、悬停片刻，然后落回地面并复位。还有好几个谜题一说就会剧透，但它们合在一起构成了不错的多样性。偶尔这些元素会混合起来，需要你试验物理效果才能把角度调得刚好。设施本身有时就是你的对手，无论是极高的落差、无法解释的震荡冲击，还是你必须深深潜入而不至于溺亡的深水。

> 这些遭遇编排得如此精妙，以至于你总是惊险万分地擦边逃脱。

后来的挑战涉及躲过有机的敌手，无论是狗还是……更奇异的生命形式。这些遭遇编排得如此精妙，以至于成功时你总是惊险万分地擦边逃脱（而当你失败时，则会欣赏到男孩被撕咬——或更糟——的血腥画面）。事实上，即便在二周目，它们依然是让人捏把汗的时刻——即便我早已知晓接下来会发生什么。重点是，无论哪种谜题，它几乎总是直觉可解的，却又未必显而易见，而寥寥几种机制被混合搭配得足够充分，以至于《Inside》从不让人厌倦、也不会陷入重复。它明智地在用尽维持那种感觉的点子之前就结束了。

而《Inside》的谜题——无论生物性的还是环境性的——都充当着推动其叙事的载体。游戏从不解释男孩为何独自在夜里的树林中，也不解释他为何潜入那座神秘设施、或希望在那里达成什么——更不用说谁在试图阻止他。这款游戏里发生的事几乎无法描述。它近乎梦境，可以从一个合乎逻辑、贴近现实的地方开始，却不知怎么最终落到某个远为奇幻的地方。二周目时，尽管我已知道所有谜题的解法，却得以更仔细地思考故事早期的部分，以及它们如何与结尾相连。我仍在思考《Inside》——它的含义，以及它对人性说了些什么——我也在享受与自己、与同事们的争论。我敦促你去玩它，既因为它是 2D 平台游戏设计的一件杰作，也因为若在你亲自体验之前这里的种种被剧透，那简直是种罪过。我几乎可以保证，你绝对料不到《Inside》会走向何方。

### 总评

《Inside》非常明显是在《地狱边境》的伟大之处上建立起来的，事实上它建起了更伟大的东西。它那难以想象的转折或许会让你目瞪口呆、困惑不解，甚至很可能说不出话来，但它会激发你与朋友就其含义、讯息与意图展开激烈讨论。这是一段短暂的旅程，却让我觉得非再走一遍不可——其中还包括寻找它那些神秘的隐藏光球收集品。趁还没人向你剧透哪怕一个重要瞬间之前，赶快去玩吧。

## 《囚禁》评测

### 高堡中的男孩

一个在技术进步手中支离破碎的世界，在寂静与黑暗中腐烂。被威慑、被奴役的人们面无表情地在街道上拖着脚步。戴着面具、身着黑衣的监工站在街角，等着某个奴隶掉队，注视着这些没有灵魂的芸芸众生被迫跳跃、起舞。在这之中，一个没有任何特征的男孩穿着红衬衫走过这座反乌托邦——那是这个压抑世界里仅有的几抹色彩之一。

这就是《囚禁》，开发商 Playdead 继《地狱边境》（Limbo）之后的第二款游戏。与《地狱边境》一样，玩法很简单：你必须行走、跳跃并抓取物体来解谜、克服障碍。但归根结底，这款游戏讲述的是你穿越一个暴虐、不可知且末日般的世界的一段旅程。在几个小时的过程中，你不断深入一座恶毒而庞大建筑的心脏，它威胁着要扼杀人的能动性与人性。

《地狱边境》跟随一个角色穿行于一片奇异而原始的土地。死亡轻易地降临到角色身上，却很少让人觉得是谋杀。而另一方面，《囚禁》则散发着暴力、残酷与矫饰。游戏凸显了一个社会的陈旧与破碎之处，你会逐渐发现这个社会已被拖入人体实验的地狱。

随着你在《囚禁》中推进，你会经历一段段安静平和的时光，其间点缀着彻头彻尾荒诞的闪回。游戏鼓励你去品味这些常常令人震惊或残酷的转折，它们激起厌恶与困惑之感。它们让你想要了解更多。

即便在通关几天之后，这些时刻依然鲜活地留在我的记忆中。一群没有意识的人影跟着我跳下悬崖，却重重砸在地上，堆成一团黏糊糊的肉泥。一个如烟雾般纤弱、女性化的生物在水下区域顽强地尾随我。我让我的角色经历了多次即刻而惨烈的死亡。我最爱这款游戏的时候，是它那些安静的低潮时刻，那时世界的压抑感最为明显；但那些直冲面门的时刻也展现了《囚禁》另一个黑暗喜剧的侧面。有时我忍不住对它所抛给我的东西之荒诞而笑出声来。

解谜可以简单到把一个箱子推到高台脚下以便跳上去，也可以复杂到同步多个自动机械来扳动开关、抬升物体、移动推车，好让你打开一扇门。一些早期谜题更多依赖于谨慎的移动而非逻辑，你要设法避免被戴面具的人影杀害或掳走。另一方面，后期的谜题需要更多耐心与思考。有些让你依次打开一连串门、把一个物体移过一个房间，另一些则要求精确计时的跳跃或开关操作才能完成。

总有那么一些时候，《囚禁》过于依赖它的谜题来维持你的投入。在这些时刻，我感到自己的核心动力已经从探索这个世界转变为单纯地扳对那个开关。这是一个曾困扰《地狱边境》的问题，而《囚禁》在第二幕把你带到地下深处时几乎跌入了类似的陷阱。你必须在游戏叙事最稀薄的段落里完成它最耗时的谜题，而游戏费尽心力营造的悬念几乎要土崩瓦解。

幸运的是，当游戏进入最后一幕、世界与谜题再次形成一个连贯整体时，这个问题就烟消云散了。《囚禁》最出色的时刻，是当你感觉根本不像是在解谜，而更像是在躲避障碍、在一片危险的空间中寻找通路。随着《囚禁》接近尾声，谜题强化了定义游戏其余部分的探索感。

《囚禁》在叙事上的成功，很大一部分来自它的视觉设计。游戏非常美，以柔和的色彩和没有特征的人物为标志，构成一种简单却富有感染力的美术风格。《地狱边境》那些模糊不清的背景不见了；《囚禁》的环境细节丰富，充满动感与秘密。例如，你可能会发现一间刚被废弃的房间里，蜡烛上仍袅袅升起一缕青烟；一辆装满自动机械的卡车在你进入新画面的那一刻驶离；用于观看奴隶跳舞的观景平台；或是建筑群机械那庞大的暗影在远处背景中隐约矗立。

《囚禁》对声音与音乐的运用偶尔令人屏息。你从不会听到人声，但每个场景都有自己独特的声响。当我穿过一片森林时，松树沙沙作响，石块相互碰撞，落叶在我脚下嘎吱作响。在建筑群里，一种脉动、有节奏的噪音伴随着我的旅程，持续而令人不安地提醒着这个世界的无情。音乐用得节制，但当它涌起时，即便像离开一栋建筑这样的小事，也会成为我记忆中定格的瞬间。

这一切——场景、声音、美丽的艺术——都在为揭开这座建筑群的秘密而铺垫，但我在结尾所发现的东西几乎毁掉了整个体验。含蓄被抛到了窗外，我被震得晕头转向，无法消化那个转折。主导了游戏大部分时间的那个压抑、安静、缓慢而神秘的故事，在一阵彻底的荒诞中骤然改变。当《囚禁》自我扭曲时，我不知道该笑还是该惊恐地尖叫。当片尾字幕开始滚动时，我静静地坐了几分钟，无法决定该如何看待它。

但随着时间流逝，那些最后的时刻渐渐打动了我。我仍觉得这个结局有些古怪，但在第二次通关《囚禁》之后，我发现了一些可亲的元素，它们与整体故事的契合程度比我最初以为的更有效。这个结局以一种既矫揉又幽默的方式自我觉察，拿自己和《地狱边境》开玩笑。它同样具有宣泄作用，在一个场景中释放了在《囚禁》其余部分积累起来的所有紧张感。

这是一款美丽、萦绕不去、令人难忘的游戏，是《地狱边境》当之无愧的续作。它的谜题虽然很少算得上困难，却是对故事引人入胜的补充。然而，这款游戏真正的成就在于它构建叙事的方式：细节丰富的环境传达了你所穿行的这个奇异世界；内省的时刻充满了极简的声音设计和最微弱的音乐点缀；而你必须去做的事，迫使你直面人性、自由与存在的现实。谜题或许不会让你再次回来游玩，但单单是进一步了解这个世界的机会，就足以成为重返《囚禁》那座反乌托邦的动力。

### 评测结论

**评分：8 / 10 — Great**

**优点**

- 关于暴力与压迫的令人不寒而栗的故事
- 萦绕不去的黑色幽默笔触
- 华丽而极简的美术与音效
- 通常与整体故事契合良好的谜题

**缺点**

- 缓慢、疏离的中段
- 结局显得突兀而用力过度
