# 铲子骑士：宝藏合集

<Tabs groupId="review-source">
  <TabItem value="ign" label="IGN">
![铲子骑士：宝藏合集 IGN 评测头图](/img/reviews/shovel-knight-treasure-trove.jpg)

> 来源：IGN（https://www.ign.com/articles/2017/03/07/shovel-knight-treasure-trove-review）· 作者：Mike Rougeau · 发布：2017-03-07 · IGN 评分：9/10（amazing）

《铲子骑士：宝藏合集》是一套内容全面的《铲子骑士》合集，很好地展示了 Nintendo Switch 的出色之处，而全新的《苦难幽灵》资料片则挖掘出新的深度。这些出色的复古画面（与音效！）平台跳跃游戏此前已在众多平台发行，你很可能已经以某种形式玩过《铲子骑士》了（如果没玩过，那你应该玩——参见我们最初的《铲子骑士》评测），但尤其是《苦难幽灵》，非常值得为它回归。

其一，这套名为《铲子骑士：宝藏合集》的完整合集，很好地展现了独立工作室能在短短几年内走多远。初代《铲子骑士》是一款小巧却精致的 2D 动作游戏，拥有出色的平台跳跃、多样化的工具武器库，以及出人意料地写得不错的故事。而《瘟疫之影》感觉像是为硬核粉丝准备的混音式追加内容，《苦难幽灵》则感觉像一款全新的游戏，展示了 Yacht Club 自 2014 年初代发行以来所学到的一切。

Switch 版拥有大量功能，要么是全新的，要么对许多自《铲子骑士》首发以来就没再玩过的人来说是新的。举例来说，基础游戏（《希望之铲》）如今有了合作模式，而 Switch 适合多人游玩的 Joy-Con 手柄（尽管整体上更精准的 Switch Pro 手柄及其真正的十字键体验更好）以及该系统普遍的便携性，让它更加出色。它还有 amiibo 功能——你可以自定义一名骑士，轻松带到朋友的机器上合作游玩；或者如果你在之前的任天堂平台上存有一名自定义骑士，也能轻触一下导入。本版本新增了"铲子仙子"，是 amiibo 拥有者可以召唤的一个小精灵，在你游玩时会在屏幕上快速穿梭。这仙子没什么用，它会模仿捡宝和打怪，却不产生任何实际效果。但它很可爱。

《宝藏合集》还加入了全新的"身体互换"功能，让你能摆弄每个主要角色的性别与自我认同代词（他/她等）。把所有骑士变成女性、把女巫变成男性——让她成为男巫——是让《铲子骑士》重新变得新鲜的好办法，你可以按自己的喜好调整故事。遗憾的是，身体互换目前只在初代游戏《希望之铲》中可用，不过有理由期待开发者会在未来的更新中把它加入资料片。

对回归玩家而言，真正的吸引力是全新的资料片《苦难幽灵》。它为一整套内容增添了许多，远不止一组新剧情任务。比如可从幽灵骑士的枢纽世界进入的新挑战——一座直插云霄、诱人攀登的高塔。一具名叫霍勒斯的空铠甲守卫着它不断变换布局的高处入口。他向你发起登顶挑战，而这一壮举只有凭借闪电般的反应和精准的平台跳跃才能完成。它并非《宝藏合集》中最困难的区域，但其挑战性与可重复游玩性的平衡让它十分出色。

接着是战役，它本身也完全站得住脚。作为一段前传故事，这场冒险跟随幽灵骑士，讲述他试图说服其他骑士加入女巫的"无赦骑士团"的历程。光看这描述，你会以为它会重走初代和《瘟疫之影》走过的老路，但幽灵骑士开辟出多得惊人的新天地，塞入了大量全新内容。我花了七个多小时才走完幽灵的故事、攻克霍勒斯的高塔，而这时间还没算上任何新挑战（其中包含更多替换版 Boss 战），也没算上通关后解锁的新游戏+模式。

和此前的瘟疫骑士一样，幽灵骑士拥有大量独特能力与攻击可供把玩。他能攀上某些墙壁，还能在快速移动的轨道上冲浪或滑行，为平台跳跃挑战创造出新的机会。在空中时，他的攻击会让他朝敌人急速冲去，而他是冲向地面还是向上飞，完全取决于你的角度和时机。这绝对需要适应，即便玩了好几个小时，你也可能被自己搞砸的跳跃次数弄得心烦意乱。遗憾的是，挫败感可能会累积，尤其在更困难的关卡里；不过由于没有大地图，你可以按任意顺序挑战每个任务，所以很容易先放下一处难题，等不那么生气时再回来。

即便如此，幽灵骑士相较于《瘟疫之影》里瘟疫骑士的武器库是一大进步。尽管摆弄瘟疫的炸弹、试图为每种新情况打造完美工具很有回报，但操控这位炼金术士进行二段跳和爆炸冲刺，却感觉别扭而不精确。相比之下，幽灵骑士感觉完全流畅、以技巧为本，让人想起经典的《恶魔城》。

若没有一大堆酷炫的额外升级与能力，那就不是《铲子骑士》了，而幽灵骑士没让人失望。幽灵的其中一件替换披风让他能在任何表面（包括尖刺）上镰刀滑行；另一件则让他在摧毁关卡中的检查点宝珠时获得可回充的"暗影"（施放能力所需的能量），代价是若你死亡，可能会损失大量进度。与此同时，幽灵可解锁的"奇物"包括一些强力招式，能让你在空中飘浮、穿墙攻击屏幕各处的敌人，以及随心所欲地回复生命。

如果说扮演瘟疫骑士有时因其动作的古怪而像在玩困难模式，那么幽灵骑士毁灭性的攻击则会让扮演他感觉像在作弊。它一度有变得过于简单的风险，直到后期关卡真正加大挑战来加以补偿。

《苦难幽灵》最棒的惊喜之一是，与重用初代《铲子骑士》同一批关卡的《瘟疫之影》不同，这部新资料片拥有近十个完全重新设计或全新的关卡。每一关都以有趣的方式利用了幽灵骑士多才多艺的移动风格与独特能力，其中包括一些常规段落，要求你在几乎脚不沾地的情况下，在目标之间挥舞镰刀穿梭。

幽灵的枢纽世界——你可以去那里与小兵闲聊、购买盔甲升级、试验新能力等等——也与此前版本中的村庄完全不同（不出所料，幽灵骑士在女巫的堡垒里，比在快活的村民中间更自在）。《瘟疫之影》也曾玩过类似的点子，揭露出村庄酒馆地下瘟疫骑士的秘密实验室，但为幽灵骑士，开发者们倾尽了全力。而这在整部资料片中一以贯之。

对于一款秉承这种老派像素传统的游戏而言，《铲子骑士》一直有着出人意料地深刻且写得不错的故事，而《苦难幽灵》将其推向新的深度——幽灵苦苦挣扎，试图说服其他骑士加入他的事业，并依次与每一个人正面交锋。和新的关卡一样，每一场 Boss 战都被重新设计，以更好地与幽灵对抗。比如，黑骑士骑着一只名叫 Terrorpin、长满尖刺的龟/犀牛状生物投入战斗，而这仅仅是资料片中的第一场 Boss 战。

每位新盟友都会在枢纽区域参加骑士团的宴会，你可以在任务间隙找他们交谈，收获有趣的对话与角色时刻。甚至还有闪回场景，充实了幽灵般的幽灵骑士的背景故事，表明他的动机比瘟疫骑士的"更多力量！"、乃至铲子骑士的"救你的朋友！"都更为复杂。

另一方面，幽灵骑士花好几个小时试图攻克霍勒斯的高塔攀登挑战的动机，至今仍是个谜——除非把我自己的痴迷也算进去。

### 总评

这是《铲子骑士》至今最好的版本，而《宝藏合集》是最完整的一套内容。除了在初代之上不断堆叠越来越多的新功能外，Yacht Club 还凭借《苦难幽灵》资料片在几乎各个方面改良了《铲子骑士》。从故事与剧本，到平台跳跃与战斗那份纯粹的流畅感，幽灵骑士都是该系列出色的一步。
