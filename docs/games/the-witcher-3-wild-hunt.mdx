# 巫师3：狂猎

<ReviewTabs slug="the-witcher-3-wild-hunt">

<ReviewTab site="ign" label="IGN">

![巫师3：狂猎 IGN 评测头图](/img/reviews/the-witcher-3-wild-hunt.jpg)

> 来源：IGN（https://www.ign.com/articles/2015/05/12/the-witcher-3-the-wild-hunt-review）· 作者：Vince Ingenito · 发布：2015-05-12 · IGN 评分：9.3/10（amazing）

与它的前作不同，《巫师 3：狂猎》并不算是一开场就尖叫着冲出发车线。相比《巫师 2》中你立刻被一头抛进一个关于阴谋与背叛的性感故事，这次的主线任务有时会显得平淡，甚至敷衍。但每当我踏出那条被踩烂的道路、去开辟自己的小径时，它就变成了一段狂野、开放、令人振奋的奇幻角色扮演体验，充满运用其出色战斗系统的机会。即便在《巫师 3》中投入了超过 100 个小时，它仍然引诱我继续玩下去——我还有太多想了解、想猎杀的东西。

就 RPG 机制而言，《巫师 3》和系列中另外两款游戏一样密集而深奥，而那压倒性庞大的开放世界环境，既让这种深度更令人望而生畏，从长远来看也更令人满足。很难表达这个世界究竟有多么巨大、多么开放：翠绿起伏的原野上随意点缀着各种形状和大小的摇曳草木，填满了彼此松散相连、破败的城镇之间的空间，那里的人们挣扎着勉强糊口。完整的昼夜循环和动态天气把这一切融为一体，让《巫师 3》的风景成为我所见过的最有真实感的开放世界之一。一个方便的小地图会为你指出想去的地方，它看起来也许像根拐杖，但说实话，没有它我会彻底迷路。一个如此规模的世界仍然让人觉得如此有目的、如此充满可做的事，这本身就是相当了不起的成就。

不过这一切有一个附带条件，就是 Xbox One 和 PS4 版本的技术表现。30 帧每秒有时都算奢求，《巫师 3》两张主要地图之间的切换有点太长，偶尔还会冒出小故障。这些从未以任何有意义的方式影响玩法，但确实略微损害了体验的美感。所幸，PC 玩家可以期待多得多。在 GTX 980 上，《巫师 3》在最高画质下全程以 60 帧每秒运行。

这张新的开放世界地图显然对故事结构产生了影响，虽然偶有精彩之处，但主线故事最终是《巫师 3》最不令人满足的部分。你或许可以称之为又一个《上古卷轴》综合征的案例。我们的故事始于横跨多片大陆寻找杰洛特失散已久的恋人叶奈法，以及他的养女希里。但我最大的问题在于，它从未真正变得更丰富：这条过于冗长的主线，本质上只是杰洛特替人跑腿，以换取希里下落的信息。它有效地维持了焦点与推进力，但感觉更像一场徒劳的追野鹅，而非《国王刺客》里那种值得层层解开的引人谜团。

多亏了大量出色的对话和配音，沿途还是有一些情感上的回报，但它与太多注水内容混在一起，形式是无意义的跑腿任务和收集马拉松。每当我觉得自己即将迎来一个有趣的揭示时，就得突然停下来护送一只山羊，或寻找一个患有嗜睡症的走失矮人。见鬼，就连杰洛特有时都几乎掩饰不住对这场没完没了的琐事大游行的沮丧。

同样值得注意的是，虽然你不玩系列前两款游戏也能顺利游玩，但如果没有《巫师》小说提供的背景，希里在旅程最后四分之一之前或多或少是个彻底的陌生人，这让我很难像《巫师 3》期望的那样去在意找到她——尤其是考虑到还有一大批有趣的角色被降格为配角背景。

所幸，一旦你离开主路去闯荡，他们都有机会闪耀，而这正是《巫师 3》几乎把一切都做得极好的地方。根据你在《巫师 2》中的选择（可以通过游戏早期的一些对话方便地重建），你会看到许多熟悉的面孔回归，在杰洛特的搜寻中扮演角色，而一旦他们登场，就会为你提供一条支线任务，通常包含有趣得多的情境可供涉足。地下地盘争斗、暗杀阴谋、三角恋和出人意料的结盟，都是这些可选冒险的一部分。它们全都如此充实、如此富含故事内容，让人感觉它们本该是主线故事的一部分。

在野外接到的许多支线任务也可以这么说。除了慷慨散落在《巫师 3》庞大土地上的一堆标准支线任务、怪物巢穴和强盗营地之外，你还会接到一堆怪物猎杀式的猎魔人委托。杰洛特的猎物从需要先使其实体化才能伤害的缥缈幽灵，到藏身浓雾中伺机出手的雾妖，不一而足。这里的回报是双重的：符合世界观设定的是，它们代表你最可靠的收入来源，而由于游戏内经济系统恰如其分地吝啬，这一点显得格外重要。

另一项好处是，这些猎杀和其他支线活动往往能让人对一个正被战争摧毁的世界、以及塑造它的诸多力量产生有趣的洞见。最棒的是，你就是那些力量之一。它也许不会以惊天动地的方式改变主线的结局，但我常常回到早先去过的地方，发现一个看似微小的决定产生了非常大的影响。这里没有道德计量表，没有模范或叛逆评分。在《巫师 3》的灰色世界里，只有因与果；你所做的决定，无论大小，都能切实改变你周围的世界——远胜大多数做出类似宣称的游戏。

角色成长和装备选择同样影响深远。相对于《巫师 2》，我发现《巫师 3》的 RPG 系统在某些方面被简化了，在另一些方面则变得更复杂。但两种情况的结果都一样：更好的体验。对药水和剑油如何补充、如何使用的简化，让它们感觉更实用、更即时可用，因为你现在不需要冥想就能完成这些。诚然，旧的方式更符合《巫师》的世界观，但在一个广阔的开放世界里，指望玩家提前预判并准备他们可能遇到的一切就不太合理了。另一方面，强大而有趣的药水种类比以往更多，包括能极大增强骑乘战斗的，以及在你施放法术（猎魔人称其为法印）时恢复生命值的。

说到法印，它们通过交替施放模式以及更多样的升级得到了全面改进，让它们在每场战斗中都有影响力。事实上，构建一个以法印为核心的杰洛特完全可行。我玩他时其实很像绝地武士，能在对话中影响他人心智，拥有强大的远程“原力”推击，以及把弩箭反射回射手的本事（一项回归的能力，且变得实用得多）。新的技能系统提供了相当大的灵活性，同时仍奖励那些想要为最佳构筑进行极限优化的玩家，而武器与护甲制作一如既往地深奥细腻，甚至更胜以往。

所有这些都在《巫师 3》灵敏、残暴的实时战斗中闪耀。这个系列此前战斗一直感觉含糊甚至有些笨拙，而在这里它如此流畅、如此令人满足，以至于我四处走动时盼着强盗来扑我，好让我用魔法屏障挡下他们的攻击、以难以置信的精准格挡他们的打击，并偶尔以血腥的华丽手法夺走他们的性命和/或肢体。《巫师》一直很擅长让我感觉自己智胜了敌人，但在这里第一次，操控杰洛特在每一场成功战斗中都真切地感觉像个狠角色。

### 哪里购买

### 总评

虽然这条直白且跑腿任务繁重的主线超出了它应有的篇幅，但每当我要倦怠时，在一张丰富、广阔的开放世界中愉快冒险的选择始终在那里等着我。即便情节不是特别有趣，其中参与的众多角色却很有趣，再加上出色的战斗与 RPG 玩法，它们把《巫师 3》提升到了少有其他 RPG 能企及的高度。
