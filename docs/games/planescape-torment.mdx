# 异域镇魂曲

<ReviewTabs slug="planescape-torment">

<ReviewTab site="gamespot" label="GameSpot">

> 来源：GameSpot（https://www.gamespot.com/reviews/planescape-torment-review/1900-2535119/）· 作者：Greg Kasavin · 发布：1999-12-21 · GameSpot 评分：9/10（Superb）

> 它显然是今年最好的传统电脑角色扮演游戏，并且注定会成为许多注定会喜欢它的粉丝们长久以来的最爱。

《异域镇魂曲》是一款传统的角色扮演游戏，拥有异常细致的故事以及一流的画面和音效。它设定在复杂而有趣的《高级龙与地下城》"异域"（Planescape）宇宙中，那是一个由截然不同的维度拼凑而成、环绕着一座连接它们的庞大城市的世界。在《异域镇魂曲》中，你扮演一个无名角色，他既不会死，也记不起自己的过去；在揭开他身世的过程中，你将体验到今年最引人入胜的游戏之一。

《异域镇魂曲》使用与《博德之门》相同的图形引擎，因此对这款 1998 年畅销角色扮演游戏的粉丝来说，会立刻感到熟悉。不过，《异域镇魂曲》的俯视等距视角比《博德之门》贴近地面得多，这意味着游戏中所有角色在屏幕上看起来都相当大。每个角色都高度细致、精心动画化，而且最重要的是设计巧妙。《异域镇魂曲》抛弃了大多数 RPG 的高奇幻风格，转而采用"异域"授权对熟悉奇幻原型独特的诠释，赋予游戏一种全然原创的外观，颠覆了人们对奇幻与科幻美术的预期。就连《异域镇魂曲》的主角——满身疤痕、浑身纹身、穿着骨头和兽皮——也似乎与通常的角色扮演游戏英雄毫无相似之处。

由于视角贴近，《异域镇魂曲》的场景比《博德之门》的场景细节更繁复，而且与它的角色一样，场景看起来既出色，又与你习惯的有所不同。游戏没有毫无意义的荒野地带；每个区域都经过精心设计，大多数区域人口密集。游戏中城市环境那如刀刃般突起的建筑，以及其地下墓穴粗犷、近乎异形般的盘结，赋予《异域镇魂曲》一种轮廓分明、极具辨识度的外观，而游戏富有氛围的配乐、出色的音效，以及稀少却高质量的配音，都有助于维持《异域镇魂曲》的风格。游戏有一种始终如一的冷峻观感，有时甚至令人不安、不适，但《异域镇魂曲》这些荒凉的环境似乎是有意为之，以激发主角想要逃离印记城（Sigil）那种压抑、幽闭桎梏的渴望。尽管场景严酷，有时《异域镇魂曲》仍色彩丰富、令人印象深刻，主要归功于它常常十分壮观的特效。强大的魔法咒语让屏幕变暗，迸发出幽灵般的能量，使画面震动摇晃。即便是游戏中最微不足道的咒语，也有令人印象深刻的特效和动画，尽管一些更繁复的效果往往会让游戏变慢。

《博德之门》的引擎还有其他局限，其中一些纯粹是审美上的，另一些则对《异域镇魂曲》的玩法略有不利影响。不过，就像在《博德之门》中一样，《异域镇魂曲》的玩家很可能会很快不予理会或无视这些问题，比如有限的屏幕分辨率、糟糕的角色寻路，以及覆盖你到访的每个新区域的那种难看的即时战略式战争迷雾。为了容纳《异域镇魂曲》更大的角色，游戏的大部分界面在你右键唤出一个圆形弹出窗口之前都是不可见的，这个窗口让你使用物品、施放法术、使用特殊能力等等。遗憾的是，虽然隐藏界面确实腾出了大部分屏幕，但它既不紧凑也不直观——你会花大量时间摸索它那些没有标记的小按钮，或者把它拖到一边，以便唤出后能看到发生了什么。至少界面激活时游戏会自动暂停，让你可以从容地弄明白。尽管《异域镇魂曲》的大部分界面大多数时候都不在屏幕上，你会发现游戏的近景视角仍有其特有的问题。游戏中几乎没有远程武器，仅仅因为从屏幕一端到另一端的相对距离太小。同样，游戏中的几个强大法术有一种糟糕的倾向：对施法者本人同样危险，因为等到锁定敌人并念出咒语时，那个敌人已经拉近了与施法者的距离，而施法者总是会遭受到自己魔法攻击的伤害。《异域镇魂曲》还受累于游戏未经打磨的菜单界面，以及其大量对话不可避免的缓慢滚动速度——这一点和界面一样，你会训练自己将其忽略。

你会忽略《异域镇魂曲》的技术问题，因为它是一款如此出色的游戏。具体来说，它是一款漫长而引人投入的游戏，拥有原创的情节、文笔出色且富有描述性的对话，以及讨人喜欢的角色。幸运的是，《异域镇魂曲》的对话读起来很流畅，因为要读的内容非常多；尽管游戏的画面富有感染力、常常很美，但游戏中最生动的那些事件实际上是写出来的，而非在屏幕上呈现的。你也许会希望游戏更频繁地"展示而非讲述"；不过，它把出色的画面和文笔结合在一起，总体效果非常好。因此，即便你有一半时间都在读文本，也很少会觉得对话妨碍了游戏快得令人惊讶的节奏。

这主要是因为对话实际上是《异域镇魂曲》最出色的部分之一，因为它是少数几款真正兑现了"让你以自己喜欢的任何方式扮演角色"这一承诺的角色扮演游戏之一。《异域镇魂曲》的对话常常让你选择许下承诺、虚张声势或装傻；如果你的角色智力高，游戏就让你察觉细微的细节；如果感知高，就让你理解哲学含义；如果力量或魅力高，就让你威吓或迷惑他人。你角色的道德阵营以及他与印记城不同派系的关系都是公开灵活的，并对游戏进程有显著影响。同样，你的角色可以随时在战士、盗贼和法师职业之间切换，并能迅速在其中任何一个、乃至全部职业上达到很高的精通程度——这在游戏中的解释与其说是习得新技能，不如说是回忆起潜藏了数百年的天赋。此外，你角色那种反常的、无法永久死亡的能力，也通过阻止你频繁读取存档来帮助维持《异域镇魂曲》的节奏，尽管有主角的不死之身，游戏也从不显得简单或无关紧要。

然而，为《异域镇魂曲》众多的程序缺陷开脱也很容易，这些缺陷有时让游戏变得极其缓慢，并让它的几十个任务中一些偶尔变得无法完成。确实，电脑角色扮演游戏中的 bug 似乎几乎和法术与生命值一样是惯例。幸运的是，《异域镇魂曲》的 bug 还没有严重到真正毁掉游戏的任何一个部分。尽管如此，你可能会遇到几处性能或任务脚本上的故障，让游戏的部分内容变得不必要地令人沮丧，尤其是考虑到《异域镇魂曲》总体上卓越的品质。

事实上，这些对几乎任何其他游戏都会造成损害的问题在这里显得如此微不足道，正是《异域镇魂曲》令人印象深刻成就的证明。它显然是今年最好的传统电脑角色扮演游戏，并且注定会成为许多注定会喜欢它的粉丝们长久以来的最爱。这是因为它是一款外观出色、漫长却从不乏味的游戏，它恳求你去通关不止一次，正如它那独特的主角和他的故事承诺不会被遗忘。

### 评测结论

**评分：9 / 10 — Superb**
