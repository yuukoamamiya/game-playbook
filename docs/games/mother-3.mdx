# 地球冒险3

![地球冒险3 游戏头图](/img/reviews-webp/mother-3.webp)

《地球冒险3》（Mother 3）是 2006 年在日本发行的 Game Boy Advance RPG。由于没有可用的 Metacritic 总分，本页只展示经过核对的媒体入口，不填入推测分数。

> 来源：[Eurogamer](https://www.eurogamer.net/mother-3-review) · 作者：Simon Parkin · 发布：2008-10-29 · 评分：7/10

很少有哪款游戏的孕育过程像《Mother 3》这样痛苦而漫长。作为 Super Nintendo 经典《EarthBound》的续作——那款游戏凭其可爱又滑稽、以现代世界为舞台的日式 RPG 风格赢得了一批忠实拥趸——它最初公布是在十二年前。在无数次流产的开端和落空的承诺之后，主设计师糸井重里终于在 2005 年于自己的博客上宣布，它即将在日本登陆 Game Boy Advance。

作为日本最受喜爱的 RPG 系列之一的最新作，《Mother 3》一路冲上预订榜榜首，随后在零售端也取得了相当的成功，可这样的成绩依然没能为它换来一次西方发行。尽管《EarthBound》在游戏行家心中是碰不得的圣物，它的销量却很糟糕，而这一表现也断送了这部续作在西方发行的机会。宫本茂本人曾这样评价这款游戏："我们原本对《EarthBound》在美国的表现寄予厚望，但它卖得不好。你也许不知道，当时有一份请求制作《Mother 3》的请愿书，收集到了三万个签名！那之后我们想，'哇……《EarthBound》的粉丝真够铁。'"

说 Mother 系列的追随者"真够铁"，其实还是轻描淡写——他们的执着常常令人难以置信。所以当任天堂本地化制作人 Nate Bihldorff 在一次采访中确认，公司没有把《Mother 3》带出日本的计划时，一群粉丝译者立刻行动起来，一点也不让人意外。他们从日版 GBA 游戏中提取文本文件，开始把游戏里成千上万行对话逐一翻译，再套用《EarthBound》的英文字体重新写入，过程极为艰辛。终于，在 10 月 17 日，也就是这群人开工两年多之后，一份完整翻译补丁被发布到网上，任何拥有该游戏数字版的人都可以通过模拟器免费游玩。

这次发布游走在法律的灰色地带，试探着浑水般的诉讼风险，但粉丝本地化者的动机显然纯粹。游戏启动时会有一条讯息，呼吁玩家通过进口官方周边来支持《Mother 3》，并且如果这款游戏哪天真在西方发行，届时去买一份正版。

当然，光有动机并不能成就一份好的翻译。翻译一款日式 RPG 极其耗时，而这份工作常常被专业人士做得很糟，所以一群粉丝竟能交出如此机智、如此有劲的文本，实在令人吃惊。而且，要给这款游戏一个公道，他们非做好不可——因为《Mother 3》比大多数作品都更契合"互动故事"这个词。它出自一位讲故事的人之手，而他选择用日式 RPG 的语汇和套路，把自己的故事带到观众面前。

正因如此，它的玩法与其说是连接剧情的几根线，不如说是一串圆点——从一个过场跳到下一个过场之间短短的互动，采用的似乎是它所属类型里最基础的形式和功能。这个最初看来只是用原色讲述的直白故事，很快就展现出许多预算高它数倍的作品都难以企及的广度与深度。它那孩子气的精灵图（外形出奇地偏西式）以意想不到的力量传达喜剧与悲剧；简单的故事先以点头眨眼引人入胜，随后又在一瞬间急转，抛出令人动容的场景。

一开始，你要给主角家里的每一位成员起名，从父亲一直到那条狗——如果你和我们差不多，这绝对是项浩大的工程。如果这还不够，你接着还要回答一连串问题，而这些答案会被编进故事里。问题无非是"你最喜欢的食物是什么？"和"你最喜欢的东西是什么？"这是最朴素的把戏，也是一款游戏让自身贴合玩家最显而易见的方式；可当悲剧与胜利在后半程降临到你的角色身上、当这些自定义真的产生关联时，它依然奏效。

游戏分成八个章节，采用了与当时 DS 上大受欢迎的《勇者斗恶龙 IV》相近的结构。大部分章节从不同角色的视角展开，你的身份在牛仔父亲、笨拙的小偷、家里的狗，以及受尽虐待的猴子之间不断切换。与前两部 Mother 作品不同，本作从一座田园般的森林村庄开始，很快就被一场森林大火打破宁静，而那成为第一个戏剧性的引爆点。笼罩其上的是一个更庞大、更黑暗的威胁：猪面军团。他们贯穿整部游戏入侵你的小镇，把它从质朴的乐园改造成技术先进的警察国家。这种转变毫不含蓄，却让编剧得以探讨自然与技术、封建与资本、个体与社群之间的关系——尽管手法略显笨重。

承载这个故事的系统就没那么出色了。无论按什么标准，这都是一款轻度 RPG：一个瑞士军刀般的按键用来调查场景、发起对话，另一个用来奔跑和撞向物体。在场景中，你的全部手段就这两个输入（尽管某些角色确实拥有自己专属的、依情境而变的动作），因此系统上唯一的创新落在战斗系统里。

这里的基础机制照搬《勇者斗恶龙》，只是外挂了一套节奏动作玩法。用常规方式攻击敌人时，如果你继续跟着战斗音乐的节拍按键，就能追加免费攻击，每按一下多打一次，连击最多可达十六次。有时你并不清楚该去对乐曲的哪一段踩点；不过只要让敌人睡着，游戏就会用一声心跳音效把正确的节拍单独拎出来。到了后期，战斗中音乐的节奏会忽快忽慢，还有些敌人会故意打乱节拍，让你按错拍子。

尽管如此，无法否认这是一款没有多少适合写进标题的卖点的游戏。它的奇妙之处都在细节里：每次和蝙蝠战斗时响起的蝙蝠侠主题曲；那个因为你没被双关语逗笑而数落你的角色；你从着火的房子里救出一位村民后洗了个恢复精神的澡，出来却发现衣服被洗得干干净净、脸上却还沾着煤灰；无处不在、替你存档的青蛙，以及它们越来越荒唐的装扮；飞行老鼠在开战前把头发蓬起来、好让自己显得更威风；那场与重装机甲驯鹿的战斗；那些为你讲解游戏精妙之处、并指出你哪里做错了的蚂蚁和麻雀；糟糕的俳句；你打开宝箱却冒出一只幽灵冲你脸上打嗝的那一刻；紧接着在下一个房间收到、帮你忘掉刚才那幕的清新薄荷；还有那场篝火戏。《Mother 3》充满了令人难忘的瞬间。

有时候，游戏里的简约等同于纯粹的愚笨。但执行得当的简约——那种需要一位称职的设计师才能做到的、刻意的朴素——是优雅。《Mother 3》的简约正是优雅。它把一段深度惊人、引人入胜的故事，安放在一款专注而广博的游戏之中。没有随机战斗，也无需靠刷级来推进剧情，这段旅程即便对类型厌恶者来说也不难入口。《Mother 3》的诞生或许漫长而全然离经叛道，但它值得所有的痛苦与牺牲。

> 来源：[RPGFan](https://www.rpgfan.com/review/mother-3/) · 作者：Alana Hagues · 发布：2021-01-16 · 评分：9.3/10

你要怎么去评价一款像《Mother 3》这样特别的游戏？

糸井重里 Mother 系列的最后一作在日本登陆 Game Boy Advance，距今已过去十四年，而我们仍在苦苦期盼一次正式的西方发行。玩到过它的人争先恐后地赞美它，没玩到的人则贪婪地吸收关于这个系列的每一个细节，忠实地等待着那个神圣的公告。会有那么一天吗？我真心希望如此。但我实在等不下去了，于是在它首次发售十四年后、又录了两期播客之后，我终于通关了《Mother 3》。从那以后，我就再没停止过想它。

游戏分为八章，开场时卢卡斯和他的双胞胎哥哥克劳斯正和母亲日花一起待在祖父家。可仅仅几个小时后，他们田园般的生活就被猪面军团入侵家乡"塔兹米利村"所击碎。这引出了一连串毁灭性的事件，永远改变了卢卡斯和塔兹米利村民的人生。前四章在事件展开的过程中各自跟随不同的角色，游戏后半段则转向更传统的"拯救世界"任务。与系列前两作相比，我认为本作为主角们赋予了更多个性与能动性。《Mother 3》的核心角色在游戏后半程都被视为异类，而且全是些不起眼的人。卢卡斯是个"爱哭鬼"，库玛托拉泼辣而"不像个淑女"，达斯特浑身发臭、还长着一只畸形足——但这些角色并没有被排挤到一旁，反而团结起来，共同去拯救世界。

如果你不了解这款游戏的名声，那么仅凭它《花生漫画》式的画面，你完全有理由以为一切都可爱又温馨。它是任天堂这台掌机上最好看的游戏之一：场景鲜活多彩，角色精灵图表情丰富。即便叙事有时沉重阴郁，它看上去依然迷人至极。这种画面与基调之间的错位其实很有帮助，因为就算你玩过《EarthBound Beginnings》或《EarthBound》，你也不会料到这游戏里会发生某些可怕的事。

正是这种基调让本作与前辈们区别开来。没错，它依旧好笑、依旧是一记辛辣的讽刺，但整个故事被悲伤浸透。仅仅第一个小时就奠定了基调：滑稽的角色名字、温暖的家人羁绊，全都被死亡与毁灭撕碎。我记得自己看着卢卡斯的父亲弗林特在朋友和孩子们眼前崩溃，陷入沉默的暴怒。看着一个男人为他失去的、从他指缝间溜走的东西哀悼，我喉头哽咽——那既让我痛苦地想起自己的悲伤，也让我想起我认识的人是如何面对失去的。《Mother 3》毫不羞于正面探讨这类主题，一路牵动你的心弦，或许最著名的就是直到结局。那段结局宛如一把冰冷的匕首刺进心脏，无论你事先对它了解多少，亲身玩过去时依然既痛苦又美丽。

这个故事有很大一部分不用言语讲述，而且往往极其有效。第四章的开头在我脑海里格外鲜明，因为它直白地描绘了三年间塔兹米利村的变化。曾经只以物易物、或干脆白送货物的商店，如今要靠钱；几乎每户人家里都有一台"快乐盒子"（本质上就是电视机），许多人成天盯着屏幕；土路被道路和铁路覆盖。居民们被操纵着相信钱能解决一切问题，结果是社区精神被摧毁。这座小镇曾是游戏的心脏，尽管弗林特和卢卡斯一家经历着痛苦，它仍像是一片在我眼前被缓缓扭曲的安全之地。我震惊了。新猪城的景象、它的领袖和猪面军团的堕落，也与游戏卑微的开端形成鲜明对比；第一次走进那里，被刺眼的灯光和压迫感十足的建筑迎面拍在脸上，实在令人不安。它让消费主义显得令人不适、丑陋，我老实说感到恶心。

我要为糸井重里和团队鼓掌，他们直截了当地拒绝消费主义，并如此不留情面地批评它。这些场景只用几分钟就说了很多，而这个信息在整个故事里持续回响。很多人把注意力放在《Mother 3》那些更沉重的段落上——它们绝对值得一谈——但真正留在我心里的，是幽默与恐怖之间那种令人不适的平衡，是游戏对消费主义悄悄竖起的中指，以及"更多"的许诺如何腐蚀人心、拆散社群与家庭。

玩起来和前两作差不多，而遗憾的是，它保留了一些老掉牙的设计。其一是角色各自拥有独立的背包，每个容量都相当紧张，尤其是某些角色只有装备可使用的道具才能发挥全部作用。你可以通过青蛙存放道具（不是像以前那样打电话给爸爸），但你必须逐件选择物品，而且每处理一件都要在几个背包之间来回切换。即便放在 2006 年，这套操作循环也烦人得离谱。

另一个问题是不知道该往哪走。《Mother 3》通常会把队伍放在下一个地点附近，或者给你一个模糊的方向。但也就仅此而已：模糊。游戏大部分相当线性（尤其是前六章），可当有人让你去一个从没去过的新地方时，事情就有点烦人了。第七章最受其害，因为它最开放、也最长，你要穿越无名群岛去拔出"针"。尤其是前往塔内塔内岛的路格外古怪——你得走进海洋中某个特定的位置潜入水下，然后在海床上穿行，还得不断停下来补充氧气。

我觉得自己从没像玩《EarthBound》开头、或玩《EarthBound Beginnings》全程时那样烦躁过，但那些老根在这里依然扎得很深——尽管《Mother 3》距上一作已过去十一年。不过我也不认为这是个以"好玩"为目标的系列；它保留核心 RPG 机制，更像是在回望这个系列当年模仿《勇者斗恶龙》的日子。

即便如此，也有几处被精细调校过，主要是在战斗上。其一，《EarthBound》那套滚动生命值的机制在这里感觉紧凑得多，也重要得多。有几场 Boss 战确实会让你措手不及，而把治疗时机卡得恰到好处，有时就是胜负的分水岭。这层额外的战术性，让本应简单的回合制战斗变得相当有趣。

另一个要素对整个系列来说全新，那就是音乐连击系统。轮到角色攻击时，只要你在背景音乐的节拍上按下攻击键，就能让普通攻击形成连击，最多累计十六下。你可以让敌人睡着来降低难度——睡着后能听见它的心跳，而心跳与音乐同步。有些曲子的节拍比其他曲子好跟得多，但有些"拍点"明显不在点上；要是运气不好、没法让敌人睡着，你就只能尽力而为。这又是一层简单的策略，除此之外，战斗系统与《EarthBound》相比基本没变。我也不觉得它需要大改；这些新增内容效果很好。

说到音乐，酒井省吾在一份庞大得惊人的原声上做得非常出色，其中包含 250 多首独特的曲目。从作为游戏主题与核心动机的"Love Theme"，到数量众多的战斗曲，变化极其丰富，没有一处让人觉得重复。酒井从 GBA 音源芯片里榨出的声音十分抓耳，音乐能在转瞬之间从古灵精怪变得气势逼人。就 GBA 的原声而言，它足以与《黄金太阳》系列并列为最佳之一。

在某些方面，我认为《Mother 3》被世界低估了。没错，它是一个教玩家理解悲伤的凄美故事；它颂扬母亲、家庭与社群的力量；它既悲伤欲绝，又好笑。但我从《Mother 3》身上带走的最主要的东西，是它那则反消费主义的信息——它被巧妙地安放在游戏开头与结尾的创伤事件之间。这是一款不怕让画面自己说话的游戏。说实话，我很惊讶自己以前没有听到更多关于它的讨论、也没有更早玩到它。十四年过去，在一个消费主义与资本主义为王、几乎没有多少媒体正面触及这个议题的世界里，它依然令人震动。仅凭这一点，它就值得被认可。等我们（但愿）拿到正式英文版的《Mother 3》时，我会是第一批重返无名群岛的人之一。
