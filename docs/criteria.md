# 评测标准

这不是专业媒体评分，而是帮助自己做游玩决策的个人记录。

## 推荐等级

| 值 | 含义 |
| --- | --- |
| `strong` | 优先推荐，近期想玩可以直接开始 |
| `recommended` | 值得尝试，但需要看个人偏好 |
| `conditional` | 有明显门槛，适合特定场景或人群 |
| `skip` | 现阶段不建议投入时间 |
| `pending` | 尚未形成结论 |

## 状态字段

- `backlog`：想玩，但还没开始
- `playing`：正在游玩
- `completed`：已通关或已完成主要体验
- `dropped`：中途放弃
- `paused`：暂时搁置

## 评分原则

评分以 10 分制记录整体体验，不追求客观，也不把“制作规模”直接等同于“好玩”。重点考虑：

1. 核心玩法是否值得持续投入。
2. 游戏是否适合自己当前的时间和状态。
3. 它是否在某个方面留下了明确记忆点。
