# Playbook / 游戏档案库

这里记录“下一款该玩什么”的判断依据。

目前站点先搭好内容框架，具体游戏条目会放在 `docs/games/`。每个游戏一篇 Markdown，方便阅读，也方便 AI 后续持续维护。

## 内容分区

- **游戏库**：每款游戏的独立档案与最终结论。
- **评测标准**：解释评分、标签和推荐等级，避免以后记录失去一致性。

## 新增一款游戏

1. 复制 `docs/games/_template.md`。
2. 改成游戏英文或拼音 slug，例如 `elden-ring.md`。
3. 填写文件顶部的 frontmatter。
4. 写入自己的游玩感受，提交后由 Cloudflare Pages 自动构建发布。
